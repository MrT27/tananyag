Extra oldal: Nyílt napi Turtle-kódok

Külön elérhető, gyorsan elővehető minták a nyílt napos bemutató órákhoz.

Mire jó ez az oldal?

A saját nyilt_ora.txt jegyzetedben szereplő ötleteket gyűjtöttem össze egy könnyen használható oldalra.

  • gyorsan megnyitható a kód,
  • külön letölthető minden minta .py fájlban,
  • nyílt napon vagy bemutató órán azonnal használható.

Ajánlott sorrend nyílt napra

  1. Teki túra – véletlen és ciklus bemutatása.
  2. Színes spirál – gyors, látványos sikerélmény.
  3. Csillagszóró vagy Forgó négyzetek – haladóbb minta.
  4. Nyomda – játékos lezárás.

Mintakódok

Teki túra

Egyszerű, látványos, véletlenszerű irányválasztást használó minta.

import turtle
import random

ablak = turtle.Screen()
ablak.title("Teki túra")
ablak.bgcolor("white")

sanyi = turtle.Turtle()
sanyi.pensize(4)
sanyi.speed(0)

szinek = ["orange", "green", "blue", "red", "pink"]

for _ in range(20):
    irany = random.randint(1, 3)
    sanyi.color(random.choice(szinek))
    if irany == 1:
        sanyi.forward(50)
    elif irany == 2:
        sanyi.right(90)
        sanyi.forward(50)
    else:
        sanyi.left(90)
        sanyi.forward(50)

turtle.exitonclick()

Színes spirál

Gyors sikerélményt adó ciklusos rajz két váltakozó színnel.

import turtle

ablak = turtle.Screen()
ablak.title("Színes spirál")
ablak.bgcolor("black")

sanyi = turtle.Turtle()
sanyi.speed(0)
sanyi.pensize(4)

for i in range(100):
    if i % 2 == 0:
        sanyi.color("blue")
    else:
        sanyi.color("orange")
    sanyi.forward(5 * i)
    sanyi.right(90)

turtle.exitonclick()

Színes csillagszóró

Karácsonyi hangulatú, sugarasan rajzoló program.

import turtle

ablak = turtle.Screen()
ablak.title("Színes csillagszóró")
ablak.bgcolor("black")

sanyi = turtle.Turtle()
sanyi.speed(0)
sanyi.pensize(4)

for i in range(144):
    if i % 2 == 0:
        sanyi.color("yellow")
    else:
        sanyi.color("red")
    sanyi.forward(150)
    sanyi.backward(150)
    sanyi.right(2.5)

turtle.exitonclick()

Forgó négyzetek

Egymásba forgatott négyzetekkel látványos geometrikus ábra.

import turtle

ablak = turtle.Screen()
ablak.title("Forgó négyzetek")
ablak.bgcolor("black")

sanyi = turtle.Turtle()
sanyi.speed(0)
sanyi.pensize(3)
sanyi.color("deepskyblue")

for i in range(72):
    for _ in range(4):
        sanyi.forward(i * 5)
        sanyi.right(90)
    sanyi.right(5)

turtle.exitonclick()

Nyomda

Bélyegzőzéses minta Turtle alakzattal, nyílt napra különösen látványos.

import turtle

ablak = turtle.Screen()
ablak.title("Nyomda")
ablak.bgcolor("black")

sanyi = turtle.Turtle()
sanyi.shape("turtle")
sanyi.color("lime")
sanyi.penup()
sanyi.goto(-400, 0)
sanyi.speed(0)

for _ in range(100):
    sanyi.stamp()
    sanyi.forward(50)

turtle.exitonclick()
