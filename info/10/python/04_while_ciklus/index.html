4. While ciklus

A while ciklussal addig ismételhetünk egy utasítássorozatot, amíg egy megadott feltétel igaz.

Mit fogsz megtanulni?

  • a while ciklus felépítését és működését,
  • számlálós és feltételes ismétlések készítését,
  • adatok ismételt bekérését és ellenőrzését,
  • végjeles adatfeldolgozást,
  • összegzés és megszámlálás megvalósítását ciklussal,
  • a végtelen ciklus felismerését és elkerülését.

1. Mi az a ciklus?

A ciklus egy vagy több utasítást ismételten végrehajt. A while ciklust akkor használjuk, amikor az ismétlések számát előre nem feltétlenül ismerjük, és a folytatás egy feltételtől függ. 

while feltetel:
    utasitasok
A ciklusmag utasításait be kell húzni. A feltétel minden ismétlés előtt újra kiértékelődik.

2. Egyszerű számlálós ciklus

Az alábbi program kiírja az 1-től 5-ig terjedő egész számokat.

szam = 1

while szam <= 5:
    print(szam)
    szam += 1

A szam += 1 minden körben eggyel növeli a változó értékét. Enélkül a feltétel mindig igaz maradna.

Visszafelé számlálás

szam = 10

while szam >= 1:
    print(szam)
    szam -= 1

print("Start!")

3. A végtelen ciklus

Végtelen ciklus keletkezik, ha a ciklus feltétele soha nem válik hamissá.

szam = 1

while szam <= 5:
    print(szam)
Ebben a programban a szam értéke nem változik, ezért a ciklus nem áll le. Mindig ellenőrizd, hogy a ciklusban történik-e olyan változás, amely közelebb visz a kilépéshez!

4. Adatbekérés ismétlése

A ciklus addig kér be számot, amíg a felhasználó nem ad meg pozitív értéket.

szam = int(input("Adj meg egy pozitív egész számot: "))

while szam <= 0:
    print("Hibás adat!")
    szam = int(input("Adj meg egy pozitív egész számot: "))

print(f"A megadott szám: {szam}")

Ezt a megoldást adatellenőrző ciklusnak is nevezhetjük.

5. Végjeles adatbekérés

A végjel egy különleges érték, amely nem része a feldolgozandó adatoknak, hanem az adatbevitel végét jelzi. Az alábbi példában a végjel a nulla. 

szam = int(input("Adj meg egy számot, a kilépéshez 0-t: "))

while szam != 0:
    print(f"A megadott szám kétszerese: {szam * 2}")
    szam = int(input("Adj meg egy számot, a kilépéshez 0-t: "))

print("Az adatbevitel véget ért.")
A végjelet nem dolgozzuk fel. A ciklus csak addig fut, amíg a bekért érték nem nulla.

6. Összegzés ciklussal

Az osszeg változóban folyamatosan gyűjtjük a megadott számok összegét.

osszeg = 0
szam = int(input("Adj meg egy számot, a kilépéshez 0-t: "))

while szam != 0:
    osszeg += szam
    szam = int(input("Adj meg egy számot, a kilépéshez 0-t: "))

print(f"A megadott számok összege: {osszeg}")

7. Megszámlálás és átlag

Az átlaghoz az összeget és a feldolgozott adatok darabszámát is nyilván kell tartani.

osszeg = 0
darab = 0
szam = int(input("Adj meg egy számot, a kilépéshez 0-t: "))

while szam != 0:
    osszeg += szam
    darab += 1
    szam = int(input("Adj meg egy számot, a kilépéshez 0-t: "))

if darab > 0:
    atlag = osszeg / darab
    print(f"A számok átlaga: {atlag:.2f}")
else:
    print("Nem adtál meg feldolgozható számot.")
A nullával való osztást el kell kerülni. Ezért az átlagot csak akkor számoljuk ki, ha legalább egy adat érkezett.

8. Feltételes megszámlálás

Számoljuk meg, hány pozitív számot adott meg a felhasználó!

pozitiv_db = 0
szam = int(input("Adj meg egy számot, a kilépéshez 0-t: "))

while szam != 0:
    if szam > 0:
        pozitiv_db += 1
    szam = int(input("Adj meg egy számot, a kilépéshez 0-t: "))

print(f"A pozitív számok darabszáma: {pozitiv_db}")

Itt a ciklust és az elágazást együtt használjuk.

9. A break utasítás

A break azonnal megszakítja a ciklus futását.

while True:
    jelszo = input("Add meg a jelszót: ")

    if jelszo == "python10":
        print("Sikeres belépés.")
        break

    print("Hibás jelszó, próbáld újra!")
A while True önmagában végtelen ciklus. Ilyenkor gondoskodni kell egy biztosan elérhető kilépési lehetőségről.

10. Gyakorlófeladatok

  1. Írd ki 1-től 20-ig a páros számokat while ciklussal!
  2. Kérj be egy pozitív számot, majd írd ki attól a számtól visszafelé az értékeket nulláig!
  3. Kérj be egy 1 és 10 közötti számot! Hibás érték esetén kérd be újra!
  4. Kérj be számokat nulláig, majd írd ki az összegüket és a darabszámukat!
  5. Kérj be számokat nulláig, és számold meg, hány páros és hány páratlan szám érkezett!
  6. Készíts PIN-kód ellenőrző programot! A felhasználónak legfeljebb három próbálkozása legyen.
1–2. feladat megoldása

Páros számok

szam = 2

while szam <= 20:
    print(szam)
    szam += 2

Visszaszámlálás

szam = int(input("Adj meg egy pozitív egész számot: "))

while szam < 0:
    szam = int(input("Pozitív számot adj meg: "))

while szam >= 0:
    print(szam)
    szam -= 1
3–4. feladat megoldása

Adatellenőrzés

szam = int(input("Adj meg egy 1 és 10 közötti számot: "))

while szam < 1 or szam > 10:
    print("Hibás érték!")
    szam = int(input("Adj meg egy 1 és 10 közötti számot: "))

print("Helyes adat.")

Összeg és darabszám

osszeg = 0
darab = 0
szam = int(input("Szám, kilépéshez 0: "))

while szam != 0:
    osszeg += szam
    darab += 1
    szam = int(input("Szám, kilépéshez 0: "))

print(f"Összeg: {osszeg}")
print(f"Darabszám: {darab}")
5. feladat megoldása 
paros_db = 0
paratlan_db = 0
szam = int(input("Szám, kilépéshez 0: "))

while szam != 0:
    if szam % 2 == 0:
        paros_db += 1
    else:
        paratlan_db += 1

    szam = int(input("Szám, kilépéshez 0: "))

print(f"Páros számok: {paros_db}")
print(f"Páratlan számok: {paratlan_db}")
6. PIN-kód feladat megoldása 
helyes_pin = "1234"
probalkozas = 0
sikeres = False

while probalkozas < 3 and not sikeres:
    pin = input("Add meg a PIN-kódot: ")
    probalkozas += 1

    if pin == helyes_pin:
        sikeres = True
    else:
        print("Hibás PIN-kód.")

if sikeres:
    print("Sikeres belépés.")
else:
    print("A belépés letiltva.")
Összefoglalás: már tudsz feltételtől függő ismétléseket készíteni, adatokat ellenőrizni, végjelig beolvasni, valamint ciklus segítségével összegezni és megszámolni értékeket.
