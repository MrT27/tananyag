10. Összetett adatszerkezetek

Több összetartozó adat kezelése párhuzamos listákkal és listák listájával.

Mit fogsz megtanulni?

  • összetartozó adatokat több listában tárolni,
  • azonos indexű elemeket együtt feldolgozni,
  • kétdimenziós listát létrehozni és bejárni,
  • sorokat, rekordokat és kapcsolódó adatokat kezelni,
  • a korábbi programozási tételeket összetett adatokon alkalmazni.

1. Összetartozó adatok

Egy tanulóhoz, termékhez vagy városhoz több adat tartozhat. Ezeket kezdetben párhuzamos listákban tárolhatjuk.

nevek = ["Anna", "Béla", "Csilla"]
jegyek = [5, 3, 4]

print(nevek[0], jegyek[0])
Az azonos indexű elemek tartoznak össze: a nevek[0] és a jegyek[0] ugyanannak a tanulónak az adata.

2. Párhuzamos listák bejárása

termekek = ["füzet", "toll", "radír"]
arak = [650, 420, 300]
keszlet = [12, 25, 8]

for i in range(len(termekek)):
    print(f"{termekek[i]}: {arak[i]} Ft, {keszlet[i]} db")
Fontos: a listák hossza és sorrendje legyen azonos. Ha csak az egyik listát rendezzük át, az adatok kapcsolata megszűnik.

3. Feltételes feldolgozás

nevek = ["Anna", "Béla", "Csilla", "Dávid"]
pontok = [86, 54, 73, 91]

for i in range(len(nevek)):
    if pontok[i] >= 80:
        print(f"{nevek[i]}: {pontok[i]} pont")

4. Szélsőérték kapcsolódó adattal

A legnagyobb érték helyett annak indexét őrizzük meg, így a kapcsolódó nevet is elérjük.

varosok = ["Pécs", "Szeged", "Győr", "Eger"]
homersekletek = [24.5, 27.1, 25.8, 23.9]
max_index = 0

for i in range(1, len(homersekletek)):
    if homersekletek[i] > homersekletek[max_index]:
        max_index = i

print(f"Legmelegebb: {varosok[max_index]}")
print(f"Hőmérséklet: {homersekletek[max_index]} °C")

5. Listák listája

Egy lista elemei maguk is lehetnek listák. Egy belső lista egy teljes rekordot tartalmazhat.

tanulok = [
    ["Anna", 5, 4, 5],
    ["Béla", 3, 4, 2],
    ["Csilla", 5, 5, 4]
]

print(tanulok[0])
print(tanulok[0][0])
print(tanulok[0][2])

Az első index a sort, a második a soron belüli elemet választja ki.

6. Kétdimenziós lista bejárása

tabla = [
    [2, 4, 6],
    [1, 3, 5],
    [8, 7, 9]
]

for sor in tabla:
    for elem in sor:
        print(elem, end=" ")
    print()

A külső ciklus a sorokat, a belső ciklus az adott sor elemeit járja be.

7. Rekord adatainak feldolgozása

tanulok = [
    ["Anna", 5, 4, 5],
    ["Béla", 3, 4, 2],
    ["Csilla", 5, 5, 4]
]

for tanulo in tanulok:
    nev = tanulo[0]
    jegyek = tanulo[1:]
    atlag = sum(jegyek) / len(jegyek)
    print(f"{nev} átlaga: {atlag:.2f}")

8. Új rekord hozzáadása

konyvek = [
    ["Egri csillagok", "Gárdonyi Géza", 560],
    ["A Pál utcai fiúk", "Molnár Ferenc", 240]

konyvek.append(["Tüskevár", "Fekete István", 320])

9. Feldolgozás függvénnyel

def legdragabb_termek(termekek):
    max_index = 0
    for i in range(1, len(termekek)):
        if termekek[i][1] > termekek[max_index][1]:
            max_index = i
    return termekek[max_index]

adatok = [["füzet", 650], ["toll", 420], ["hátizsák", 12900]]
termek = legdragabb_termek(adatok)
print(f"{termek[0]}: {termek[1]} Ft")

11. Gyakori hibák

  • A párhuzamos listák eltérő hosszúságúak.
  • Csak az egyik listát rendezzük át.
  • Felcseréljük a sor és az oszlop indexét.
  • Maximumkereséskor nem az indexet őrizzük meg.
  • Egy teljes rekord helyett csak egyetlen adatot adunk hozzá.

7. feladat megoldása
def legnagyobb_elem(tabla):
    maximum = tabla[0][0]
    for sor in tabla:
        for elem in sor:
            if elem > maximum:
                maximum = elem
    return maximum

print(legnagyobb_elem([[4, 8, 2], [11, 3, 7], [5, 9, 6]]))
