6. Listák

A listában több összetartozó adatot tárolhatunk, módosíthatunk és dolgozhatunk fel egyetlen változó segítségével.

Mit fogsz megtanulni?

  • lista létrehozását és kiírását,
  • az elemek elérését index alapján,
  • a szeletelés alapjait,
  • elemek módosítását, hozzáadását és törlését,
  • a lista hosszának meghatározását,
  • listák bejárását for ciklussal,
  • lista feltöltését billentyűzetről.

1. Mi az a lista?

A lista több értéket tárol egy meghatározott sorrendben. A lista elemeit szögletes zárójelek közé írjuk, és vesszővel választjuk el.

gyumolcsok = ["alma", "banán", "citrom", "dió"]
szamok = [4, 7, 12, 3]

print(gyumolcsok)
print(szamok)
Egy lista különböző típusú adatokat is tartalmazhat, de kezdőként célszerű egy listában azonos jelentésű és azonos típusú adatokat tárolni.

2. Elemek elérése index alapján

A lista elemeinek sorszámát indexnek nevezzük. Pythonban az indexelés 0-tól kezdődik.

gyumolcsok = ["alma", "banán", "citrom", "dió"]

print(gyumolcsok[0])   # alma
print(gyumolcsok[2])   # citrom
print(gyumolcsok[-1])  # dió
Fontos: egy négyelemű lista érvényes pozitív indexei: 0, 1, 2 és 3. A nem létező index használata hibát okoz.

3. A lista hossza

A len() függvény megadja, hány elem található a listában.

gyumolcsok = ["alma", "banán", "citrom", "dió"]

print(len(gyumolcsok))  # 4

Az utolsó elem pozitív indexe ezért mindig len(lista) - 1.

4. Szeletelés

Szeleteléssel a lista egy részét kérhetjük le. A kezdőindex eleme bekerül, a végindex eleme viszont már nem.

gyumolcsok = ["alma", "banán", "citrom", "dió", "eper", "füge"]

print(gyumolcsok[2:4])  # ['citrom', 'dió']
print(gyumolcsok[:3])   # az első három elem
print(gyumolcsok[4:])   # a 4-es indextől a végéig

5. Listaelem módosítása

A lista módosítható adatszerkezet: egy elemének új értéket adhatunk.

gyumolcsok = ["alma", "banán", "citrom"]

gyumolcsok[2] = "cseresznye"
print(gyumolcsok)

6. Új elemek hozzáadása

Hozzáadás a lista végéhez: append()

gyumolcsok = ["alma", "banán", "citrom"]
gyumolcsok.append("dió")

print(gyumolcsok)

Beszúrás adott helyre: insert()

gyumolcsok = ["alma", "banán", "citrom"]
gyumolcsok.insert(1, "körte")

print(gyumolcsok)

Az insert(1, "körte") az 1-es indexű helyre szúrja be az új elemet; a korábbi elemek jobbra tolódnak.

7. Elemek törlése

gyumolcsok = ["alma", "banán", "citrom", "dió"]

gyumolcsok.remove("banán")  # törlés érték alapján
torolt = gyumolcsok.pop(1)  # törlés index alapján, az értéket visszaadja
del gyumolcsok[-1]          # törlés index alapján

print(gyumolcsok)
print(f"A pop által törölt elem: {torolt}")
A remove() hibát okoz, ha a megadott érték nincs a listában. Ezt később az in operátorral ellenőrizhetjük.

8. Keresés az in operátorral

gyumolcsok = ["alma", "banán", "citrom"]

if "banán" in gyumolcsok:
    print("A banán szerepel a listában.")
else:
    print("A banán nem szerepel a listában.")

9. Lista bejárása

Elemek közvetlen bejárása

gyumolcsok = ["alma", "banán", "citrom"]

for gyumolcs in gyumolcsok:
    print(gyumolcs)

Bejárás indexekkel

gyumolcsok = ["alma", "banán", "citrom"]

for i in range(len(gyumolcsok)):
    print(f"{i}. index: {gyumolcsok[i]}")
Ha csak az értékekre van szükségünk, az első megoldás egyszerűbb. Indexes bejárást akkor használjunk, ha az indexre is szükség van.

10. Lista feltöltése billentyűzetről

Kérjünk be öt számot, és helyezzük őket egy listába!

szamok = []

for i in range(5):
    szam = int(input(f"Add meg a(z) {i + 1}. számot: "))
    szamok.append(szam)

print(szamok)

11. Rendezés és megfordítás

szamok = [8, 2, 11, 4, 1]

szamok.sort()
print(szamok)

szamok.reverse()
print(szamok)

A sort() növekvő sorrendbe rendezi, a reverse() pedig megfordítja a lista aktuális sorrendjét.

12. Lista másolása

eredeti = [1, 2, 3]
masolat = eredeti.copy()

masolat.append(4)

print(eredeti)  # [1, 2, 3]
print(masolat)  # [1, 2, 3, 4]
Gyakori hiba: a masolat = eredeti nem készít önálló másolatot. Ilyenkor a két változó ugyanarra a listára hivatkozik.

  6. Kérj be öt számot egy listába, majd írd ki közülük csak a páros számokat!

7. feladat megoldása 
bevasarlolista = []
termek = input("Adj meg egy terméket, a befejezéshez nyomj Entert: ")

while termek != "":
    bevasarlolista.append(termek)
    termek = input("Adj meg egy terméket, a befejezéshez nyomj Entert: ")

print("Bevásárlólista:")
for termek in bevasarlolista:
    print(f"- {termek}")
Összefoglalás: már tudsz több adatot egy listában tárolni, az elemeket index alapján elérni és módosítani, új elemeket hozzáadni, elemeket törölni, valamint listát ciklussal feltölteni és bejárni.
