6. Listák

Egy buszjárat megállóit és az utasszámokat listákban tároljuk. Ezeken keresztül tanuljuk meg a listák létrehozását, módosítását és bejárását. A példák kitalált közlekedési adatokat használnak.

Mit fogsz megtanulni?

  • lista létrehozását és kiírását,
  • az elemek elérését index alapján,
  • a szelmegalloés alapjait,
  • elemek módosítását, hozzáadását és törlését,
  • a lista hosszának meghatározását,
  • listák bejárását for ciklussal,
  • lista feltöltését billentyűzetről.

1. Mi az a lista?

A lista több értéket tárol egy meghatározott sorrendben. A lista elemeit szögletes zárójelek közé írjuk, és vesszővel választjuk el.

megallok = ["Vasútállomás", "Iskola", "Könyvtár", "Sportcsarnok"]
utasszamok = [4, 7, 12, 3]

print(megallok)
print(utasszamok)
Egy lista különböző típusú adatokat is tartVasútállomászhat, de kezdőként célszerű egy listában azonos jelentésű és azonos típusú adatokat tárolni.

2. Elemek elérése index alapján

A lista elemeinek sorszámát indexnek nevezzük. Pythonban az indexelés 0-tól kezdődik.

megallok = ["Vasútállomás", "Iskola", "Könyvtár", "Sportcsarnok"]

print(megallok[0])   # Vasútállomás
print(megallok[2])   # Könyvtár
print(megallok[-1])  # Sportcsarnok
Fontos: egy négyelemű lista érvényes pozitív indexei: 0, 1, 2 és 3. A nem létező index használata hibát okoz.

3. A lista hossza

A len() függvény megadja, hány elem található a listában.

megallok = ["Vasútállomás", "Iskola", "Könyvtár", "Sportcsarnok"]

print(len(megallok))  # 4

Az utolsó elem pozitív indexe ezért mindig len(lista) - 1.

4. Szelmegalloés

Szelmegalloéssel a lista egy részét kérhetjük le. A kezdőindex eleme bekerül, a végindex eleme viszont már nem.

megallok = ["Vasútállomás", "Iskola", "Könyvtár", "Sportcsarnok", "Uszoda", "Kórház"]

print(megallok[2:4])  # ['Könyvtár', 'Sportcsarnok']
print(megallok[:3])   # az első három elem
print(megallok[4:])   # a 4-es indextől a végéig

5. Listaelem módosítása

A lista módosítható adatszerkezet: egy elemének új értéket adhatunk.

megallok = ["Vasútállomás", "Iskola", "Könyvtár"]

megallok[2] = "Autóbusz-állomás"
print(megallok)

6. Új elemek hozzáadása

Hozzáadás a lista végéhez: append()

megallok = ["Vasútállomás", "Iskola", "Könyvtár"]
megallok.append("Sportcsarnok")

print(megallok)

Beszúrás adott helyre: insert()

megallok = ["Vasútállomás", "Iskola", "Könyvtár"]
megallok.insert(1, "Park")

print(megallok)

Az insert(1, "Park") az 1-es indexű helyre szúrja be az új elemet; a korábbi elemek jobbra tolódnak.

7. Elemek törlése

megallok = ["Vasútállomás", "Iskola", "Könyvtár", "Sportcsarnok"]

megallok.remove("Iskola")  # törlés érték alapján
torolt = megallok.pop(1)  # törlés index alapján, az értéket visszaadja
del megallok[-1]          # törlés index alapján

print(megallok)
print(f"A pop által törölt elem: {torolt}")
A remove() hibát okoz, ha a megadott érték nincs a listában. Ezt később az in operátorral ellenőrizhetjük.

8. Keresés az in operátorral

megallok = ["Vasútállomás", "Iskola", "Könyvtár"]

if "Iskola" in megallok:
    print("Az Iskola szerepel a listában.")
else:
    print("Az Iskola nem szerepel a listában.")

9. Lista bejárása

Elemek közvetlen bejárása

megallok = ["Vasútállomás", "Iskola", "Könyvtár"]

for megallo in megallok:
    print(megallo)

Bejárás indexekkel

megallok = ["Vasútállomás", "Iskola", "Könyvtár"]

for i in range(len(megallok)):
    print(f"{i}. index: {megallok[i]}")
Ha csak az értékekre van szükségünk, az első megoldás egyszerűbb. Indexes bejárást akkor használjunk, ha az indexre is szükség van.

10. Lista feltöltése billentyűzetről

Kérjünk be öt járat utasszámát, és helyezzük őket egy listába!

utasszamok = []

for i in range(5):
    utasszam = int(input(f"Add meg a(z) {i + 1}. járat utasszámát: "))
    utasszamok.append(utasszam)

print(utasszamok)

11. Rendezés és megfordítás

utasszamok = [8, 2, 11, 4, 1]

utasszamok.sort()
print(utasszamok)

utasszamok.reverse()
print(utasszamok)

A sort() növekvő sorrendbe rendezi az utasszámokat, a reverse() pedig megfordítja a lista aktuális sorrendjét. Egy útvonal megállóit ne rendezd névsorba: ott az utazás sorrendje számít!

12. Lista másolása

Egy járatlistáról külön másolatot készítünk, és csak a másolatot bővítjük.

eredeti = [12, 24, 36]
masolat = eredeti.copy()

masolat.append(48)

print(eredeti)  # [12, 24, 36]
print(masolat)  # [12, 24, 36, 48]
Gyakori hiba: a masolat = eredeti nem készít önálló másolatot. Ilyenkor a két változó ugyanarra a listára hivatkozik.
