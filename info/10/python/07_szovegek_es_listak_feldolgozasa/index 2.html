7. Szövegek és listák feldolgozása

A szövegeket karakterenként vagy szavanként is feldolgozhatjuk, a kiválasztott adatokat pedig új listába gyűjthetjük.

Mit fogsz megtanulni?

  • szöveg karaktereinek bejárását,
  • gyakori szövegkezelő metódusok használatát,
  • mondatok szavakra bontását a split() segítségével,
  • lista elemeinek összefűzését a join() metódussal,
  • keresést, megszámlálást és szűrést,
  • új lista készítését egy meglévő lista alapján.

1. A szöveg mint karaktersorozat

A Python a szöveget karakterek rendezett sorozataként kezeli. Emiatt indexelhető, szeletelhető és ciklussal bejárható.

szo = "programozás"

print(szo[0])    # p
print(szo[-1])   # s
print(szo[0:7])  # program
Fontos: a szöveg karaktereit nem módosíthatjuk közvetlenül. Egy változtatáshoz új szöveget kell létrehozni.

2. Szöveg bejárása

szo = input("Adj meg egy szót: ")

for karakter in szo:
    print(karakter)

Indexes bejárást akkor használunk, ha a karakter helyére is szükségünk van.

szo = "Python"

for i in range(len(szo)):
    print(f"{i}. index: {szo[i]}")

3. Kis- és nagybetűk kezelése

nev = input("Add meg a neved: ")

print(nev.lower())       # minden betű kicsi
print(nev.upper())       # minden betű nagy
print(nev.capitalize())  # az első betű nagy
print(nev.title())       # minden szó első betűje nagy

Keresés előtt gyakran egységesítjük a szöveget, hogy a kis- és nagybetűk ne befolyásolják az eredményt.

4. Felesleges szóközök eltávolítása

szoveg = "   Python tananyag   "

print(szoveg.strip())   # mindkét oldalról
print(szoveg.lstrip())  # bal oldalról
print(szoveg.rstrip())  # jobb oldalról
A strip() különösen hasznos fájlból beolvasott sorok és felhasználói adatok tisztításakor.

5. Keresés szövegben

mondat = "A Python könnyen tanulható nyelv."

if "Python" in mondat:
    print("A keresett szó szerepel a mondatban.")

print(mondat.count("a"))
print(mondat.startswith("A"))
print(mondat.endswith("nyelv."))

6. Szöveg cseréje

mondat = "A macska a széken ül."
uj_mondat = mondat.replace("macska", "kutya")

print(uj_mondat)

A replace() nem az eredeti szöveget módosítja, hanem egy új szöveget ad vissza.

7. Mondat felbontása szavakra: split()

A split() egy szövegből listát készít. Alapértelmezés szerint a szóközöknél darabol.

mondat = input("Írj be egy mondatot: ")
szavak = mondat.split()

print(szavak)
print(f"A mondat {len(szavak)} szóból áll.")

Más elválasztójelet is megadhatunk.

adat = "alma;körte;szilva;barack"
gyumolcsok = adat.split(";")

print(gyumolcsok)

8. Lista összefűzése szöveggé: join()

szavak = ["A", "Python", "jól", "tanulható"]
mondat = " ".join(szavak)

print(mondat)

Az idézőjelek között megadott szöveg kerül az elemek közé.

nevek = ["Anna", "Béla", "Csilla"]
print(", ".join(nevek))

9. Karakterek megszámlálása

Számoljuk meg, hány magánhangzó szerepel egy szóban!

szo = input("Adj meg egy szót: ").lower()
maganhangzok = "aáeéiíoóöőuúüű"
darab = 0

for karakter in szo:
    if karakter in maganhangzok:
        darab += 1

print(f"A magánhangzók száma: {darab}")

10. Szavak keresése és szűrése

Gyűjtsük ki azokat a szavakat, amelyek legalább öt karakterből állnak!

mondat = input("Írj be egy mondatot: ")
szavak = mondat.split()
hosszu_szavak = []

for szo in szavak:
    if len(szo) >= 5:
        hosszu_szavak.append(szo)

print(hosszu_szavak)
Ez a szűrés alapgondolata: végigjárjuk az adatokat, megvizsgálunk egy feltételt, és a megfelelő elemeket új listába tesszük.

11. Szöveg megfordítása

szo = input("Adj meg egy szót: ")
forditott = ""

for karakter in szo:
    forditott = karakter + forditott

print(forditott)

Szeleteléssel rövidebben is megoldható:

print(szo[::-1])

12. Palindrom vizsgálata

A palindrom olyan szó vagy szöveg, amely visszafelé olvasva is ugyanaz.

szo = input("Adj meg egy szót: ").lower()

if szo == szo[::-1]:
    print("Palindrom.")
else:
    print("Nem palindrom.")

13. Gyakorlófeladatok

  1. Kérj be egy szót, majd írd ki a karaktereit külön sorokba!
  2. Kérj be egy mondatot, és írd ki, hány karakterből, illetve hány szóból áll!
  3. Kérj be egy szöveget, majd számold meg benne az „a” betűket kis- és nagybetűtől függetlenül!
  4. Kérj be egy mondatot, és írd ki csak a négy karakternél hosszabb szavakat!
  5. Kérj be öt nevet egy listába, majd írd ki azokat, amelyek „A” betűvel kezdődnek!
  6. Kérj be vesszővel elválasztott egész számokat, alakítsd őket számlistává, majd írd ki a páros számokat!
  7. Kérj be egy mondatot, fordítsd meg a szavak sorrendjét, majd írd ki az eredményt!
1–2. feladat megoldása 
szo = input("Adj meg egy szót: ")

for karakter in szo:
    print(karakter)
mondat = input("Írj be egy mondatot: ")
szavak = mondat.split()

print(f"Karakterek száma: {len(mondat)}")
print(f"Szavak száma: {len(szavak)}")
3–4. feladat megoldása 
szoveg = input("Adj meg egy szöveget: ").lower()
darab = 0

for karakter in szoveg:
    if karakter == "a":
        darab += 1

print(f"Az a betűk száma: {darab}")
mondat = input("Írj be egy mondatot: ")
szavak = mondat.split()

for szo in szavak:
    if len(szo) > 4:
        print(szo)
5–6. feladat megoldása 
nevek = []

for i in range(5):
    nevek.append(input(f"Add meg a(z) {i + 1}. nevet: ").strip())

for nev in nevek:
    if nev.lower().startswith("a"):
        print(nev)
adat = input("Adj meg egész számokat vesszővel elválasztva: ")
szoveges_szamok = adat.split(",")
szamok = []

for elem in szoveges_szamok:
    szamok.append(int(elem.strip()))

for szam in szamok:
    if szam % 2 == 0:
        print(szam)
7. feladat megoldása 
mondat = input("Írj be egy mondatot: ")
szavak = mondat.split()
szavak.reverse()

print(" ".join(szavak))
Összefoglalás: már tudsz szöveget karakterenként és szavanként feldolgozni, szöveget listává alakítani, listát szöveggé összefűzni, valamint feltétel alapján karaktereket és listaelemeket keresni, megszámolni és kiválogatni.
