11. Szótárak

Összetartozó adatok tárolása beszédes kulcs–érték párokkal.

Mit fogsz megtanulni?

  • szótárat létrehozni és adatokat lekérni belőle,
  • új kulcs–érték párt hozzáadni, módosítani és törölni,
  • biztonságosan kezelni a hiányzó kulcsokat,
  • szótárakat ciklussal bejárni,
  • szótárak listájában összetett adatokat feldolgozni.

1. Mi az a szótár?

A szótár egy olyan adatszerkezet, amelyben az értékeket sorszámok helyett beszédes kulcsokkal érjük el.

tanulo = {
    "nev": "Anna",
    "kor": 16,
    "atlag": 4.6
}

print(tanulo["nev"])
print(tanulo["atlag"])
A "nev", "kor" és "atlag" kulcsok; az utánuk álló adatok az értékek.

2. Miért jobb néha, mint a listák listája?

Lista használatával

tanulo = ["Anna", 16, 4.6]
print(tanulo[2])

Meg kell jegyezni, hogy a 2. index az átlagot jelenti.

Szótár használatával

tanulo = {
    "nev": "Anna",
    "kor": 16,
    "atlag": 4.6
}
print(tanulo["atlag"])

A kulcs neve elárulja, milyen adatot kérünk le.

3. Új adat hozzáadása és módosítása

auto = {
    "marka": "Toyota",
    "szin": "kék"
}

auto["evjarat"] = 2018

auto["szin"] = "piros"

print(auto)

Ha a kulcs még nem létezik, új adat jön létre. Ha már létezik, az értéke módosul.

4. Elem törlése

termek = {
    "nev": "füzet",
    "ar": 650,
    "keszlet": 12
}

del termek["keszlet"]

ar = termek.pop("ar")
print(ar)
print(termek)

A del törli az elemet, a pop() pedig törlés közben vissza is adja az értékét.

5. Kulcs létezésének ellenőrzése

ember = {"nev": "Béla", "kor": 17}

if "email" in ember:
    print(ember["email"])
else:
    print("Nincs megadva e-mail-cím.")
Gyakori hiba: ha nem létező kulcsra hivatkozunk szögletes zárójellel, a program hibával leáll.

6. Biztonságos lekérés a get() metódussal

ember = {"nev": "Csilla", "kor": 16}

print(ember.get("nev"))
print(ember.get("email"))
print(ember.get("email", "nincs megadva"))

A get() hiányzó kulcs esetén nem állítja le a programot. Második paraméterként alapértelmezett értéket is megadhatunk.

7. Szótár bejárása

tanulo = {
    "nev": "Dávid",
    "kor": 16,
    "atlag": 4.2
}

for kulcs in tanulo:
    print(kulcs, tanulo[kulcs])

A ciklus alapértelmezés szerint a kulcsokat járja be.

8. keys(), values() és items()

adatok = {
    "varos": "Pécs",
    "lakossag": 140000,
    "megye": "Baranya"
}

for kulcs in adatok.keys():
    print(kulcs)

for ertek in adatok.values():
    print(ertek)

for kulcs, ertek in adatok.items():
    print(f"{kulcs}: {ertek}")
MetódusMit jár be?
keys()A kulcsokat
values()Az értékeket
items()A kulcs–érték párokat

9. Szótárak listája

Több rekordot úgy tárolhatunk, hogy minden listaelem egy külön szótár.

tanulok = [
    {"nev": "Anna", "kor": 16, "atlag": 4.6},
    {"nev": "Béla", "kor": 17, "atlag": 3.4},
    {"nev": "Csilla", "kor": 16, "atlag": 4.9}
]

for tanulo in tanulok:
    print(f"{tanulo['nev']}: {tanulo['atlag']}")

termekek = [

12. Gyakoriságok tárolása szótárban

A szótár különösen hasznos, amikor meg akarjuk számolni, hogy az egyes értékek hányszor fordulnak elő.

szavak = ["alma", "körte", "alma", "szilva", "körte", "alma"]
gyakorisag = {}

for szo in szavak:
    if szo in gyakorisag:
        gyakorisag[szo] += 1
    else:
        gyakorisag[szo] = 1

print(gyakorisag)

13. Feldolgozás függvénnyel

def legjobb_tanulo(tanulok):
    max_index = 0

    for i in range(1, len(tanulok)):
        if tanulok[i]["atlag"] > tanulok[max_index]["atlag"]:
            max_index = i

    return tanulok[max_index]

adatok = [
    {"nev": "Anna", "atlag": 4.6},
    {"nev": "Béla", "atlag": 3.4},
    {"nev": "Csilla", "atlag": 4.9}
]

legjobb = legjobb_tanulo(adatok)
print(legjobb["nev"])

14. Gyakori hibák

  • Nem létező kulcsot kérünk le szögletes zárójellel.
  • Összekeverjük a kulcsot és az értéket.
  • Azonos kulcsot kétszer adunk meg; ilyenkor az utolsó érték marad meg.
  • Szótárak listájában elfelejtjük megadni, melyik kulcs értékét dolgozzuk fel.
  • Bejárás közben megváltoztatjuk a szótár méretét.
