8. Programozási tételek

Gyakran ugyanazokat az adatfeldolgozási mintákat használjuk. Ezeket nevezzük programozási tételeknek.

Mit fogsz megtanulni?

  • összegzés és megszámlálás alkalmazását,
  • eldöntést és lineáris keresést,
  • legkisebb és legnagyobb elem meghatározását,
  • kiválasztást és kiválogatást,
  • a megfelelő tétel felismerését egy feladat szövegéből,
  • több tétel összekapcsolását összetett feladatokban.

1. Mit nevezünk programozási tételnek?

A programozási tételek olyan általános megoldási minták, amelyek sok különböző feladatban újra felhasználhatók. A lista elemeit többnyire ciklussal járjuk be, közben pedig egy változóban gyűjtjük az eredményt.

Fontos gondolat: először azt kell felismerni, milyen eredményt keresünk: összeget, darabszámot, választ egy kérdésre, egy konkrét elemet vagy egy új listát.

2. Összegzés tétele

Az elemek összegét határozzuk meg. Az eredményváltozó kezdeti értéke 0.

szamok = [12, 7, 5, 18, 9]
osszeg = 0

for szam in szamok:
    osszeg += szam

print(f"Az elemek összege: {osszeg}")

Feltételes összegzésnél csak a megfelelő elemeket adjuk hozzá.

paros_osszeg = 0

for szam in szamok:
    if szam % 2 == 0:
        paros_osszeg += szam

print(f"A páros számok összege: {paros_osszeg}")

3. Megszámlálás tétele

Megszámoljuk, hány elem felel meg egy feltételnek.

jegyek = [5, 3, 4, 2, 5, 1, 4]
darab = 0

for jegy in jegyek:
    if jegy == 5:
        darab += 1

print(f"Az ötösök száma: {darab}")
Az összegzésnél az elemek értékét adjuk össze, a megszámlálásnál mindig egy számlálót növelünk.

4. Átlagszámítás

Az átlag nem külön programozási tétel: összegzést és darabszámot használunk hozzá.

pontok = [72, 65, 91, 84, 78]
osszeg = 0

for pont in pontok:
    osszeg += pont

atlag = osszeg / len(pontok)
print(f"Az átlag: {atlag:.2f}")
Üres lista: osztás előtt ellenőrizni kell, hogy a lista tartalmaz-e elemet.

5. Eldöntés tétele

A kérdésre igen vagy nem a válasz: található-e legalább egy megfelelő elem?

szamok = [3, 7, 11, 14, 19]
talalhato = False

for szam in szamok:
    if szam % 2 == 0:
        talalhato = True
        break

if talalhato:
    print("Van páros szám a listában.")
else:
    print("Nincs páros szám a listában.")

A break azért használható, mert az első találat után már ismerjük a választ.

6. Lineáris keresés

Nemcsak azt szeretnénk tudni, hogy van-e találat, hanem a helyére vagy az adatára is szükségünk van.

nevek = ["Anna", "Béla", "Csilla", "Dávid"]
keresett = input("Kit keresel? ")
index = -1

for i in range(len(nevek)):
    if nevek[i].lower() == keresett.lower():
        index = i
        break

if index != -1:
    print(f"A név indexe: {index}")
else:
    print("A név nem található.")
Miért −1? A lista érvényes indexei 0-tól kezdődnek, ezért a −1 külön jelölheti, hogy nem találtunk megfelelő elemet.

7. Minimum- és maximumkiválasztás

Feltételezzük, hogy a lista nem üres. Az első elemet tekintjük kezdetben a legkisebbnek vagy legnagyobbnak.

homersekletek = [12, 9, 15, 7, 14]
minimum = homersekletek[0]
maximum = homersekletek[0]

for homerseklet in homersekletek[1:]:
    if homerseklet < minimum:
        minimum = homerseklet
    if homerseklet > maximum:
        maximum = homerseklet

print(f"Minimum: {minimum} °C")
print(f"Maximum: {maximum} °C")

Ha a szélsőérték helye is kell, indexet tárolunk.

max_index = 0

for i in range(1, len(homersekletek)):
    if homersekletek[i] > homersekletek[max_index]:
        max_index = i

print(f"A legnagyobb érték indexe: {max_index}")

8. Kiválasztás tétele

Biztosan tudjuk, hogy a keresett elem szerepel az adatok között, ezért a cél a helyének meghatározása.

szamok = [8, 13, 21, 34, 55]
keresett = 21
i = 0

while szamok[i] != keresett:
    i += 1

print(f"A keresett elem indexe: {i}")
Csak akkor használható biztonságosan, ha garantált, hogy a keresett elem valóban megtalálható a listában. Ellenkező esetben lineáris keresést használjunk.

9. Kiválogatás tétele

A feltételnek megfelelő összes elemet új listába gyűjtjük.

szamok = [4, 11, 8, 17, 20, 5]
parosak = []

for szam in szamok:
    if szam % 2 == 0:
        parosak.append(szam)

print(parosak)

Az eredeti lista nem változik meg.

10. Másolás tétele

Minden elemből új értéket készítünk, és ezeket egy új listában tároljuk.

celsius = [0, 10, 20, 30]
fahrenheit = []

for fok in celsius:
    fahrenheit.append(fok * 9 / 5 + 32)

print(fahrenheit)
Kiválogatásnál csak néhány elem kerül az új listába; másolásnál minden eredeti elemhez létrejön egy új elem.

11. Több tétel összekapcsolása

Egy valódi feladat gyakran több programozási tételt is igényel.

pontok = [56, 82, 47, 91, 73, 88]
osszeg = 0
sikeresek = []
maximum = pontok[0]

for pont in pontok:
    osszeg += pont

    if pont >= 60:
        sikeresek.append(pont)

    if pont > maximum:
        maximum = pont

atlag = osszeg / len(pontok)

print(f"Átlag: {atlag:.2f}")
print(f"Sikeres eredmények: {sikeresek}")
print(f"Legjobb eredmény: {maximum}")

  2. Számold meg, hány negatív szám található egy listában!
  3. Döntsd el, van-e a listában 100-nál nagyobb szám!
  4. Kérj be egy nevet, és keresd meg egy névlistában! Írd ki az indexét vagy azt, hogy nincs benne!
  5. Határozd meg egy lista legkisebb elemét és annak indexét!
  6. Gyűjtsd új listába a legalább négyes osztályzatokat!
  7. Egy napi hőmérsékleteket tartalmazó listából írd ki az átlagot, a minimumot, a maximumot és a fagypont alatti értékek számát!

7. feladat megoldása 
homersekletek = [3, -2, 5, 1, -4, 6, 0]
osszeg = 0
minimum = homersekletek[0]
maximum = homersekletek[0]
fagyos_napok = 0

for fok in homersekletek:
    osszeg += fok

    if fok < minimum:
        minimum = fok
    if fok > maximum:
        maximum = fok
    if fok < 0:
        fagyos_napok += 1

print(f"Átlag: {osszeg / len(homersekletek):.2f} °C")
