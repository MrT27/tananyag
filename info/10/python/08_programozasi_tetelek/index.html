8. Programozási tételek

Ugyanazt a feladatot először ciklussal, majd a Python rövidebb eszközével oldjuk meg.

A példák adatai napi könyvtári kölcsönzések. Minden kódblokk önállóan futtatható.

Órai gyakorlás

1. Összegzés

Mennyi a kölcsönzések összege?

Klasszikus megoldás

adatok = [3, 5, 2, 8, 5]

osszeg = 0
for x in adatok:
    osszeg += x
print(osszeg)

Rövidebb Python-megoldás

adatok = [3, 5, 2, 8, 5]

print(sum(adatok))

A sum() számlistán az összeget adja, üres listán 0-t.

Várt eredmény23

2. Megszámlálás

Hányszor szerepel az 5?

Klasszikus megoldás

adatok = [3, 5, 2, 8, 5]

darab = 0
for x in adatok:
    if x == 5:
        darab += 1
print(darab)

Rövidebb Python-megoldás

adatok = [3, 5, 2, 8, 5]

print(adatok.count(5))

A count() pontos egyezést vizsgál. A legalább ötös értékekhez feltétel kell.

Várt eredmény2

3. Eldöntés

Szerepel-e a 8?

Klasszikus megoldás

adatok = [3, 5, 2, 8, 5]

i = 0
while i < len(adatok) and adatok[i] != 8:
    i += 1
print(i < len(adatok))

For ciklussal

adatok = [3, 5, 2, 8, 5]

van = False
for x in adatok:
    if x == 8:
        van = True
        break
print(van)

Rövidebb Python-megoldás

adatok = [3, 5, 2, 8, 5]

print(8 in adatok)

A for-os változatban a break állítja meg a keresést. Az in konkrét értéket keres.

Várt eredményTrue

4. Lineáris keresés

Hol van az első 5? Ha nincs, legyen az eredmény −1.

Klasszikus megoldás

adatok = [3, 5, 2, 8, 5]

hely = -1
for i in range(len(adatok)):
    if adatok[i] == 5:
        hely = i
        break
print(hely)

Rövidebb Python-megoldás

adatok = [3, 5, 2, 8, 5]

print(adatok.index(5) if 5 in adatok else -1)

Az index() az első találat indexét adja. Hiányzó értéknél hibát dob, ezért kell előtte az in.

Várt eredmény1

5. Minimumkiválasztás

Melyik a legkisebb érték és az első ilyen elem indexe?

Klasszikus megoldás

adatok = [3, 5, 2, 8, 5]

hely = 0
for i in range(1, len(adatok)):
    if adatok[i] < adatok[hely]:
        hely = i
print(adatok[hely], hely)

Rövidebb Python-megoldás

adatok = [3, 5, 2, 8, 5]

ertek = min(adatok)
print(ertek, adatok.index(ertek))

A min() értéket ad. Üres listán nincs minimum. Holtversenyben az első indexet kapjuk.

Várt eredmény2 2

6. Maximumkiválasztás

Melyik a legnagyobb érték és az első ilyen elem indexe?

Klasszikus megoldás

adatok = [3, 5, 2, 8, 5]

hely = 0
for i in range(1, len(adatok)):
    if adatok[i] > adatok[hely]:
        hely = i
print(adatok[hely], hely)

Rövidebb Python-megoldás

adatok = [3, 5, 2, 8, 5]

ertek = max(adatok)
print(ertek, adatok.index(ertek))

A max() értéket ad. Üres listán nincs maximum. A szigorú összehasonlítás az első maximumot tartja meg.

Várt eredmény8 3

7. Kiválasztás

Hol van a biztosan szereplő 3?

Klasszikus megoldás

adatok = [3, 5, 2, 8, 5]

i = 0
while adatok[i] != 3:
    i += 1
print(i)

Rövidebb Python-megoldás

adatok = [3, 5, 2, 8, 5]

print(adatok.index(3))

Kiválasztásnál adott, hogy van találat. Ha ez bizonytalan, használd a lineáris keresést.

Várt eredmény0

8. Kiválogatás

Mely értékek legalább ötösek?

Klasszikus megoldás

adatok = [3, 5, 2, 8, 5]

eredmeny = []
for x in adatok:
    if x >= 5:
        eredmeny.append(x)
print(eredmeny)

Rövidebb Python-megoldás

adatok = [3, 5, 2, 8, 5]

print([x for x in adatok if x >= 5])

A listakifejezés a for ciklust és a feltételt egy sorba írja.

Várt eredmény[5, 8, 5]

9. Másolás átalakítással

Kétszerezd meg az összes értéket egy új listában.

Klasszikus megoldás

adatok = [3, 5, 2, 8, 5]

eredmeny = []
for x in adatok:
    eredmeny.append(x * 2)
print(eredmeny)

Rövidebb Python-megoldás

adatok = [3, 5, 2, 8, 5]

print([x * 2 for x in adatok])

Az új lista ugyanannyi elemet tartalmaz. A listakifejezés minden elemre alkalmazza a műveletet.

Várt eredmény[6, 10, 4, 16, 10]

10. Átlagszámítás

Mennyi az átlag? Üres listán jelezd, hogy nincs adat.

Klasszikus megoldás

adatok = [3, 5, 2, 8, 5]

osszeg = 0
for x in adatok:
    osszeg += x
print(osszeg / len(adatok) if adatok else "Nincs adat")

Rövidebb Python-megoldás

adatok = [3, 5, 2, 8, 5]

from statistics import mean
print(mean(adatok) if adatok else "Nincs adat")

Az átlagot összegzésből és elemszámból kapjuk. A mean() ugyanezt számolja ki.

Várt eredmény4.6
