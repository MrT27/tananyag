8. Programozási tételek

Járatok utasszámait, késéseit és megállóit dolgozzuk fel az újra felhasználható adatfeldolgozási mintákkal, a programozási tételekkel. A példák kitalált közlekedési adatokat használnak.

Mit fogsz megtanulni?

  • összegzés és megszámlálás alkalmazását,
  • eldöntést és lineáris keresést,
  • legkisebb és legnagyobb elem meghatározását,
  • kiválasztást és kiválogatást,
  • a megfelelő tétel felismerését egy feladat szövegéből,
  • több tétel összekapcsolását összetett feladatokban.

1. Mit nevezünk programozási tételnek?

A programozási tételek olyan általános megoldási minták, amelyek sok különböző feladatban újra felhasználhatók. A lista elemeit többnyire ciklussal járjuk be, közben pedig egy változóban gyűjtjük az eredményt.

Fontos gondolat: először azt kell felismerni, milyen eredményt keresünk: összeget, darabszámot, választ egy kérdésre, egy konkrét elemet vagy egy új listát.

2. Összegzés tétele

Öt járat szállított utasainak számát adjuk össze. Egy utazás egy utasnak számít; ez nem feltétlenül különböző emberek száma. Az eredményváltozó kezdeti értéke 0.

utasszamok = [12, 7, 5, 18, 9]
osszeg = 0

for utasszam in utasszamok:
    osszeg += utasszam

print(f"Összes szállított utas: {osszeg}")

Feltételes összegzésnél csak a megfelelő elemeket adjuk hozzá.

paros_osszeg = 0

for utasszam in utasszamok:
    if utasszam % 2 == 0:
        paros_osszeg += utasszam

print(f"A páros utasszámok összege: {paros_osszeg}")

3. Megszámlálás tétele

Megszámoljuk, hány járat késett pontosan öt percet. A lista a járatok késését tárolja percekben.

kesesek = [5, 3, 4, 2, 5, 1, 4]
darab = 0

for keses in kesesek:
    if keses == 5:
        darab += 1

print(f"Az öt percet késő járatok száma: {darab}")
Az összegzésnél az elemek értékét adjuk össze, a megszámlálásnál mindig egy számlálót növelünk.

4. Átlagszámítás

Az átlag nem külön programozási tétel: összegzést és darabszámot használunk hozzá. Itt az egy járatra jutó átlagos utasszámot keressük.

utasszamok = [72, 65, 91, 84, 78]
osszeg = 0

for utasszam in utasszamok:
    osszeg += utasszam

atlag = osszeg / len(utasszamok)
print(f"Átlagos utasszám: {atlag:.2f}")
Üres lista: osztás előtt ellenőrizni kell, hogy a lista tartalmaz-e elemet.

5. Eldöntés tétele

A kérdésre igen vagy nem a válasz: található-e legalább egy páros járatszám a listában?

jaratszamok = [3, 7, 11, 14, 19]
talalhato = False

for jarat in jaratszamok:
    if jarat % 2 == 0:
        talalhato = True
        break

if talalhato:
    print("Van páros járatszám a listában.")
else:
    print("Nincs páros járatszám a listában.")

A break azért használható, mert az első találat után már ismerjük a választ.

6. Lineáris keresés

Nemcsak azt szeretnénk tudni, hogy van-e találat, hanem a helyére vagy az adatára is szükségünk van.

megallok = ["Vasútállomás", "Iskola", "Főtér", "Uszoda"]
keresett = input("Melyik megállót keresed? ")
index = -1

for i in range(len(megallok)):
    if megallok[i].lower() == keresett.lower():
        index = i
        break

if index != -1:
    print(f"A megálló indexe: {index}")
else:
    print("A megálló nem található.")
Miért −1? A lista érvényes indexei 0-tól kezdődnek, ezért a −1 külön jelölheti, hogy nem találtunk megfelelő elemet.

7. Minimum- és maximumkiválasztás

A menetidőket percekben tároljuk. Feltételezzük, hogy a lista nem üres. Az első elemet tekintjük kezdetben a legkisebbnek vagy legnagyobbnak.

menetidok = [12, 9, 15, 7, 14]
minimum = menetidok[0]
maximum = menetidok[0]

for menetido in menetidok[1:]:
    if menetido < minimum:
        minimum = menetido
    if menetido > maximum:
        maximum = menetido

print(f"Minimum: {minimum} perc")
print(f"Maximum: {maximum} perc")

Ha a szélsőérték helye is kell, indexet tárolunk.

max_index = 0

for i in range(1, len(menetidok)):
    if menetidok[i] > menetidok[max_index]:
        max_index = i

print(f"A leghosszabb menetidő indexe: {max_index}")

8. Kiválasztás tétele

Biztosan tudjuk, hogy a 21-es járat szerepel a járatlistában, ezért a cél a helyének meghatározása.

jaratszamok = [8, 13, 21, 34, 55]
keresett = 21
i = 0

while jaratszamok[i] != keresett:
    i += 1

print(f"A keresett elem indexe: {i}")
Csak akkor használható biztonságosan, ha garantált, hogy a keresett elem valóban megtalálható a listában. Ellenkező esetben lineáris keresést használjunk.

9. Kiválogatás tétele

A páros járatszámokat új listába gyűjtjük; minden megfelelő elemet megtartunk.

jaratszamok = [4, 11, 8, 17, 20, 5]
parosak = []

for jarat in jaratszamok:
    if jarat % 2 == 0:
        parosak.append(jarat)

print(parosak)

Az eredeti lista nem változik meg.

10. Másolás tétele

Minden percben megadott menetidőt másodpercre váltunk, és az eredményeket új listában tároljuk.

menetidok_percben = [5, 10, 15, 20]
menetidok_masodpercben = []

for perc in menetidok_percben:
    menetidok_masodpercben.append(perc * 60)

print(menetidok_masodpercben)
Kiválogatásnál csak néhány elem kerül az új listába; másolásnál minden eredeti elemhez létrejön egy új elem.

11. Több tétel összekapcsolása

Egy valódi feladat gyakran több programozási tételt is igényel. Meghatározzuk a járatok átlagos és legnagyobb utasszámát, és kiválogatjuk a legalább 60 utast szállító járatok utasszámait.

utasszamok = [56, 82, 47, 91, 73, 88]
osszeg = 0
legalabb_hatvan_utas = []
maximum = utasszamok[0]

for utasszam in utasszamok:
    osszeg += utasszam

    if utasszam >= 60:
        legalabb_hatvan_utas.append(utasszam)

    if utasszam > maximum:
        maximum = utasszam

atlag = osszeg / len(utasszamok)

print(f"Átlag: {atlag:.2f}")
print(f"Legalább 60 utast szállító járatok utasszámai: {legalabb_hatvan_utas}")
print(f"Legnagyobb utasszám: {maximum}")

13. Gyakorlófeladatok

  1. Öt járat utasszámai: [12, 5, 9, 18, 6]. Határozd meg az összes szállított utas számát és a járatonkénti átlagot!
  2. Az indulások eltérései percekben: [3, -2, 7, -8, 0, -1]. A negatív érték korábbi, a pozitív későbbi, a 0 pontos indulást jelent. Számold meg a korábban induló járatokat!
  3. Az utasszámok: [23, 67, 104, 81, 99]. Döntsd el, volt-e 100-nál több utast szállító járat!
  4. Kérj be egy megállónevet, és keresd meg a ["Vasútállomás", "Iskola", "Főtér", "Uszoda"] listában! Kis- és nagybetűtől függetlenül keresd; írd ki az indexét vagy azt, hogy nincs benne!
  5. A menetidők percekben: [18, 4, 27, 9, 4, 15]. Határozd meg a legrövidebb menetidőt és első előfordulásának indexét!
  6. A késések percekben: [2, 5, 3, 4, 1, 5, 4]. Gyűjtsd új listába a legalább négyperces késéseket!
  7. A járatok menetideje percekben: [23, 32, 25, 21, 34, 26, 20]. Írd ki az átlagos, a legrövidebb és a leghosszabb menetidőt, valamint a 30 percnél hosszabb utak számát!
