3. Elágazások

Az elágazások segítségével a program feltételeket vizsgál, majd az eredménytől függően különböző utasításokat hajt végre.

Mit fogsz megtanulni?

  • logikai feltételek megfogalmazását,
  • az if, else és elif használatát,
  • számok és szövegek összehasonlítását,
  • összetett feltételek készítését az and, or és not operátorokkal,
  • hibás vagy nem megfelelő adatok felismerését.

1. Logikai értékek és feltételek

Egy feltétel eredménye kétféle lehet: igaz (True) vagy hamis (False).

print(8 > 5)    # True
print(8 == 5)   # False
print(8 != 5)   # True

Összehasonlító operátorok

OperátorJelentésPélda
==egyenlőa == 10
!=nem egyenlőa != 10
>nagyobba > 10
<kisebba < 10
>=nagyobb vagy egyenlőa >= 10
<=kisebb vagy egyenlőa <= 10
Az értékadás jele egy darab egyenlőségjel: =. Az összehasonlításhoz két egyenlőségjelet használunk: ==.

2. Egyszerű if elágazás

Az if utáni utasítás csak akkor fut le, ha a feltétel igaz.

eletkor = int(input("Add meg az életkorodat: "))

if eletkor >= 18:
    print("Nagykorú vagy.")

A behúzás kötelező: ez jelzi, mely utasítások tartoznak az elágazáshoz.

3. Kétirányú elágazás: if–else

Az else ága akkor fut le, ha az if feltétele hamis.

szam = int(input("Adj meg egy egész számot: "))

if szam % 2 == 0:
    print("A szám páros.")
else:
    print("A szám páratlan.")

4. Többirányú elágazás: elif

Az elif segítségével több feltételt vizsgálhatunk egymás után. Az első igaz ág utasításai futnak le.

szam = int(input("Adj meg egy számot: "))

if szam > 0:
    print("Pozitív szám.")
elif szam < 0:
    print("Negatív szám.")
else:
    print("A szám nulla.")

5. Példa – Szín kiválasztása

kod = int(input("Adj meg egy számot 1 és 4 között: "))

if kod == 1:
    print("Zöld")
elif kod == 2:
    print("Kék")
elif kod == 3:
    print("Vörös")
elif kod == 4:
    print("Fekete")
else:
    print("Nem megfelelő érték!")

6. Összetett feltételek

OperátorA feltétel akkor igaz, ha…
andmindkét részfeltétel igaz
orlegalább az egyik részfeltétel igaz
nota feltétel eredményének ellentéte igaz
 
pontszam = int(input("Add meg a pontszámot: "))

if pontszam >= 0 and pontszam <= 100:
    print("Érvényes pontszám.")
else:
    print("A pontszámnak 0 és 100 közé kell esnie.")

7. Példa – Osztályzat meghatározása

pontszam = int(input("Add meg az elért pontszámot: "))

if pontszam < 0 or pontszam > 100:
    print("Hibás pontszám!")
elif pontszam < 40:
    print("Elégtelen")
elif pontszam < 55:
    print("Elégséges")
elif pontszam < 70:
    print("Közepes")
elif pontszam < 85:
    print("Jó")
else:
    print("Jeles")
A feltételeket növekvő sorrendben vizsgáljuk. Ha például a pontszám 63, akkor a pontszam < 70 lesz az első igaz feltétel.

8. Példa – Két szám összehasonlítása

a = int(input("Az első szám: "))
b = int(input("A második szám: "))

if a > b:
    print(f"A nagyobb szám: {a}")
elif b > a:
    print(f"A nagyobb szám: {b}")
else:
    print("A két szám egyenlő.")

9. Egymásba ágyazott elágazások

Egy elágazáson belül újabb elágazást is létrehozhatunk, de ahol lehet, érdemes egyszerű összetett feltételt használni.

eletkor = int(input("Életkor: "))
van_jegy = input("Van jegyed? (i/n): ")

if eletkor >= 14:
    if van_jegy == "i":
        print("Beléphetsz.")
    else:
        print("Jegyet kell vásárolnod.")
else:
    print("Csak 14 éves kortól látogatható.")

10. Gyakorlófeladatok

1. Szó hossza

Kérj be egy szót, majd írd ki, hogy hosszabb-e 5 karakternél!

2. Oszthatóság

Kérj be egy egész számot, majd írd ki, hogy osztható-e 3-mal és 5-tel egyszerre!

3. Legnagyobb szám

Kérj be három számot, és írd ki közülük a legnagyobbat! Elsőként próbáld meg a beépített max() függvény nélkül.

4. Kedvezmény

Kérd be egy vásárlás összegét! 20 000 Ft-tól 10%, 50 000 Ft-tól 20% kedvezmény jár. Írd ki a fizetendő összeget!

5. Dátum ellenőrzése – kihívás

Kérj be egy hónapszámot és egy napot! Írd ki, hogy a megadott dátum lehetséges-e! A szökőévet egyelőre nem kell kezelni.

11. Lehetséges megoldások

1–2. feladat megoldása

Szó hossza

szo = input("Adj meg egy szót: ")

if len(szo) > 5:
    print("A szó hosszabb 5 karakternél.")
else:
    print("A szó legfeljebb 5 karakter hosszú.")

Oszthatóság

szam = int(input("Adj meg egy egész számot: "))

if szam % 3 == 0 and szam % 5 == 0:
    print("A szám 3-mal és 5-tel is osztható.")
else:
    print("A szám nem osztható mindkettővel.")
3–4. feladat megoldása

Legnagyobb szám

a = int(input("Első szám: "))
b = int(input("Második szám: "))
c = int(input("Harmadik szám: "))

legnagyobb = a
if b > legnagyobb:
    legnagyobb = b
if c > legnagyobb:
    legnagyobb = c

print(f"A legnagyobb szám: {legnagyobb}")

Kedvezmény

osszeg = int(input("A vásárlás összege: "))

if osszeg >= 50000:
    fizetendo = osszeg * 0.8
elif osszeg >= 20000:
    fizetendo = osszeg * 0.9
else:
    fizetendo = osszeg

print(f"Fizetendő: {fizetendo:.0f} Ft")
5. Dátumellenőrzés megoldása 
honap = int(input("Hónap: "))
nap = int(input("Nap: "))

ervenyes = False

if honap in (1, 3, 5, 7, 8, 10, 12) and 1 <= nap <= 31:
    ervenyes = True
elif honap in (4, 6, 9, 11) and 1 <= nap <= 30:
    ervenyes = True
elif honap == 2 and 1 <= nap <= 28:
    ervenyes = True

if ervenyes:
    print("A dátum lehetséges.")
else:
    print("A dátum nem lehetséges.")
Összefoglalás: már tudsz feltételeket vizsgálni, két- vagy többirányú döntéseket készíteni, összetett feltételeket megfogalmazni és hibás adatokat felismerni.
