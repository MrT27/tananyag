9. Függvények

A függvényekkel a programot kisebb, áttekinthető és többször felhasználható részekre bontjuk.

Mit fogsz megtanulni?

  • függvényt létrehozni és meghívni,
  • paramétereket átadni,
  • eredményt visszaadni a return utasítással,
  • különbséget tenni kiíró és értéket visszaadó függvény között,
  • listákat feldolgozó függvényeket készíteni,
  • egy nagyobb programot kisebb feladatokra bontani.

1. Miért használunk függvényeket?

Ha ugyanazt a műveletet többször kell elvégezni, nem célszerű minden alkalommal újra leírni a kódot. A függvény egy névvel ellátott programrész, amelyet szükség szerint meghívhatunk.

Előnyök: rövidebb program, kevesebb ismétlés, könnyebb javítás és áttekinthetőbb felépítés.

2. Egyszerű függvény létrehozása

A függvényt a def kulcsszóval hozzuk létre. A függvény törzsét behúzással jelöljük.

def koszones():
    print("Üdvözöllek a Python tananyagban!")

koszones()
koszones()
Fontos: a függvény létrehozása még nem hajtja végre a benne lévő utasításokat. Ehhez meg kell hívni a függvényt.

3. Paraméterek

A paraméter segítségével adatot adhatunk át a függvénynek.

def koszones(nev):
    print(f"Szia, {nev}!")

koszones("Anna")
koszones("Béla")

A nev a függvény paramétere, az "Anna" és "Béla" pedig a híváskor átadott argumentum.

4. Több paraméter

def teglalap_adatai(a, b):
    kerulet = 2 * (a + b)
    terulet = a * b
    print(f"Kerület: {kerulet}")
    print(f"Terület: {terulet}")

teglalap_adatai(5, 3)
A paraméterek sorrendje számít. A híváskor megadott első érték az első paraméterhez kerül.

5. Visszatérési érték: return

A függvény nemcsak kiírhat valamit, hanem eredményt is visszaadhat. A visszaadott értéket változóban tárolhatjuk vagy további számításban használhatjuk.

def negyzet(szam):
    return szam * szam

eredmeny = negyzet(6)
print(eredmeny)
print(negyzet(10) + 5)
Gyakori hiba: a print() csak kiír, a return viszont visszaad egy értéket a függvény hívásának helyére.

6. Kiíró és értéket visszaadó függvény

Kiíró függvény

def duplaz_kiir(szam):
    print(szam * 2)

Értéket visszaadó függvény

def duplaz(szam):
    return szam * 2

Általában a visszatérési értéket használó megoldás rugalmasabb, mert az eredménnyel a függvényen kívül is dolgozhatunk.

7. Logikai értéket visszaadó függvény

Az elágazások feltételét külön függvénybe is szervezhetjük.

def paros_e(szam):
    return szam % 2 == 0

szam = int(input("Adj meg egy egész számot: "))

if paros_e(szam):
    print("A szám páros.")
else:
    print("A szám páratlan.")

8. Helyi változók

A függvényben létrehozott változó általában csak a függvényen belül használható.

def kor_terulet(sugar):
    pi = 3.14159
    terulet = pi * sugar ** 2
    return terulet

print(kor_terulet(4))
A terulet változóra a függvényen kívül nem hivatkozhatunk közvetlenül. Az értékét a return segítségével adjuk vissza.

9. Lista átadása függvénynek

A korábban megismert programozási tételeket függvényekbe szervezhetjük.

def lista_osszege(szamok):
    osszeg = 0

    for szam in szamok:
        osszeg += szam

    return osszeg

adatok = [4, 8, 3, 12]
print(lista_osszege(adatok))

10. Feltételes megszámlálás függvényben

def pozitivak_szama(szamok):
    darab = 0

    for szam in szamok:
        if szam > 0:
            darab += 1

    return darab

adatok = [-3, 5, 0, 8, -1, 4]
print(f"Pozitív számok: {pozitivak_szama(adatok)}")

11. Új listát visszaadó függvény

def parosak_kivalogatasa(szamok):
    parosak = []

    for szam in szamok:
        if szam % 2 == 0:
            parosak.append(szam)

    return parosak

adatok = [3, 8, 11, 14, 20, 5]
print(parosak_kivalogatasa(adatok))
A függvény bemenete egy lista, a kimenete pedig egy új lista. Az eredeti lista nem változik meg.

12. Alapértelmezett paraméter

def koszones(nev, napszak="napot"):
    print(f"Jó {napszak}, {nev}!")

koszones("Anna")
koszones("Béla", "reggelt")

Az alapértelmezett értékkel rendelkező paramétert nem kötelező minden híváskor megadni.

13. Egy program felbontása függvényekre

def beker_pozitiv_szam():
    szam = int(input("Adj meg egy pozitív egész számot: "))

    while szam <= 0:
        szam = int(input("Hibás adat. Adj meg pozitív számot: "))

    return szam


def osztok_szama(szam):
    darab = 0

    for oszto in range(1, szam + 1):
        if szam % oszto == 0:
            darab += 1

    return darab


szam = beker_pozitiv_szam()
print(f"A szám osztóinak száma: {osztok_szama(szam)}")

A főprogram rövid és jól olvasható marad, a részfeladatok pedig külön függvényekbe kerülnek.

14. Gyakori hibák

  • A függvény meghívásának elfelejtése.
  • A return és a print() összekeverése.
  • Nem megfelelő számú argumentum átadása.
  • A return utáni utasítások végrehajtásának várása.
  • A függvényen belüli helyi változó használata a függvényen kívül.

15. Gyakorlófeladatok

  1. Készíts koszon nevű függvényt, amely paraméterként kap egy nevet, és személyre szabott üzenetet ír ki!
  2. Készíts függvényt, amely visszaadja egy téglalap kerületét!
  3. Készíts pozitiv_e nevű függvényt, amely logikai értékkel jelzi, hogy a kapott szám pozitív-e!
  4. Készíts függvényt, amely visszaadja egy számlista átlagát! Üres lista esetén adjon vissza None értéket!
  5. Készíts függvényt, amely megszámolja egy szövegben a magánhangzókat!
  6. Készíts függvényt, amely egy listából új listába gyűjti a megadott határnál nagyobb számokat!
  7. Bonts függvényekre egy programot, amely öt jegyet kér be, kiszámítja az átlagot, majd szövegesen értékeli az eredményt!

def jegyek_bekerese():
    jegyek = []

    for i in range(5):
        jegy = int(input(f"{i + 1}. jegy: "))
        jegyek.append(jegy)

    return jegyek


def lista_atlaga(szamok):
    osszeg = 0

    for szam in szamok:
        osszeg += szam

    return osszeg / len(szamok)


def ertekeles(atlag):
    if atlag >= 4.5:
        return "kiváló"
    elif atlag >= 3.5:
        return "jó"
    elif atlag >= 2.5:
        return "közepes"
    elif atlag >= 2:
        return "elégséges"
    else:
        return "elégtelen"


jegyek = jegyek_bekerese()
atlag = lista_atlaga(jegyek)
print(f"Átlag: {atlag:.2f}")
print(f"Értékelés: {ertekeles(atlag)}")
