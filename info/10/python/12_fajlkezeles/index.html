12. Fájlkezelés

Adatok beolvasása szövegfájlból, feldolgozása, majd az eredmények mentése.

Mit fogsz megtanulni?

  • szövegfájlt biztonságosan megnyitni a with open() szerkezettel,
  • a fájl sorait bejárni és megtisztítani,
  • tagolt adatokat listára bontani és megfelelő típusra alakítani,
  • a beolvasott rekordokat szótárak listájában tárolni,
  • eredményeket új fájlba írni.

1. Fájl megnyitása és beolvasása

A fájlt célszerű ugyanabba a mappába menteni, ahol a Python-program található.

with open("nevek.txt", "r", encoding="UTF-8") as bemenet:
    for sor in bemenet:
        print(sor)

Az r olvasási módot jelent. A with blokk végén a Python automatikusan bezárja a fájlt.

2. Sorvégi karakter eltávolítása

nevek = []

with open("nevek.txt", "r", encoding="UTF-8") as bemenet:
    for sor in bemenet:
        nevek.append(sor.strip())

print(nevek)
Fontos: a strip() eltávolítja a sorvégi sortörést és a felesleges szóközöket.

3. Tagolt adatok feldolgozása

A saját feladataidban gyakran pontosvessző választja el az egy sorhoz tartozó adatokat.

# ceg.txt egyik sora:
# Anna;szakértő;520000;2014

dolgozok = []

with open("ceg.txt", "r", encoding="UTF-8") as bemenet:
    for sor in bemenet:
        adatok = sor.strip().split(";")
        dolgozo = {
            "nev": adatok[0],
            "pozicio": adatok[1],
            "fizetes": int(adatok[2]),
            "kezdes_eve": int(adatok[3])
        }
        dolgozok.append(dolgozo)

A fájlból minden adat szövegként érkezik, ezért a számokat int() vagy float() segítségével át kell alakítani.

4. A beolvasott adatok feldolgozása

print(f"{len(dolgozok)} dolgozó van a listában.")

fizikai_darab = 0
fizetes_osszesen = 0

for dolgozo in dolgozok:
    if dolgozo["pozicio"] == "fizikai":
        fizikai_darab += 1
    fizetes_osszesen += dolgozo["fizetes"]

print(f"Fizikai dolgozók: {fizikai_darab} fő")
print(f"Havi fizetés összesen: {fizetes_osszesen:,} Ft")

Itt már a korábban tanult megszámlálást és összegzést alkalmazzuk fájlból érkező adatokon.

5. Keresés és szélsőérték fájlból beolvasott adatokban

talalat = False
for dolgozo in dolgozok:
    if dolgozo["pozicio"] == "szakértő":
        talalat = True
        break

print("Van szakértő." if talalat else "Nincs szakértő.")

max_index = 0
for i in range(1, len(dolgozok)):
    if dolgozok[i]["fizetes"] > dolgozok[max_index]["fizetes"]:
        max_index = i

print(f"A legtöbbet {dolgozok[max_index]['nev']} keresi.")

6. Fájlba írás

with open("eredmeny.txt", "w", encoding="UTF-8") as kimenet:
    print("A 2010 után belépett fizikai dolgozók:", file=kimenet)

    for dolgozo in dolgozok:
        if dolgozo["kezdes_eve"] > 2010 and dolgozo["pozicio"] == "fizikai":
            print(dolgozo["nev"], file=kimenet)

A w új fájlt készít, vagy felülírja a meglévőt. A print(..., file=kimenet) a képernyő helyett a fájlba ír.

7. Írási módok

MódJelentés
rMeglévő fájl olvasása.
wÚj fájl írása; a korábbi tartalmat felülírja.
aÚj tartalom hozzáfűzése a fájl végéhez.
xÚj fájl létrehozása; hibát ad, ha már létezik.

8. Teljes példa: autóflotta

autok = []

with open("autok.txt", "r", encoding="UTF-8") as bemenet:
    for sor in bemenet:
        adatok = sor.strip().split(";")
        auto = {
            "szin": adatok[0],
            "marka": adatok[1],
            "futott_km": int(adatok[2]),
            "szerviz_napok": int(adatok[3])
        }
        autok.append(auto)

ford_km = 0
markak = []

for auto in autok:
    if auto["marka"] == "Ford":
        ford_km += auto["futott_km"]
    if auto["marka"] not in markak:
        markak.append(auto["marka"])

print(f"A flottában {len(autok)} autó van.")
print(f"A Fordok összesen {ford_km:,} km-t futottak.")

with open("markak.txt", "w", encoding="UTF-8") as kimenet:
    for marka in markak:
        print(marka, file=kimenet)

A témakörhöz tartozó adatfájlok

Töltsd le a feladathoz szükséges fájlt, majd másold ugyanabba a mappába, ahol a Python-programod található.

nevek.txt – soronként egy név szamok.txt – soronként egy egész szám termekek.txt – név;ár;készlet ceg.txt – név;pozíció;fizetés;kezdés éve autok.txt – szín;márka;futott kilométer;szerviznapok idezet.txt – soronként egy idézet README.txt – fájlformátumok és használati útmutató
Tipp: a fájlneveket ne változtasd meg, mert a mintaprogramok ezeket a neveket használják.

Gyakorlófeladatok

  1. Olvasd be egy szamok.txt fájl egész számait, majd írd ki az összegüket és átlagukat!
  2. Olvasd be a nevek.txt fájlt, és írd ki az öt karakternél hosszabb neveket!
  3. Egy termekek.txt fájl sorai: név;ár;készlet. Határozd meg a legdrágább terméket!
  4. A ceg.txt alapján írd ki fájlba a 400 000 Ft-nál többet keresők nevét!
  5. Az autok.txt adataiból számold meg márkánként az autókat!
  6. Olvass be idézeteket, fordítsd meg minden sor karaktereit, és mentsd őket új fájlba!
