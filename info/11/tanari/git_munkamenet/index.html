Tanári GitHub munkamenet

A kod-magazin-tanari projekt biztonságos kezelése több tanteremben.

Cél: óra elején mindig a legfrissebb állapotból indulni, óra végén pedig feltölteni azt, ameddig az adott csoporttal eljutottál.

A két rutin, amit ténylegesen meg kell jegyezni

Óra elején

git status
git pull

Ellenőrzés, majd a GitHubon lévő legfrissebb állapot letöltése.

Óra végén

git status
git add .
git status
git commit -m "CSS 6. óra - aktuális állapot"
git push

Ellenőrzés, mentés a Git történetébe, majd feltöltés GitHubra.

1. A rendszer logikája

A GitHub repository a tanári projekt központi példánya. Minden tanteremben ugyanazt a repositoryt használod.

HelyFeladatFő parancs
Saját gépAnyag előkészítése és módosításagit pull / git push
1. tanteremAz ottani óra folytatásagit pull / git push
2. tanteremUgyanonnan folytatásgit pull / git push
Diák gépTanári állapot letöltésegit clone / git pull
Lényeg: mielőtt egy gépen dolgozni kezdesz, git pull; mielőtt otthagyod a gépet, git push.

2. Első alkalom egy tanári gépen

Ha a gépen még nincs meg a projekt, VS Code-ban jelentkezz be az ungitamas GitHub-fiókba. Ezután a terminálban klónozd a publikus repót:

git clone https://github.com/ungitamas/kod-magazin-tanari.git
cd kod-magazin-tanari
code .

A klónozás után ellenőrizd:

git status
git remote -v

A remote -v kimenetében a ungitamas/kod-magazin-tanari repositorynak kell szerepelnie.

3. Óra eleji ellenőrzés

Nyisd meg a projekt mappáját VS Code-ban, majd:

git status

Az ideális állapot:

On branch main
Your branch is up to date with 'origin/main'.

nothing to commit, working tree clean

Ezután:

git pull
Ha a git status módosított fájlokat jelez még az óra megkezdése előtt, ne fusson automatikusan a git pull. Előbb nézd meg, mi maradt a gépen az előző alkalomról.

4. Óra közben

Git szempontból nincs külön teendő. Dolgozz a HTML- és CSS-fájlokon, és mentsd őket a megszokott módon.

Cmd + S   # macOS
Ctrl + S  # Windows / Linux

Óra közben nem szükséges minden apró változtatást commitolni. A tanórai állapotot elég az óra végén elmenteni.

5. Óra végi mentés és feltöltés

1. Nézd meg, mi változott

git status

2. Készítsd elő a módosításokat

git add .

3. Ellenőrizd még egyszer

git status

4. Készíts commitot

git commit -m "CSS 6. óra - prioritás"

5. Töltsd fel

git push
Ha a git push sikeres, a következő tanteremben egy git pull után ugyanebből az állapotból tudsz tovább dolgozni.

6. Jó commitüzenetek órán

A commitüzenetből később legyen egyértelmű, hol tartottál.

git commit -m "CSS 6. óra - prioritás"
git commit -m "11.A - cikk fejléc kész"
git commit -m "11.B - linkek formázása"
git commit -m "Kód magazin - aktuális állapot"

7. A CSS 6. óra példája

A jelenlegi 11. évfolyamos anyagban a CSS 6. óra témája az ütköző CSS-szabályok és a prioritás. Az órai munkamenet így nézhet ki:

  1. git status, majd git pull;
  2. nyisd meg a 11/css/6_ora/ anyagot;
  3. mutasd be a szelektorok prioritását és a DevTools Styles paneljét;
  4. a pelda/ projektben kapcsold ki egymás után a szabályokat;
  5. az óra végén ellenőrzés, commit és push.

8. Gyors hibakezelés

HelyzetMit tegyél?
Nem tudod, melyik repóban vagy.pwd, majd git remote -v
Nem tudod, maradt-e módosítás.git status
A git commit azt írja, nincs mit commitolni.Valószínűleg nincs változás, vagy előtte kimaradt a git add ..
A git push hitelesítést kér.Ellenőrizd, hogy VS Code-ban a megfelelő GitHub-fiókkal vagy-e belépve.
A git pull konfliktust jelez.Ne írj felül semmit vaktában. Előbb git status, és nézd meg az érintett fájlokat.
Ne használd rutinból: git reset --hard, git clean -fd vagy git push --force. Ezekkel könnyű munkát elveszíteni.

9. Ha több csoport különböző tempóban halad

Ha a csoportok ugyanazon a projekten dolgoznak, de más állapotig jutnak, a commitüzenetben jelöld a csoportot. Így a Git történetben később is látod, melyik állapot melyik órához tartozott.

git commit -m "11.A - CSS prioritás kész"
git commit -m "11.B - DevTools példa kész"

Ha később szükség lesz teljesen külön ágakra, azt külön lépésként érdemes bevezetni; az alap munkamenethez egyelőre a main ág is elég.
