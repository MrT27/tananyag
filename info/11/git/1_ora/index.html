Git 11. évfolyam 1. óra

Git alapok – helyi verziókövetés

Megtanuljuk, hogyan követhetjük egy projekt változásait, és hogyan készíthetünk visszakereshető pillanatképeket a kód különböző állapotairól.

1. Mi az a Git?

A Git egy verziókövető rendszer. Segítségével nyomon követhetjük, hogyan változik egy projekt az idő során.

Ha eljutunk egy olyan állapothoz, amellyel elégedettek vagyunk, készíthetünk róla egy pillanatképet. Ezt a Gitben commitnak nevezzük.

A Git nem ugyanaz, mint a GitHub. Ezen az órán még csak a saját gépünkön dolgozunk.

2. Ellenőrizzük, hogy működik-e a Git

Nyiss terminált, majd írd be:

git

Ha a Git súgója vagy parancslistája jelenik meg, akkor a Git telepítve van.

3. Projektmappa megnyitása a terminálban

Tegyük fel, hogy van egy ilyen projektünk:

git-gyakorlat/
└── index.html

A terminálban lépjünk be a mappába:

cd git-gyakorlat
A Git-parancsokat mindig abban a projektmappában adjuk ki, amelyen dolgozni szeretnénk.

4. Git repository létrehozása

git init

Ezzel Git repositoryvá alakítjuk a projektmappát. A háttérben létrejön egy rejtett .git mappa.

A .git mappát nem szerkesztjük kézzel. Ebben tárolja a Git a verziókövetéshez szükséges adatokat.

5. Első fájl hozzáadása

A Git nem készít automatikusan pillanatképet minden fájlról. Először meg kell mondanunk, melyik fájlt szeretnénk a következő commitba tenni. 

git add index.html

Ezzel az index.html fájlt előkészítettük a következő commithoz.

6. Első commit

git commit -m "Első verzió"

A commit egy pillanatkép a projekt egy adott állapotáról.

  • git commit – elkészíti a pillanatképet;
  • -m – commitüzenetet adunk meg;
  • "Első verzió" – röviden leírjuk, mit tartalmaz ez az állapot.
A commitüzenet legyen rövid, de mondja el, mi változott.

7. Készítsünk második verziót

Módosítsd az index.html fájlt, például adj hozzá egy új bekezdést. Mentsd el a fájlt, majd: 

git add index.html
git commit -m "Bekezdés hozzáadása"

A projektnek most már két külön eltárolt állapota van.

8. Commitok megtekintése

git log

A git log megmutatja a projekt commitelőzményeit. Láthatjuk többek között a commitok azonosítóját és az üzenetüket.

Ezen az órán még nem lépkedünk vissza korábbi commitokra. Most az a fontos, hogy megértsük: minden commit egy eltárolt projektállapot.

10. Közös órai feladat

  1. Készíts git-gyakorlat nevű mappát.
  2. Hozz létre benne egy egyszerű index.html fájlt.
  3. Nyisd meg a projektmappát terminálban.
  4. Inicializáld a repositoryt git init paranccsal.
  5. Add hozzá az index.html fájlt.
  6. Készíts commitot Első verzió üzenettel.
  7. Módosítsd az oldalt egy új bekezdéssel.
  8. Mentsd el a fájlt.
  9. Add hozzá újra a fájlt.
  10. Készíts új commitot Bekezdés hozzáadása üzenettel.
  11. A git log segítségével nézd meg mindkét commitot.
