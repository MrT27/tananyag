Közös munka GitHubon – Collaborator

Ketten dolgozunk ugyanazon a repositoryn: meghívás, clone, pull, commit és push.

1. Hogyan dolgozhat két ember ugyanazon a projekten?

A repository tulajdonosa hozzáadhat egy másik GitHub-felhasználót Collaboratorként. Ezután mindketten dolgozhatnak ugyanazon a repositoryn, és feltölthetik a saját commitjaikat.

A közös pont a GitHub. Nem egymásnak küldözgetjük a fájlokat. Mindkét fejlesztő a saját gépén dolgozik, a változásokat pedig a közös repositoryn keresztül adják át egymásnak.

2. Collaborator meghívása

A páros egyik tagja hozza létre a repositoryt. Ezután a repository beállításainál hívja meg a társát Collaboratorként.

  1. Nyisd meg a repositoryt GitHubon.
  2. Nyisd meg a Settings menüt.
  3. Keresd meg a Collaborators / hozzáférések kezelésére szolgáló részt.
  4. Add hozzá a párod GitHub-felhasználónevét.
  5. A meghívott tanuló fogadja el a meghívást.
A meghívás elfogadása után a társad már jogosultságot kaphat arra, hogy a közös repositoryba pusholjon.

3. Mindketten klónozzátok a repositoryt

Mindkét tanuló a saját gépére klónozza ugyanazt a repositoryt:

git clone https://github.com/felhasznalo/repo.git
cd repo
code .

Innentől mindkét gépen van egy helyi munkapéldány, amelyek ugyanahhoz a GitHub repositoryhoz kapcsolódnak.

4. A közös munka alapszabálya

MUNKA ELŐTT: PULL    •    MUNKA UTÁN: PUSH

Mielőtt módosítasz valamit, töltsd le a társad legfrissebb változtatásait:

git pull

Dolgozz a VS Code-ban, majd:

git status
git add .
git commit -m "értelmes commit üzenet"
git push

5. Munkamegosztás

A tanuló – HTML

Elsősorban az index.html szerkezetén dolgozik: címsorok, szövegek, lista, kép, link és a CSS bekötése.

B tanuló – CSS

Elsősorban a style.css fájlon dolgozik: háttér, betűk, címsorok, kép, class szelektorok és az oldal megjelenése.

A felosztás segít abban, hogy az első közös munkánál ne ugyanazt a fájlrészletet módosítsátok egyszerre.

Páros feladat – Közös weboldal

Dolgozzatok 2 fős csapatokban, és készítsetek közösen egy egyszerű, formázott weboldalt. A témát ti választhatjátok meg.

Repository

  • Az egyik tanuló hozzon létre egy GitHub repositoryt.
  • Hívja meg a párját Collaboratorként.
  • A másik tanuló fogadja el a meghívást.
  • Mindketten klónozzátok le ugyanazt a repositoryt.

A weboldal tartalma

  • index.html megfelelő HTML-alapszerkezettel
  • címsor és több bekezdés
  • felsorolás
  • legalább egy kép
  • legalább egy hivatkozás
  • bekötött style.css
  • háttér és szövegformázás
  • címsorok formázása
  • kép formázása
  • legalább egy class szelektor használata

Git/GitHub követelmények

  • Legyen legalább 5 commit a repositoryban.
  • Mindkét tanulótól legyen legalább 2 saját commit.
  • A commitüzenetekből derüljön ki, mi változott.
  • A munka során használjátok a git pull és git push parancsokat.
  • Ne küldjétek egymásnak külön a HTML- vagy CSS-fájlokat: a változások GitHubon keresztül kerüljenek át a másik gépére.

7. Beadás

A feladat végén a GitHub repository linkjét kell elküldeni.

  • Mindkét tanuló neve szerepeljen a beadásban.
  • Nem ZIP-fájlt kérünk.
  • Nem külön HTML- és CSS-fájlt kérünk.
  • A repositoryban legyen látható a kész projekt és a commitok története.
Következő lépés: mi történik akkor, ha mindketten ugyanazt a fájlt – akár ugyanazt a sort – módosítjátok? A következő részben szándékosan előidézünk egy ütközést, és eljutunk a merge conflicthoz.
