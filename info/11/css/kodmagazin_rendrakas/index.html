11. évfolyam Rendrakás / összefoglalás 13–14. óra között

Kód Magazin – rendrakás a Flexbox előtt

A CSS-alapok végére értünk. Mielőtt belevágunk a Flexboxba, megtisztítjuk és egységesítjük a több órán keresztül épített Kód Magazin projektet.

Számozatlan összefoglaló óra. Nincs hozzá külön Jonas-videó. Csak olyan megoldásokat használunk, amelyeket a 13. óráig már megtanultunk: szelektorok, öröklődés, dobozmodell, térközök, konténer, block/inline, abszolút pozicionálás és box-sizing.

Miért pont most?

A projektet sok külön órán módosítottuk. Ez természetes, de közben maradtak benne demonstrációs szabályok, túl általános szelektorok és olyan részek, amelyek működnek ugyan, de már nem elég áttekinthetők.

A következő órától Flexboxot tanulunk. Ahhoz jó kiindulópont kell: világos HTML-szerkezet, beszédes classok és rendezett CSS.

Cél: ne új technikát tanuljunk, hanem az eddigi tudásunkkal tegyük rendbe a projektet.

0. Kiinduló állapot

A kezdőcsomag az eddig felépített Kód Magazin. Nem nulláról indulunk, hanem meglévő kódot olvasunk, értékelünk és javítunk.

0.1. A jelenlegi style.css egyben

Mielőtt elkezdjük a rendrakást, nézzük meg egyben azt a CSS-t, amely az eddigi órák során kialakult. A korábbi magyarázó és kikommentelt próbakódokat innen kiszedtem, így csak az aktív szabályok látszanak. Pontosan ebből fogjuk eldönteni, mi maradjon, mit nevezzünk át, és mit töröljünk.

Fontos: ez még nem a rendezett megoldás. Szándékosan benne vannak olyan korábbi demonstrációk is, mint a li:first-child, az article p:first-child, a body { position: relative; } vagy a h2::before. Ezeket az óra során fogjuk átnézni.

1. HTML-szerkezet ellenőrzése

Elv: először a HTML legyen logikus. CSS-sel ne próbáljunk rossz szerkezetet elfedni.

1.1. Az aside az article testvére legyen

<article>
  ...
</article>

<aside>
  ...
</aside>

A kapcsolódó bejegyzések kiegészítő tartalmat jelentenek. Ez ráadásul jó alap lesz ahhoz, hogy később az article és az aside egymás mellé kerülhessen.

2. Beszédes classok a fontos elemeknek

Ahol egy elemnek külön szerepe van, ne hosszú és törékeny szelektorokkal célozzuk meg.

<img class="author-img" ...>
<p class="author">...</p>

<ul class="related">
  ...
  <p class="related-author">...</p>
</ul>

<button class="like-btn" type="button">❤️ Like</button>

Ezek a nevek rögtön elmondják, hogy az adott elem milyen szerepet tölt be.

3. Korábbi demonstrációk kiszedése

Tanulás közben hasznosak voltak, de a rendezett projektben már csak zajt okoznak:

ol li:nth-child(even) {
  color: red;
}

article p:first-child {
  font-weight: bold;
}

article header p {
  font-style: italic;
}

header p {
  font-style: italic;
}

A szerző bekezdését inkább a .author class formázza.

Rendrakási szabály: ami csak egy korábbi bemutató kedvéért van a CSS-ben, de a kész oldalnak nincs rá szüksége, azt töröljük.

4. Alapbeállítások egységesítése

* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

body {
  color: #444;
  font-family: sans-serif;
  border-top: 10px solid #1098ad;
}
  • A box-sizing: border-box most már bekerül a globális alapbeállításba.
  • A font-family a body-n van, mert öröklődik.
  • Nem írjuk ki ugyanazt öt külön elemhez.

5. A konténer marad a már tanult formában

.container {
  width: 800px;
  margin: 0 auto;
}

Ebben a rendrakási órában még nem használunk max-width-et és rem-et, mert azok csak jóval később következnek. Most a 10. órán megtanult középre igazított konténert tartjuk meg.

}

7. Navigáció és linkek

A már megtanult linkállapotokat megtartjuk. A navigációs linkek azonban kapjanak külön térközt:

nav {
  font-size: 18px;
}

nav a:link {
  display: inline-block;
  margin-top: 10px;
  margin-right: 30px;
}

nav a:link:last-child {
  margin-right: 0;
}

Itt az inline-block is visszaköszön a 11. órából.

9. Like gomb – az abszolút pozicionálás rendes használata

A gomb a cikk fejlécéhez tartozik, ezért a .post-header legyen a viszonyítási alap:

.post-header {
  position: relative;
  margin-bottom: 40px;
}

.like-btn {
  position: absolute;
  right: 50px;
  bottom: 50px;
}
Miért nem kell a body-ra vagy a .container-re position: relative? Mert a Like gombot a .post-header-hez akarjuk igazítani. Az abszolút elem a legközelebbi pozicionált őshöz igazodik.

11. Mit nem használunk még?

  • nincs Flexbox;
  • nincs Grid;
  • nincs rem;
  • nincs max-width;
  • nincs media query;
  • nincs ::before/::after díszítés.

Így a projekt pontosan az eddig megtanult CSS-alapokra épül. Innen tisztán indulhat a 14. óra, a Flexbox.

12. Órai rendrakási ellenőrzőlista

  1. Az aside az article után, testvérként áll.
  2. Az ol és az MDN-link megvan.
  3. Az elírás javítva.

  11. A kapcsolódó lista nem mutat bulletpontokat.
