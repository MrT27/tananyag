11. évfolyam 40. óra Tanári segédlet

Hat európai úti cél – megoldás lépésről lépésre

A kezdőcsomagtól a teljes, három törésponttal működő megoldásig.

Szükséges fájlok

A segédlet a két végleges csomaghoz készült.

Kezdőcsomag Tanári megoldás
Javasolt használat: bontsd ki a kezdőcsomagot egy külön gyakorlómappába, és a lenti lépéseket azon végezd el. A megoldáscsomagot csak ellenőrzéshez használd.

Megoldási sorrend

  1. Favicon és szemantikus HTML-szerkezet.
  2. Globális alapbeállítások és a body formázása.
  3. Közös konténer kialakítása.
  4. Fejléc és navigáció Flexboxszal.
  5. A hat kártya elrendezése Griddel.
  6. Kártyák, képek és szövegek formázása.
  7. A 75rem, 59rem és 34rem töréspontok.
  8. Ellenőrzés DevToolsban.

1. Favicon bekötése

Az index.html fájl head részében a megjegyzés helyére kerüljön:

<link rel="icon" href="img/favicon-96x96.png?v=2" type="image/png">
Ellenőrzés: frissítés után a böngészőfülön megjelenik az ikon. Ha nem, használj erőltetett frissítést: Cmd + Shift + R vagy Ctrl + Shift + R.

2. Szemantikus HTML-szerkezet

A tartalom nem változik, csak a jelentés nélküli div elemeket cseréljük szemantikus elemekre.

Kezdő elemHelyes elem
<div class="fejlec"><header>
<div class="navigacio"><nav>
<div class="uti-celok"><main>
<div class="kartya"><article class="kartya">
<div class="lablec"><footer>

Az első kártya helyes szerkezete:

<article id="parizs" class="kartya">
  <img src="img/parizs.jpg" alt="Az Eiffel-torony Párizsban">
  <h2>Párizs</h2>
  <p class="orszag">Franciaország</p>
  <p>A fények városa híres az Eiffel-toronyról, hangulatos utcáiról és világhírű múzeumairól.</p>
</article>
Tipikus hiba: a nyitó div átírása után a záró </div> változatlan marad. Mindig a nyitó és a záró taget is cserélni kell.

3. Globális alapbeállítások

A style.css elejére írjuk:

* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

Ez eltávolítja a böngésző alapértelmezett térközeit, a border-box pedig kiszámíthatóvá teszi a méretezést.

4. A body alapformázása

body {
  color: #263238;
  background-color: #eef3f7;
  font-family: Arial, sans-serif;
  line-height: 1.6;
}
Látható eredmény: az oldal világoskékes hátteret, sötét szöveget és egységes Arial betűtípust kap.

5. Közös konténer

A fejléc, a fő tartalom és a lábléc azonos szélességű, középre igazított konténert kap:

header,
main,
footer {
  max-width: 1200px;
  margin: 0 auto;
  padding: 32px;
}

max-width mellett a konténer keskenyebb lehet, de 1200 pixelnél nem nő nagyobbra. A margin: 0 auto középre igazítja.

6. Fejléc Flexboxszal

header {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 24px;
  color: #ffffff;
  background-color: #234e70;
}

h1 {
  font-size: 36px;
}
  • display: flex: egymás mellé rendezi a címet és a navigációt.
  • justify-content: space-between: a két elem a fejléc két oldalára kerül.
  • align-items: center: függőlegesen középre igazít.
  • gap: megakadályozza, hogy szűkebb helyen összeérjenek.

7. Navigáció Flexboxszal

nav {
  display: flex;
  gap: 24px;
}

nav a {
  color: #ffffff;
  font-weight: bold;
  text-decoration: none;
}

nav a:hover {
  text-decoration: underline;
}
Ellenőrzés: a hat városnév vízszintesen, egyenletes térközzel jelenik meg. A linkre mutatva aláhúzás látható.

8. Háromoszlopos Grid

main {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 28px;
}

A hat kártya három egyforma oszlopban, két sorban jelenik meg. Az 1fr azt jelenti, hogy mindhárom oszlop ugyanakkora részt kap.

Tipikus hiba: ha a Grid-szabály a .kartya elemre kerül a main helyett, a kártyák nem rendeződnek oszlopokba. A Gridet mindig a közös szülőn kell bekapcsolni.

9. Kártyák, képek és szövegek

.kartya {
  padding: 20px;
  background-color: #ffffff;
  border: 1px solid #c5d3df;
  border-radius: 10px;
}

.kartya img {
  display: block;
  width: 100%;
  height: auto;
  margin-bottom: 16px;
}

.kartya h2 {
  color: #234e70;
  margin-bottom: 4px;
}

.kartya p {
  margin-bottom: 12px;
}

.kartya .orszag {
  color: #c05621;
  font-weight: bold;
}

A width: 100% miatt a kép kitölti a kártya rendelkezésre álló szélességét, a height: auto pedig megtartja az oldalarányt.

10. Lábléc

footer {
  color: #ffffff;
  background-color: #234e70;
  text-align: center;
}

11. Első töréspont – kisebb laptop

A következő kód már a queries.css fájlba kerül:

@media (max-width: 75rem) {
  header,
  main,
  footer {
    width: 94%;
    padding: 24px;
  }

  main {
    gap: 20px;
  }
}

A konténer már nem érhet a képernyő széléhez, a belső és a Grid-térköz pedig csökken.

12. Második töréspont – tablet

@media (max-width: 59rem) {
  header {
    align-items: flex-start;
    flex-direction: column;
  }

  main {
    grid-template-columns: repeat(2, 1fr);
  }
}

A fejléc címe és navigációja egymás alá kerül. A hat kártya két oszlopban, három sorban jelenik meg.

13. Harmadik töréspont – mobiltelefon

@media (max-width: 34rem) {
  header,
  main,
  footer {
    width: 100%;
    padding: 16px;
  }

  h1 {
    font-size: 30px;
  }

  nav {
    flex-direction: column;
    gap: 8px;
  }

  main {
    grid-template-columns: 1fr;
    gap: 16px;
  }

  .kartya {
    padding: 16px;
  }
}

Mobilon a navigáció függőleges, a kártyák pedig egyetlen oszlopban jelennek meg.

14. Ellenőrzés DevToolsban

  1. Nyisd meg az oldalt Live Serverrel.
  2. Nyisd meg a DevToolst, majd kapcsold be a reszponzív eszköztárat.
  3. Nézd meg az oldalt 1280 pixel körül: három oszlopot kell látnod.
  4. Csökkentsd 900 pixel környékére: két oszlopot kell látnod.
  5. Csökkentsd 500 pixel környékére: egy oszlop és függőleges navigáció kell.
  6. Húzd végig lassan a szélességet, és figyeld, megjelenik-e vízszintes görgetősáv.
  7. Ellenőrizd, hogy mind a hat kép és a favicon betöltődik.
A jó végeredmény: 3 → 2 → 1 oszlop, működő navigáció, hiányzó kép és vízszintes túlcsordulás nélkül.
