11. évfolyam Közlekedési projekt 30. óra

Tabletes elrendezés

A második töréspontnál megszüntetjük a szűk kéthasábos elrendezést, és a rendelkezésre álló helyhez igazítjuk a fejlécet és a kapcsolódó témákat.

Jonas-alap:133. videó – Responding to Tablets, a Közlekedési magazin egyszerűsített szerkezetére alkalmazva

Az óra célja

  • A második, 59em-es töréspont elkészítése.
  • A kéthasábos fő Grid egyoszlopossá alakítása.
  • A fejléc elemeinek egymás alá rendezése.
  • A kapcsolódó témák helyének kihasználása egy belső Griddel.
  • A két media query együttes működésének ellenőrzése.
Kezdőcsomag letöltéseMegoldás letöltése

1. A kezdőállapot

A kezdőcsomag már tartalmazza a 29. óra 75em-es media queryjét. Kisebb laptopon az oldal jól használható, de tabletes szélességen a cikk és a 260 px-es oldalsáv túlságosan összenyomja egymást.

@media (max-width: 75em) {
  .container {
    width: 94%;
    grid-template-columns: 1fr 260px;
    column-gap: 40px;
  }
}
Responsive módban vizsgáld meg az oldalt 1000, 950, 900 és 850 px-en! Figyeld meg a címsort, a táblázatot, a cikk szélességét és az oldalsávot.

2. A második töréspont

A tabletes átalakítást körülbelül 944 px-nél végezzük el:

944 ÷ 16 = 59

@media (max-width: 59em) {
  /* Tabletes módosítások */
}
944 px csak a számítás kiindulópontja. A döntés oka az, hogy ezen a tartományon a kéthasábos elrendezés tartalma már túl keskennyé válik.

3. A fő Grid egy oszlopra vált

@media (max-width: 59em) {
  .container {
    width: 92%;
    grid-template-columns: 1fr;
    column-gap: 0;
    row-gap: 40px;
  }
}

A cikk és az aside a HTML-ben egymás után következik. Amikor a konténernek már csak egy oszlopa van, automatikusan egymás alá kerülnek.

Nem kell külön megadni az article és az aside helyét. A Grid automatikus elhelyezése követi a HTML sorrendjét.

4. A fejléc átrendezése Flexboxszal

A logó és a navigáció egymás mellett már szűkössé válik. A már ismert flex-direction segítségével egymás alá tesszük őket:

@media (max-width: 59em) {
  .main-header {
    align-items: flex-start;
    flex-direction: column;
    gap: 20px;
  }
}

A navigáció ezen az órán még látható marad. A mobilmenüt később készítjük el.

5. Címsor és oldalsáv

@media (max-width: 59em) {
  h2 {
    font-size: 32px;
  }

  aside {
    padding: 30px;
  }
}

A címsor kisebb helyet foglal, az aside pedig az új, teljes szélességű helyzetében kevésbé nagy belső térközt kap.

6. A kapcsolódó témák belső Gridje

Az oldalsáv a cikk alatt már sokkal szélesebb. Ezt kihasználva a három kapcsolódó témát három oszlopba rendezzük:

@media (max-width: 59em) {
  .related {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
  }

  .related-post {
    align-items: flex-start;
    flex-direction: column;
    margin-bottom: 0;
  }
}

A .related Grid-konténer lesz. A három .related-post a három oszlopba kerül. A kártyákon belül az ikon és a szöveg egymás alá rendeződik.

7. A media queryk együtt működnek

900 px-en mindkét feltétel igaz:

@media (max-width: 75em) { /* érvényes */ }
@media (max-width: 59em) { /* szintén érvényes */ }

A 75em-es szabályok továbbra is érvényesek. A később szereplő 59em-es blokk csak azokat a tulajdonságokat írja felül, amelyeket újra megadunk.

Példa: a 75em-es szabály 40 px-es oszlopközt ad, de a 59em-es szabály ezt 0-ra írja felül. A navigáció 16 px-es margója viszont megmarad, mert azt a második media query nem módosítja.

8. Önálló feladat és ellenőrzés

  1. A 75em-es blokk alá készíts 59em-es media queryt.
  2. Alakítsd egyoszlopossá a fő Gridet.
  3. Rendezd egymás alá a fejléc elemeit.
  4. Csökkentsd a címsort és az aside paddingjét.
  5. Rendezd háromoszlopos Gridbe a kapcsolódó témákat.
  6. Ellenőrizd az oldalt 944, 945, 900, 800 és 720 px-en.
  7. DevToolsban vizsgáld meg, melyik deklaráció melyik media queryből érkezik.

9. Ellenőrző kérdések

  1. Miért választottunk új töréspontot?
  2. Hogyan számítjuk ki az 59em körülbelüli pixelértékét?
  3. Miért kerül automatikusan az aside a cikk alá?
  4. Mit csinál a flex-direction: column a fejlécben?
  5. Miért lehet háromoszlopos a kapcsolódó rész, amikor a fő oldal már egyoszlopos?
  6. 900 px-en mely media queryk érvényesek?
Válaszok
  1. A kéthasábos tartalom tableten túl keskennyé vált.
  2. 59-et megszorozzuk 16-tal: 944 px.
  3. Az egyoszlopos Grid automatikusan a HTML sorrendjében helyezi el a gyermekeket.
  4. Egymás alá rendezi a logót és a navigációt.
  5. Mert az aside a fő Grid teljes szélességét megkapja, és azon belül külön Gridet hozhatunk létre.
  6. A 75em-es és az 59em-es is.

Mit vigyél el ebből az órából?

  • A második media query az elsővel együtt működik.
  • A fő Grid egyszerűen átalakítható egyoszlopossá.
  • A HTML helyes sorrendje segíti a reszponzív elrendezést.
  • Egy elem új helyzetében új belső elrendezést is kaphat.
  • A következő órán elkészítjük a telefonos nézetet és az egyszerű, JavaScript nélküli navigációt.
