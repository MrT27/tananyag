11. évfolyam CSS 1. óra

Szelektorok kombinálása CSS-ben

Megtanuljuk csökkenteni az ismétlődő CSS-kódot, több elemet egyszerre kijelölni, valamint egy adott HTML-részen belüli elemeket formázni.

Órai fájlok: a kezdő projektből dolgozunk. A teljes tanfolyami végállapotot is mellékeltem összehasonlításhoz.
Starter letöltése Final letöltése

Az óra célja

Az óra végére képes leszel:

  • több CSS-szelektort egy szabályban összekapcsolni;
  • felismerni és csökkenteni a felesleges kódismétlést;
  • használni a leszármazott szelektort;
  • egy adott konténeren belüli elemeket célzottan formázni;
  • megérteni, miért válhat törékennyé a túl hosszú, HTML-struktúrát követő szelektor.

1. Mi a probléma az ismétlődő CSS-sel?

Tegyük fel, hogy ugyanazt a betűtípust több elemhez külön-külön megadjuk:

h1 {
  font-family: sans-serif;
}

h2 {
  font-family: sans-serif;
}

h3 {
  font-family: sans-serif;
}

p {
  font-family: sans-serif;
}

li {
  font-family: sans-serif;
}

Ez működik, de feleslegesen ismétlődik. Ha később megváltoztatjuk a betűtípust, minden szabályt külön át kellene írni.

2. Szelektorlista – több elem kijelölése egyszerre

Ha ugyanazt a formázást több elemre szeretnénk alkalmazni, a szelektorokat vesszővel választjuk el. 

h1,
h2,
h3,
h4,
p,
li {
  font-family: sans-serif;
}
Olvasd így: válaszd ki az összes h1, h2, h3, h4, p és li elemet, majd alkalmazd rájuk ugyanazt a szabályt.

3. Miért jobb ez?

Ha most más betűtípust szeretnénk, csak egyetlen helyen kell módosítani:

h1,
h2,
h3,
h4,
p,
li {
  font-family: serif;
}

Ezután egyetlen módosítással visszaállíthatjuk sans-serif-re is. A kód rövidebb és könnyebben karbantartható.

4. A lábléc szövegének előkészítése

A következő példához a footer szövegét helyezzük bekezdésbe.

Eredetileg

<footer>Copyright &copy; 2027 by The Code Magazine.</footer>

Módosítva

<footer>
  <p>Copyright &copy; 2027 by The Code Magazine.</p>
</footer>

Így a lábléc szövege is egy p elem, ezért megkapja a bekezdések általános formázását.

5. Leszármazott szelektor

A normál bekezdések legyenek például 22 pixelesek: 

p {
  font-size: 22px;
}

A láblécben viszont kisebb szöveget szeretnénk. Ehhez: 

footer p {
  font-size: 16px;
}
footer p jelentése: válaszd ki azokat a p elemeket, amelyek egy footer elemen belül találhatók.

6. Miért nevezik leszármazott szelektornak?

A HTML-struktúrát egyszerűsítve így láthatjuk:

<footer>
  <p>Copyright...</p>
</footer>

A p a footer belsejében található. A CSS-ben a két szelektor közötti szóköz jelzi ezt a kapcsolatot.

7. Egy másik példa: a cikk szerzője

A cikk fejlécében található szerzői bekezdést szeretnénk dőlt betűssé tenni. 

header p {
  font-style: italic;
}

Ez elsőre működhet, de van egy probléma: az oldalon több header elem is lehet.

Ha a fő oldalfejlécbe később bekerül egy p, azt is dőlt betűssé tenné a header p szabály.

8. Pontosabb leszármazott szelektor

A szerzői bekezdés az article elemben található header része. Pontosíthatunk: 

article header p {
  font-style: italic;
}

Ez csak azokat a bekezdéseket választja ki, amelyek egy article belsejében lévő header elemen belül találhatók.

9. Mi a hátránya?

Az article header p működik, de már erősen függ a HTML pontos szerkezetétől.

Ha később átszervezzük a HTML-t, a CSS-szelektor is elromolhat vagy módosításra szorulhat.

Ezért nem érdemes indokolatlanul hosszú, mély HTML-struktúrát követő szelektorokat építeni. A következő témában olyan elemeket fogunk megismerni, amelyeknek saját nevet adhatunk, és egyszerűbben célozhatjuk őket.

10. Közös órai feladat

  1. Csomagold ki a starter.zip projektet.
  2. Hozz létre egy style.css fájlt.
  3. Kösd be a HTML head részében.
  4. Készíts szelektorlistát a h1, h2, h3, h4, p, li elemekhez.
  5. Állítsd a betűtípust sans-serif-re.
  6. A footer szövegét helyezd p elembe.
  7. A normál bekezdések betűmérete legyen 22 px.
  8. A footer p betűmérete legyen 16 px.
  9. Az article header p legyen dőlt betűs.
  10. Mentsd a fájlokat és ellenőrizd az eredményt Live Serverrel.

11. Ellenőrző kérdések

  1. Hogyan választunk ki több különböző elemet ugyanazzal a CSS-szabállyal?
  2. Miért előnyös a szelektorlista?
  3. Mit jelent a footer p szelektor?
  4. Mi a különbség a vessző és a szóköz szerepe között a szelektorokban?
  5. Miért lehet túl általános a header p?
  6. Mit választ ki az article header p?
  7. Miért lehet problémás a túl mély leszármazott szelektor?

Összefoglalás

Szelektorlista:

h1,
h2,
h3,
h4,
p,
li {
  font-family: sans-serif;
}

Leszármazott szelektor:

footer p {
  font-size: 16px;
}

Pontosabb, beágyazott leszármazott szelektor:

article header p {
  font-style: italic;
}
Legfontosabb gondolat: a CSS-ben törekedjünk arra, hogy ne ismételjük feleslegesen ugyanazokat a szabályokat, de a szelektoraink se váljanak szükségtelenül bonyolulttá.

Az óra végére elkészülő kód

Ez az a köztes állapot, amelyet ezen az órán el kell érnünk. Nem a teljes CSS-fejezet végleges megoldása, hanem pontosan ennek az órának az eredménye.

Órai megoldás letöltése Teljes későbbi final projekt

style.css

/* 1. CSS óra – szelektorok kombinálása */

/* Több szelektor összekapcsolása vesszővel */
h1,
h2,
h3,
h4,
p,
li {
  font-family: sans-serif;
}

/* Alap betűméretek a példákhoz */
p {
  font-size: 22px;
}

/* Leszármazott (descendant) szelektor:
   csak a footer elemen belüli bekezdések */
footer p {
  font-size: 16px;
}

/* Beágyazott leszármazott szelektor:
   csak az article elemben lévő header bekezdései */
article header p {
  font-style: italic;
}
