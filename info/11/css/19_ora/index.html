CSS Grid alapok

A Flexbox után megismerjük a CSS Gridet: sorokból és oszlopokból álló, kétdimenziós elrendezéseket építünk.

Esti ismétlés Jonas kurzusából:58. videó – Introduction to CSS Grid

Az óra célja

  • Megérteni a grid container és grid item fogalmát.
  • Rács létrehozása display: grid segítségével.
  • Oszlopok és sorok megadása.
  • A gap, column-gap és row-gap használata.
  • Észrevenni a Flexbox és a Grid közötti alapvető különbséget.
Kezdőcsomag letöltése

1. Flexbox vagy Grid?

A Flexbox elsősorban egy irányban rendez elemeket: sorban vagy oszlopban. A CSS Grid ezzel szemben két dimenzióban dolgozik: egyszerre kezelhetünk sorokat és oszlopokat.

Egyszerűen: Flexbox = egy tengely, Grid = sorok + oszlopok.

2. Grid container és grid item

Ugyanaz a gondolkodás, mint a Flexboxnál: kiválasztunk egy szülőelemet, és abból rácskonténert készítünk.

.container {
  display: grid;
}

A közvetlen gyermekelemek innentől grid itemek. A display: grid önmagában még nem feltétlenül változtat látványosan az oldalon: meg kell mondanunk a rács szerkezetét is.

3. Oszlopok létrehozása

A grid-template-columns mondja meg, hány oszlop legyen és milyen szélességűek legyenek.

.container {
  display: grid;
  grid-template-columns: 250px 150px;
}

Ez két oszlopot hoz létre: az első 250, a második 150 pixel széles.

Négy azonos szélességű oszlophoz:

grid-template-columns: repeat(4, 1fr);

3
4
1fr a rendelkezésre álló hely egy részét jelenti. Négy darab 1fr esetén a hely négy egyenlő részre oszlik.

4. A Grid automatikusan új sorokat hoz létre

Ha négy oszlopunk van, de nyolc elemünk, akkor az első négy elem az első sorba, a következő négy a második sorba kerül. Nem szükséges minden sort előre megadni.

.container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
}

5. Sorok méretezése

Ha a sorok magasságát is meg akarjuk adni, a grid-template-rows használható:

.container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-template-rows: 180px 120px;
}

Az első sor 180 pixel, a második 120 pixel magas lesz.

Ha nem adunk meg sormagasságot, a böngésző a tartalom alapján hozza létre a szükséges sorokat.

6. Térköz a rácsban: gap

.container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 30px;
}

A gap egyszerre ad távolságot a sorok és az oszlopok között.

Külön is megadhatjuk őket:

column-gap: 30px;
row-gap: 60px;
Gridnél a rácselemek közötti térközhöz a gap a természetes megoldás. Ne kezdjük az elemeket körbemargózni.

7. Órai gyakorlat

  1. Nyisd meg a kezdőcsomagot.
  2. A .container legyen grid konténer.
  3. Készíts négy egyenlő szélességű oszlopot repeat(4, 1fr) segítségével.
  4. Az első sor legyen 180px, a második 120px magas.
  5. Az oszlopok között legyen 30px, a sorok között 60px távolság.
  6. Próbáld ki, mi történik, ha kitörlöd a grid-template-rows sort.
Mintamegoldás 
.container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-template-rows: 180px 120px;
  column-gap: 30px;
  row-gap: 60px;
}

8. Mit vigyél el ebből az órából?

  • display: grid hozza létre a grid konténert.
  • grid-template-columns az oszlopokat adja meg.
  • grid-template-rows a sorokat méretezi.
  • repeat() segítségével rövidebben írhatunk ismétlődő oszlopokat.
  • fr a rendelkezésre álló hely arányos felosztására használható.
  • gap a rács elemei közötti térköz.

9. Ellenőrző kérdések

  1. Mi a grid container?
  2. Mit csinál a grid-template-columns?
  3. Mit jelent a repeat(4, 1fr)?
  4. Mi történik, ha több grid item van, mint ahány oszlop?
  5. Mi a különbség a gap, column-gap és row-gap között?
Válaszok
  1. Az a szülőelem, amelyen display: grid van.
  2. Megadja a rács oszlopainak számát és szélességét.
  3. Négy azonos, a rendelkezésre álló helyet egyenlően felosztó oszlopot.
  4. A böngésző új sort hoz létre.
  5. A gap mindkét irányra, a másik kettő csak oszlopokra vagy sorokra hat.
