11. évfolyam CSS 8. óra

Tipográfia és térközök finomítása

A meglévő Kód Magazin cikk megjelenését tesszük rendezettebbé betűméretekkel, sormagassággal, igazítással és margókkal.

1. Címsorok mérete és megjelenése

h1 {
  font-size: 26px;
  text-transform: uppercase;
  font-style: italic;
}

h2 {
  font-size: 40px;
  margin-bottom: 30px;
}

h3 {
  font-size: 30px;
  margin-top: 40px;
  margin-bottom: 20px;
}

2. text-transform

A text-transform: uppercase; a megjelenő szöveget nagybetűssé alakítja. 

h1 {
  text-transform: uppercase;
}
Fontos: ez a megjelenést módosítja, nem a HTML-ben lévő eredeti szöveget.

3. text-align

A kapcsolódó cikkek címe középre igazítható: 

h4 {
  font-size: 20px;
  text-transform: uppercase;
  text-align: center;
}

4. Bekezdések olvashatósága – line-height

p {
  font-size: 22px;
  line-height: 1.5;
  margin-bottom: 15px;
}

A line-height a sorok közötti távolságot szabályozza. A 1.5 azt jelenti, hogy a sormagasság a betűméret másfélszerese.

5. Címsorok közötti térköz

h2 {
  margin-bottom: 30px;
}

h3 {
  margin-top: 40px;
  margin-bottom: 20px;
}

A margin-top és margin-bottom segítségével szabályozzuk a blokkok közötti függőleges távolságot.

6. Listák térközei

ul,
ol {
  margin-left: 50px;
  margin-bottom: 20px;
}

li {
  font-size: 20px;
  margin-bottom: 10px;
}

A listát balról beljebb húzzuk, a listaelemek között pedig külön térközt hagyunk.

7. Az utolsó listaelem külön kezelése

li:last-child {
  margin-bottom: 0;
}

Így az utolsó listaelem alatt nem marad felesleges plusz térköz.

Ezzel a korábban tanult :last-child pszeudo-osztályt most valódi elrendezési célra használjuk.

8. Közös órai feladat

  1. A h1 legyen 26 px-es, nagybetűs és dőlt.
  2. A h2 legyen 40 px-es, alatta 30 px margóval.
  3. A h3 legyen 30 px-es, fölötte 40 px, alatta 20 px margóval.
  4. A h4 legyen nagybetűs és középre igazított.
  5. A bekezdések legyenek 22 px-esek, line-height: 1.5 értékkel.
  6. A bekezdések alatt legyen 15 px margó.
  7. A listák legyenek balról 50 px-re behúzva.
  8. A listaelemek alatt legyen 10 px margó.
  9. Az utolsó listaelem alatt ne legyen margó.

9. Ellenőrző kérdések

  1. Mire való a text-transform?
  2. Mit csinál a text-align: center;?
  3. Mit szabályoz a line-height?
  4. Mi a különbség a margin-top és margin-bottom között?
  5. Miért hasznos a li:last-child { margin-bottom: 0; }?
