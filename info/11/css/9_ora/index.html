11. évfolyam CSS 9. óra

Képek és navigáció formázása

A meglévő Kód Magazin projektet visszük tovább: a fő kép méretezése és a navigációs linkek rendezése következik.

1. Mi a cél?

A fő cikk képe töltse ki a cikk rendelkezésre álló szélességét, miközben megtartja az eredeti képarányát.

A navigációs linkeket pedig szeretnénk egymás mellett, rendezett térközzel megjeleníteni.

2. Class a fő képen

HTML-ben adjunk nevet a fő cikk képének:

<img
  class="post-img"
  src="img/post-img.jpg"
  alt="HTML-kód egy laptop képernyőjén"
/>

CSS-ben:

.post-img {
  width: 100%;
  height: auto;
}

3. Mit jelent a width: 100%?

A kép szélessége a rendelkezésére álló szülőelem teljes szélessége lesz.

A 100% nem feltétlenül a teljes böngészőablak szélességét jelenti, hanem annak az elemnek a szélességét, amelyben a kép található.

4. Miért kell a height: auto?

.post-img {
  width: 100%;
  height: auto;
}

A height: auto; megtartja a kép eredeti képarányát. Így a kép nem nyúlik meg és nem torzul el.

5. Navigációs linkek formázása

A navigációban lévő linkeket célzottan formázhatjuk: 

nav a:link {
  margin-right: 30px;
  margin-top: 10px;
  display: inline-block;
}

6. Miért inline-block?

A linkek alapvetően inline elemek. Az inline-block megtartja azt, hogy egymás mellett maradjanak, de közben könnyebben kezelhetővé válnak a térközeik és méreteik.

Most még nem készítünk bonyolult menüt. A cél csak az, hogy a linkek rendezettebben jelenjenek meg egymás mellett.

7. Linkek közötti térköz

nav a:link {
  margin-right: 30px;
}

Minden navigációs link jobb oldalára 30 px térközt teszünk.

Az utolsó linknél erre már nincs szükség:

nav a:link:last-child {
  margin-right: 0;
}

8. A HTML-részlet

<nav>
  <a href="#">Blog</a>
  <a href="#">Kihívások</a>
  <a href="#">Flexbox</a>
  <a href="#">CSS Grid</a>
</nav>

<img
  class="post-img"
  src="img/post-img.jpg"
  alt="HTML-kód egy laptop képernyőjén"
/>

9. Közös órai feladat

  1. Adj a fő cikk képének post-img class-t.
  2. A kép szélessége legyen 100%.
  3. A kép magassága legyen auto.
  4. A navigációs linkek jobb oldalára tegyél 30 px margót.
  5. A linkek felső margója legyen 10 px.
  6. Állítsd a navigációs linkeket inline-block megjelenítésre.
  7. Az utolsó navigációs link jobb margója legyen 0.

10. Ellenőrző kérdések

  1. Mit jelent a width: 100% egy képnél?
  2. Miért használunk height: auto értéket?
  3. Mit jelent az inline-block?
  4. Miért használunk margin-right-ot a navigációs linkeken?
  5. Miért nullázzuk az utolsó link jobb oldali margóját?
  6. Mit választ ki a nav a:link szelektor?

Az óra CSS-kódja

Órai CSS letöltése 
/* KÉPEK ÉS NAVIGÁCIÓ FORMÁZÁSA */

/* A fő cikk képe töltse ki a rendelkezésre álló szélességet */
.post-img {
  width: 100%;
  height: auto;
}

/* Navigációs linkek */
nav a:link {
  margin-right: 30px;
  margin-top: 10px;
  display: inline-block;
}

/* Az utolsó link után ne legyen felesleges térköz */
nav a:link:last-child {
  margin-right: 0;
}
