11. évfolyam CSS 5. óra

Chrome DevTools – fejlesztői eszközök

Megtanuljuk megvizsgálni a HTML-elemeket, az alkalmazott CSS-szabályokat, és ideiglenesen módosítani a stílusokat közvetlenül a böngészőben.

Az óra célja

  • megnyitni a böngésző fejlesztői eszközeit;
  • használni az Elements fület;
  • egy HTML-elemhez tartozó CSS-szabályokat megvizsgálni;
  • CSS-tulajdonságokat ideiglenesen be- és kikapcsolni;
  • új stílust tesztelni a böngészőben;
  • pszeudo-osztály állapotokat, például :hover-t kényszeríteni;
  • megérteni, hogy ezek a módosítások nem írják át automatikusan a saját fájljainkat.

1. Mi az a DevTools?

A modern böngészők beépített fejlesztői eszközöket tartalmaznak. Ezeket röviden DevTools-nak nevezzük.

Segítségével megnézhetjük, hogy a böngésző milyen HTML-t és CSS-t használ egy adott elem megjelenítéséhez.

2. A fejlesztői eszközök megnyitása

A leirat három lehetőséget említ:

  1. jobb kattintás az oldalon → Inspect / Vizsgálat;
  2. a böngésző menüjéből a fejlesztői eszközök megnyitása;
  3. billentyűparancs használata.
Kezdőként a legegyszerűbb módszer: jobb kattintás a vizsgálandó elemre, majd Inspect.

3. Az Elements fül

Az Elements fülön láthatjuk az oldal HTML-szerkezetét. Az elemek lenyithatók, így végig tudjuk követni az egymásba ágyazott HTML-elemeket.

Ha az egérrel egy HTML-elem fölé visszük a mutatót a DevToolsban, a böngésző az oldalon is kiemeli a hozzá tartozó területet.

4. HTML-elemek vizsgálata

Például kiválaszthatjuk a fő fejlécet, a navigációt vagy egy címsort. Így megfigyelhetjük, hogy az adott elem pontosan mekkora területet foglal el. 

<header class="main-header">
  ...
</header>

5. A Styles panel

Egy kijelölt elem mellett a Styles panelen láthatjuk az összes olyan CSS-szabályt, amely az adott elemre érvényes.

Például egy h1-re több különböző szabály is hathat:

h1,
h2,
h3 {
  color: #1098ad;
}

h1 {
  font-size: 26px;
  text-transform: uppercase;
  font-style: italic;
}

A DevTools segít megérteni, hogy ezek közül melyik szabály milyen tulajdonságot ad az elemhez.

6. Alapértelmezett böngészőstílusok

Nem minden stílust mi írunk. A böngésző saját alapértelmezett stílusokat is alkalmazhat.

A leirat ezt user agent stylesheet néven említi. Például egy h1 alapértelmezés szerint félkövér lehet.

7. CSS-szabályok be- és kikapcsolása

A Styles panelen egy tulajdonság melletti jelölőnégyzettel ideiglenesen ki- vagy bekapcsolhatjuk az adott szabályt. 

color: #1098ad;
text-decoration: none;
Ez nagyon hasznos hibakereséshez: gyorsan kiderül, melyik tulajdonság okozza az adott megjelenést.

8. Új stílus kipróbálása

A DevToolsban új CSS-tulajdonságot is megadhatunk teszteléshez. Például: 

font-size: 30px;

Az eredmény azonnal megjelenik a böngészőben.

Ezek a módosítások csak ideiglenesek. Az oldal újratöltésekor eltűnnek, mert a saját HTML- és CSS-fájljaink nem módosulnak.

9. Pszeudo-osztály állapotok tesztelése

A DevTools segítségével egy elem állapotát is kényszeríthetjük. Ez különösen hasznos a linkeknél. 

a:hover {
  color: orangered;
  font-weight: bold;
}

Így a linket úgy tudjuk megvizsgálni, mintha éppen fölötte lenne az egér, akkor is, ha valójában nincs fölötte.

10. :active állapot vizsgálata

Ugyanígy az :active állapot is bekapcsolható a fejlesztői eszközökben. 

a:active {
  background-color: black;
  font-style: italic;
}

11. Közös órai feladat

  1. Nyisd meg a Kód Magazin oldalt a böngészőben.
  2. Jobb kattintás → Inspect segítségével nyisd meg a DevTools-t.
  3. Az Elements fülön keresd meg a fő h1 elemet.
  4. Vizsgáld meg a Styles panelen a rá érvényes CSS-szabályokat.
  5. Kapcsold ki ideiglenesen a színét.
  6. Adj hozzá ideiglenesen font-size: 30px; tulajdonságot.
  7. Vizsgálj meg egy linket.
  8. Kényszerítsd a :hover állapotot.
  9. Próbáld ki az :active állapotot is.
  10. Frissítsd újra az oldalt, és figyeld meg, mi történik a módosításokkal.

12. Ellenőrző kérdések

  1. Mi a DevTools?
  2. Mire használjuk az Elements fület?
  3. Mit mutat a Styles panel?
  4. Mi az a user agent stylesheet?
  5. Hogyan kapcsolhatunk ki ideiglenesen egy CSS-tulajdonságot?
  6. Mi történik a DevToolsban végzett módosításokkal oldalfrissítés után?
  7. Miért hasznos a :hover állapot kényszerítése?
  8. Mikor lehet hasznos a DevTools hibakeresésnél?
