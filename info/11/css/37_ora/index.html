11. évfolyam HTML/CSS lezárás 37. óra

Haladó szelektorok és pszeudo-elemek

Pontosabban választjuk ki az elemeket, majd díszítő tartalmat készítünk új HTML-elem nélkül.

Az óra célja

  • A gyermek-, közvetlen testvér- és általános testvér-kombinátor megkülönböztetése.
  • Elemek kiválasztása attribútumuk alapján.
  • A ::before és ::after használata.
  • A megoldások ellenőrzése DevToolsban.
Kezdőcsomag letöltése

1. Leszármazott és közvetlen gyermek

.kartya p { color: #345; }
.kartya > p { font-weight: bold; }

A szóköz minden, a kártyán belül bárhol található bekezdést kijelöl. A > csak azt, amelynek közvetlen szülője a .kartya.

Ha a bekezdés még egy div belsejébe kerül, már nem közvetlen gyermek.

2. Közvetlen testvér: +

h2 + p { font-size: 1.15rem; }

Az első olyan p elemet találja el, amely közvetlenül egy h2 után áll, ugyanazon szülőn belül. Jó példa a cikk bevezető bekezdésének kiemelése.

3. Későbbi testvérek: ~

h2 ~ p { color: #495057; }

Az összes későbbi, azonos szülőhöz tartozó p elemet kijelöli. Nem kell közvetlenül a címsor után állniuk.

A + B: csak a következő B. A ~ B: minden későbbi B.

4. Attribútumszelektorok

a[target="_blank"] { text-decoration-style: dotted; }
a[href^="https"] { color: #087f5b; }
a[href$=".pdf"] { font-weight: bold; }
input[required] { border: 2px solid #e8590c; }
  • [required]: van ilyen attribútuma.
  • [attr="érték"]: pontos egyezés.
  • ^=: ezzel kezdődik; $=: erre végződik; *=: tartalmazza.

5. ::before és ::after

.figyelmeztetes::before { content: "⚠ "; }
a[target="_blank"]::after { content: " ↗"; }

A pszeudo-elem a kijelölt elem tartalmának elején vagy végén jelenik meg. A content nélkül általában nem jön létre.

Csak díszítésre vagy rövid jelzésre használjuk. Lényeges információt ne kizárólag CSS-ből adjunk.

6. Dekoratív doboz pszeudo-elemmel

.cimke::before {
  content: "";
  display: inline-block;
  width: 10px;
  height: 10px;
  margin-right: 8px;
  background-color: #2b8a3e;
  border-radius: 50%;
}

Üres tartalommal is létrehozhatunk díszítő dobozt. A méretezéshez itt inline-block kell.

7. Órai feladat

  1. A kártyák közvetlen bekezdéseit jelöld ki > segítségével.
  2. A kártyacím utáni első bekezdést nagyítsd meg + használatával.
  3. A címsor utáni összes bekezdés színét módosítsd ~ használatával.
  4. A külső oldalon megnyíló linkeket válaszd ki attribútumszelektorral.
  5. Adj utánuk ↗ jelzést ::after segítségével.
  6. A .cimke elé készíts zöld pontot ::before segítségével.
  7. DevToolsban ellenőrizd az illeszkedéseket.
Mintamegoldás
.kartya > p { line-height: 1.7; }
.kartya h2 + p { font-size: 1.15rem; }
.kartya h2 ~ p { color: #495057; }
a[target="_blank"]::after { content: " ↗"; }

Ellenőrző kérdések

  1. Mi a különbség a szóköz és a > között?
  2. Mikor talál több elemet a ~, mint a +?
  3. Mit jelent az a[href$=".pdf"]?
  4. Miért szükséges a content?
