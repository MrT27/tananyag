CSS Grid – igazítás

A rácsot és a grid itemeket is tudjuk igazítani. A kulcs az, hogy mindig eldöntsük: a teljes rácsot mozgatjuk, vagy az elemeket a saját cellájukon belül.

Esti ismétlés Jonas kurzusából:62. videó – Aligning Grid Items and Tracks

Az óra célja

  • A justify-content és align-content szerepének megértése.
  • A justify-items és align-items használata.
  • Egyetlen grid item külön igazítása justify-self és align-self segítségével.
  • A stretch alapértelmezett viselkedés felismerése.
Kezdőcsomag letöltése

1. Kétféle igazítás

Gridben két külön kérdést tehetünk fel:

  1. Hol legyen a teljes rács a konténerben?
  2. Hol legyenek az elemek a saját cellájukon belül?
Ez a legfontosabb különbség. A content végű tulajdonságok a teljes rácsot, az items végűek a cellákon belüli elemeket igazítják.

2. A teljes rács igazítása a konténerben

Ehhez csak akkor van látható helyünk, ha a grid container nagyobb, mint maga a rács.

.container {
  display: grid;
  width: 700px;
  height: 500px;
  grid-template-columns: 125px 200px 125px;
  grid-template-rows: 160px 100px;

  justify-content: center;
  align-content: center;
}
  • justify-content → vízszintes igazítás.
  • align-content → függőleges igazítás.

Hasznos értékek: start, center, end, illetve például space-between.

Ha a rács teljesen kitölti a konténert, nincs szabad hely, ezért ezek hatása kevésbé vagy egyáltalán nem látszik.

3. Grid itemek igazítása a cellákon belül

Alapértelmezés szerint a grid itemek megpróbálják kitölteni a cellájukat. Ezt nevezzük stretch viselkedésnek.

.container {
  align-items: center;
  justify-items: center;
}
  • align-items → függőleges igazítás a cellán belül.
  • justify-items → vízszintes igazítás a cellán belül.

Gyakori értékek: start, center, end, stretch.

4. Egyetlen elem külön igazítása

Ha csak egy grid itemet szeretnénk máshová tenni, nem kell az egész rács szabályait megváltoztatni.

.item-3 {
  align-self: end;
  justify-self: end;
}

Az align-self felülírja az adott elemnél az align-items, a justify-self pedig a justify-items értékét.

6. Órai gyakorlat

  1. Nyisd meg a kezdőcsomagot.
  2. Állítsd a teljes rácsot vízszintesen és függőlegesen középre.
  3. Adj 40px rést a grid itemek közé.
  4. Állítsd az összes grid itemet a saját cellája közepére.
  5. A 3-as elem kerüljön a cellája jobb alsó sarkába.
  6. Próbáld ki a justify-content: space-between értéket, majd állítsd vissza középre.
  7. Kapcsold vissza a stretch értéket az align-items-nél, és figyeld meg a különbséget.
Mintamegoldás
.container {
  justify-content: center;
  align-content: center;
  gap: 40px;
  justify-items: center;
  align-items: center;
}

.item-3 {
  justify-self: end;
  align-self: end;
}

7. Mit vigyél el ebből az órából?

  • content → a teljes rács helyzete a konténerben.
  • items → az összes elem helyzete a saját cellájában.
  • self → egyetlen elem külön igazítása.
  • A justify itt vízszintesen, az align függőlegesen dolgozik.
  • A Grid alapértelmezett item-igazítása gyakran stretch.

8. Ellenőrző kérdések

  1. Mi a különbség a justify-content és a justify-items között?
  2. Melyik tulajdonság igazítja függőlegesen az összes itemet a saját cellájában?
  3. Hogyan igazítanál csak egyetlen elemet jobbra?
  4. Mit jelent a stretch?
  5. Mikor látható igazán az align-content és a justify-content hatása?
Válaszok
  1. Az első a teljes rácsot mozgatja a konténerben, a második az itemeket a celláikon belül.
  2. align-items.
  3. justify-self: end;.
  4. Az elem megpróbálja kitölteni a rendelkezésre álló cellaterületet az adott irányban.
  5. Ha a konténer nagyobb, mint maga a létrehozott rács, tehát marad szabad hely.
