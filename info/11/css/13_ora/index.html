Kiszámítható méretezés – box-sizing: border-box

Miért lesz egy 300 px széles doboz valójában szélesebb, ha paddinget adunk hozzá – és hogyan oldjuk meg ezt egyetlen CSS-szabállyal?

Esti ismétlés Jonas kurzusából:49. videó – box-sizing: border-box

Az óra célja

  • Az alapértelmezett content-box méretszámítás felidézése.
  • Annak megértése, miért növeli a padding és a border a doboz teljes méretét.
  • A box-sizing: border-box használata.
  • A globális CSS-reset kiegészítése a box-sizing szabállyal.
  • A DevTools dobozmodelljének használata ellenőrzéshez.

A kezdőcsomag a korábbi magazinoldalra épül. Az oldalsáv 300 px széles, de 40 px paddinget is kap – itt fogjuk megfigyelni a problémát.

Kezdőcsomag letöltése

1. Gyors ismétlés: mit jelent a width?

Korábban megtanultuk a dobozmodellt: content → padding → border → margin. Alapértelmezésben a CSS-ben megadott width csak a tartalmi terület szélességét jelenti.

.doboz {
  width: 300px;
  padding: 40px;
}
Alapértelmezett box-sizing: content-box mellett a padding hozzáadódik a megadott szélességhez.

2. A probléma: a 300 px nem mindig 300 px

Ha egy elem 300 px széles, és mindkét oldalán 40 px padding van, akkor keret nélkül is:

300 + 40 + 40 = 380 px

Ha még 5–5 px keretet is adunk hozzá:

300 + 40 + 40 + 5 + 5 = 390 px

A teljes doboz szélesebb 300 px-nél

Nagyobb elrendezéseknél ez könnyen azt eredményezi, hogy egy elem már nem fér el ott, ahová terveztük.

Próba: nyisd meg a kezdőcsomagot, vizsgáld meg az aside elemet DevToolsban, és nézd meg a Box Model ábrán a tartalom, padding és border értékeit.

3. A megoldás: box-sizing: border-box

A border-box megváltoztatja a méretszámítást:

.doboz {
  width: 300px;
  padding: 40px;
  border: 5px solid #1098ad;
  box-sizing: border-box;
}

Most a megadott 300 px már a teljes doboz külső szélessége: a content, a padding és a border együtt fér bele ebbe a méretbe.

5. Alkalmazzuk az oldalsávon

A kezdőcsomagban az oldalsáv ilyen:

aside {
  width: 300px;
  padding: 40px;
  border-top: 5px solid #1098ad;
  border-bottom: 5px solid #1098ad;
}

Add hozzá:

aside {
  box-sizing: border-box;
}

DevToolsban figyeld meg, hogy a teljes szélesség most már pontosan 300 px. A tartalmi rész lesz keskenyebb, nem maga a teljes doboz nagyobb.

Kísérlet: kapcsold ki-be DevToolsban a box-sizing: border-box sort. Figyeld meg, melyik szám változik: a teljes szélesség vagy a content szélessége?

6. Ne csak egy elemre: legyen ez az alapértelmezés

A box-sizing nem öröklődik automatikusan a body-ból, ezért egyszerűen az univerzális szelektorhoz adjuk:

* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

Ezzel minden elem kiszámíthatóbban méretezhető. A korábbi resetünket tehát egyetlen új sorral egészítjük ki.

Érdemes megjegyezni: ezt a szabályt a legtöbb modern projekt elején használhatod. Innentől a width és height kezelése sokkal egyszerűbb lesz.

7. Órai feladat

  1. Nyisd meg a kezdőcsomagot.
  2. Az aside szélességét állítsd 300px-re.
  3. Adj neki 40px paddinget.
  4. DevToolsban mérd meg a teljes szélességét border-box nélkül.
  5. Add hozzá az aside-hoz a box-sizing: border-box; szabályt.
  6. Újra ellenőrizd a méretet.
  7. Végül vedd ki az aside-ból a szabályt, és tedd az univerzális * szelektorba.
Végleges CSS-részlet
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

aside {
  width: 300px;
  padding: 40px;

8. Mini kihívás

Készíts egy új .kartya elemet:

.kartya {
  width: 250px;
  padding: 25px;
  border: 5px solid #333;
}
  1. Számold ki előre, mekkora lesz a teljes szélessége content-box esetén.
  2. Ellenőrizd DevToolsban.
  3. Kapcsold be a box-sizing: border-box szabályt.
  4. Mi lett most a teljes szélesség?
Megoldás

content-box: 250 + 25 + 25 + 5 + 5 = 310 px. border-box: a teljes doboz 250 px.

9. Ellenőrző kérdések

  1. Mi az alapértelmezett box-sizing érték?
  2. content-box esetén mire vonatkozik a width?
  3. Mi történik a teljes szélességgel, ha paddinget adunk hozzá?
  4. Mit változtat meg a border-box?
  5. Miért praktikus a szabályt a * szelektorban megadni?
Válaszok
  1. content-box.
  2. Csak a tartalmi területre.
  3. A padding és a border hozzáadódik, ezért a teljes doboz nagyobb lesz.
  4. A megadott width/height a teljes, borderig tartó doboz mérete lesz.
  5. Így minden elemre egyszerre alkalmazzuk a kiszámíthatóbb méretszámítást.
