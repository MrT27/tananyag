Gyakorlás HTML + CSS

BookZone dolgozat – megoldás lépésről lépésre

Ugyanazt a feladatot oldjuk meg, amit a dolgozatban kellett elkészíteni. Nem egyben másoljuk be a kész megoldást: minden lépésnél megnézzük, mit kér a feladat és miért azt a HTML- vagy CSS-megoldást használjuk.

0. Kiindulás

A dolgozatban ezekből a fájlokból indulunk:

index.html
style.css
szoveg.txt
img/
└── haromtest-problema.jpg

A szoveg.txt csak a tartalmat adja. Nekünk kell eldönteni, melyik szövegből lesz címsor, bekezdés, lista vagy hivatkozás.

Kiinduló fájlok Eredeti feladatlap

1. A CSS-fájl bekötése

Először az index.html és a style.css között kell kapcsolatot létrehozni. 

<link rel="stylesheet" href="style.css">
Ellenőrzés: a sor a head elemben legyen, és a fájlnév pontosan style.css legyen.

2. Fő fejléc és navigáció

A BookZone neve és a három menüpont az oldal fő fejlécébe kerül. 

<header class="main-header">
  <h1>BookZone</h1>

  <nav>
    <a href="#">Kezdőlap</a>
    <a href="#">Könyvek</a>
    <a href="#">Kapcsolat</a>
  </nav>
</header>

A main-header class azért kell, mert később csak ezt a fejlécet szeretnénk háttérszínnel formázni.

3. A fő könyv szerkezete

A részletesen bemutatott könyv önálló tartalom, ezért article elembe kerül. 

<article>
  <header>
    <h2>A háromtest-probléma</h2>
    <p>Liu Cixin</p>
  </header>
</article>
Az oldalon két header is lehet. A külső az egész oldal fő fejléce, az article-ben lévő pedig a könyv saját fejléce.

4. Borítókép és ár

<img
  src="img/haromtest-problema.jpg"
  alt="A háromtest-probléma című sci-fi regény borítója"
  width="300"
>

<p><strong>5 990 Ft</strong></p>

Az alt röviden leírja a képet. Az ár kiemelésére a szemantikailag is hangsúlyt jelentő strong elemet használjuk.

5. Leírás és könyvjellemzők

A két leíró szöveg két külön bekezdés lesz, a három jellemző pedig felsorolás. 

<p>
  A történet középpontjában egy különös tudományos rejtély és az emberiség
  jövőjét alapjaiban megváltoztató felfedezés áll.
</p>

  egy izgalmas, nagyszabású sci-fi történetben kapcsolja össze.
</p>

7. Lábléc

<footer>
  <p>Copyright © 2026 BookZone</p>
</footer>
Ezzel a HTML szerkezete elkészült. Mielőtt CSS-t írunk, ellenőrizzük, hogy minden szöveg, kép és link megjelenik-e.

8. CSS – az oldal alapbeállításai

body {
  color: #374151;
  font-family: sans-serif;
}

.main-header {
  background-color: #ecfdf5;
}

A body adja az oldal alap szövegszínét és betűtípusát. A fejléc világoszöld hátterét csak a .main-header kapja.

9. Címsorok formázása

A h1, h2 és h3 ugyanazt a színt kapja, ezért szelektorlistát használunk. 

h1,
h2,
h3 {
  color: #047857;
}

h1 {
  font-size: 30px;
}

h2 {
  font-size: 40px;
}

h3 {
  font-size: 26px;
}

h4 {
  font-size: 20px;
}

10. Bekezdések és listaelemek

p {
  font-size: 20px;
}

li {
  font-size: 18px;
}

Az elemszelektor minden azonos típusú elemre hat, ezért nem kell minden bekezdést külön megjelölni.

11. Az aside formázása

aside {
  background-color: #ecfdf5;
  border-top: 5px solid #047857;
  border-bottom: 5px solid #047857;
}

Itt egyszerre gyakoroljuk a háttérszínt és a felső/alsó szegélyt.

12. Pszeudo-osztályok

li:first-child {
  font-weight: bold;
}

li:nth-child(even) {
  color: #b45309;
}

A :first-child azokat a li elemeket választja ki, amelyek a saját szülőjük első gyermekei. A :nth-child(even) a páros sorszámú gyermekeket választja.

13. Linkek – LVHA

A linkállapotokat a tanult sorrendben írjuk: Link → Visited → Hover → Active. 

a:link {
  color: #047857;
  text-decoration: none;
}

a:visited {
  color: #047857;
}

a:hover {
  color: #b45309;
  font-weight: bold;
  text-decoration: underline;
}

a:active {
  background-color: #111827;
  font-style: italic;
}

14. Végső ellenőrzés

  1. A style.css be van kötve.
  2. A fő fejléc main-header class-t kapott.
  3. Megvan a nav, az article, az aside és a footer.
  4. A kép elérési útja helyes, és van alt szövege.
  5. Az ár strong elemben van.
  6. A könyvjellemzők listában vannak.
  7. A három ajánlott könyv külön listaelem.
  8. A címsorok szelektorlistával kapják a fő színt.
  9. Működik a :first-child és a :nth-child(even).
  10. A linkek LVHA sorrendben vannak formázva.
