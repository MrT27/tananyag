11. évfolyam CSS 3. óra

Pszeudo-osztályok CSS-ben

Megtanuljuk automatikusan kiválasztani egy lista első, utolsó vagy adott sorszámú elemét.

Az óra célja

  • megérteni, mi az a pszeudo-osztály;
  • használni a :first-child és :last-child szelektorokat;
  • használni a :nth-child() pszeudo-osztályt;
  • megérteni az odd és even kulcsszavakat;
  • felismerni a :first-child egyik gyakori félreértését.

1. Mi az a pszeudo-osztály?

A pszeudo-osztály egy már meglévő elem bizonyos állapotát vagy helyzetét célozza meg. Kettősponttal írjuk. 

li:first-child {
  font-weight: bold;
}
Ez azokat az li elemeket választja ki, amelyek a saját szülőelemük első gyermekei.

2. Az első listaelem – :first-child

Korábban ezt külön osztállyal is megoldhattuk volna:

<li class="first-li">Első elem</li>

De elegánsabb:

li:first-child {
  font-weight: bold;
}

Így minden lista első eleme automatikusan félkövér lesz.

3. Az utolsó listaelem – :last-child

li:last-child {
  font-style: italic;
}

Ez minden olyan li elemet kijelöl, amely a saját szülőjének utolsó gyermeke.

4. Adott sorszám – :nth-child()

Ha például a második listaelemet szeretnénk kiválasztani:

li:nth-child(2) {
  color: red;
}

A harmadik:

li:nth-child(3) {
  color: red;
}

5. Páros és páratlan elemek

Páratlan elemek:

li:nth-child(odd) {
  color: red;
}

Páros elemek:

li:nth-child(even) {
  color: red;
}
Ez különösen hasznos például táblázatok vagy ismétlődő listaelemek váltakozó formázásánál.

6. Gyakori félreértés

Nézzük ezt: 

article p:first-child {
  color: red;
}
Ez nem azt jelenti, hogy „az article első p eleme”. Azt jelenti: válassz olyan p elemet, amely egyben az article első gyermeke is.

7. Miért nem működik mindig?

Ha az article első eleme például egy header:

<article>
  <header>...</header>
  <p>Első bekezdés</p>
</article>

akkor a p ugyan az első bekezdés, de nem az article első gyermeke.

8. Mikor működik jól?

Listákban különösen jól működik, mert egy ul vagy ol gyermekei jellemzően mind li elemek. 

<ul>
  <li>Első</li>
  <li>Második</li>
  <li>Harmadik</li>
</ul>

9. Közös órai feladat

  1. Az összes lista első eleme legyen félkövér.
  2. Az összes lista utolsó eleme legyen dőlt.
  3. A második listaelemek legyenek pirosak.
  4. Próbáld ki az odd és even kulcsszavakat.
  5. Próbáld ki az article p:first-child szelektort.
  6. Módosítsd a HTML-t úgy, hogy a p tényleg az első gyermek legyen.
  7. Figyeld meg, mikor kezd el működni a szabály.

10. Ellenőrző kérdések

  1. Mit jelöl a kettőspont a CSS szelektorban?
  2. Mit választ ki az li:first-child?
  3. Mit választ ki az li:last-child?
  4. Mit jelent az li:nth-child(3)?
  5. Mit jelent az odd?
  6. Mit jelent az even?
  7. Miért nem feltétlenül működik az article p:first-child?
  8. Milyen HTML-szerkezetnél különösen hasznosak ezek a pszeudo-osztályok?

Az óra CSS-kódja

Órai CSS letöltése 
/* Pszeudo-osztályok */

/* Minden lista első eleme */
li:first-child {
  font-weight: bold;
}

/* Minden lista utolsó eleme */
li:last-child {
  font-style: italic;
}

/* Egy konkrét sorszámú elem */
li:nth-child(2) {
  color: red;
}

/* Páros elemek */
li:nth-child(even) {
  color: red;
}

/* Páratlan elemek */
li:nth-child(odd) {
  color: red;
}

/* Fontos: ez csak akkor működik,
   ha a p valóban az article első gyermeke */
article p:first-child {
  color: red;
}

/* Ez akkor működik, ha a p az article utolsó gyermeke */
article p:last-child {
  color: red;
}
