11. évfolyam CSS 10. óra

Pozicionálás: relative és absolute

A meglévő Kód Magazin projekten tanuljuk meg, hogyan lehet egy elemet egy másikhoz képest pontosan elhelyezni.

Miért van szükség pozicionálásra?

Eddig az elemek természetes sorrendben követték egymást az oldalon. Most olyan elemet szeretnénk elhelyezni, amely részben "ráül" egy másik elemre.

A példában egy kis TOP címkét helyezünk a cikk címe mellé. A dolgozatban maga a TOP felirat nem lesz kötelező, de a pozicionálás logikáját ismerni kell.

1. position: relative

Először megadjuk, hogy a címsor legyen a viszonyítási pont: 

h2 {
  position: relative;
}
A relative önmagában még nem feltétlenül mozdítja el az elemet. Itt azért kell, hogy az abszolút pozicionált címke ehhez a h2-höz igazodjon.

2. position: absolute

A címkét abszolút pozicionáljuk: 

position: absolute;

Ezután a top, right, bottom és left segítségével pontosan elhelyezhető.

3. A TOP címke létrehozása

A meglévő HTML-t nem kell új elemmel bővíteni. A címkét CSS-ből hozzuk létre a ::before pszeudo-elemmel. 

h2::before {
  content: "TOP";
}

A content adja meg a megjelenő szöveget.

4. A címke formázása

h2::before {
  content: "TOP";
  background-color: #ffe70e;
  color: #444;
  font-size: 16px;
  font-weight: bold;
  display: inline-block;
  padding: 5px 10px;
}

5. A címke elhelyezése

h2::before {
  ...
  position: absolute;
  top: -10px;
  right: -25px;
}

A negatív érték azt jelenti, hogy az elem kissé kilóg a címsor dobozából.

6. Relative + absolute együtt

A legfontosabb kapcsolat:

szülő / viszonyítási pont: position: relative;
mozgatott elem: position: absolute; 
h2 {
  position: relative;
}

h2::before {
  position: absolute;
  top: -10px;
  right: -25px;
}

7. Mit csinál a top és a right?

  • top – a felső oldaltól mért távolság;
  • right – a jobb oldaltól mért távolság;
  • bottom – az alsó oldaltól mért távolság;
  • left – a bal oldaltól mért távolság.

8. A meglévő HTML

A fontos pont az, hogy a HTML szerkezetünk továbbra is ugyanaz: 

<article>
  <header class="post-header">
    <h2>The Basic Language of the Web: HTML</h2>
    <p id="author">
      Posted by <strong>Laura Jones</strong>
    </p>
  </header>

  ...
</article>

9. Közös órai feladat

  1. Állítsd a h2 pozícióját relative-ra.
  2. Készíts h2::before pszeudo-elemet.
  3. A tartalma legyen TOP.
  4. Adj neki sárga háttérszínt.
  5. Legyen 16 px-es és félkövér.
  6. Adj neki padding: 5px 10px; értéket.
  7. Állítsd position: absolute-ra.
  8. Helyezd el top: -10px és right: -25px értékkel.
  9. Próbáld ki, mi történik, ha megváltoztatod a top és right értékeket.

10. Ellenőrző kérdések

  1. Mire való a position: relative ebben a példában?
  2. Mire való a position: absolute?
  3. Mihez képest helyezkedik el az abszolút pozicionált elem?
  4. Mit szabályoz a top?
  5. Mit szabályoz a right?
  6. Mit jelenthet egy negatív pozícióérték?
  7. Mire való a ::before?
  8. Mire való a content tulajdonság?
