Mobile-first mini feladat és Search Console-bemutató

Megfordítjuk a korábbi gondolkodásmódot, majd tisztázzuk a közzététel és indexelés kapcsolatát.

Az óra célja

  • Desktop-first és mobile-first összehasonlítása.
  • Kis komponens felépítése min-width médiakérdéssel.
  • A közzététel, feltérképezés és indexelés elkülönítése.
  • Search Console URL Inspection tanári bemutató.
  • A HTML/CSS tananyagegység összefoglalása.
Mini feladat letöltése

Egyik módszer sem automatikusan jobb. A választott irányt következetesen kell használni.

2. Mobile-first példa

/* Alap: telefon */
.jaratok {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}
@media (min-width: 48em) {
  .jaratok { grid-template-columns: 1fr 1fr; }
}
@media (min-width: 75em) {
  .jaratok { grid-template-columns: repeat(3, 1fr); }
}

A médiakérdések nem eszközneveket, hanem azt a szélességet írják le, ahol a tartalomnak több helyet adunk.

3. Mini feladat

  1. A járatkártyák telefonon egy oszlopban jelenjenek meg.
  2. 48em-től legyen két oszlop.
  3. 75em-től legyen három oszlop.
  4. A navigáció telefonon egymás alatt, 48em-től egymás mellett legyen.
  5. A tartalom ne érjen a képernyő széléhez.
  6. Próbáld ki 360, 768 és 1280 pixel körül.

4. Közzététel, feltérképezés, indexelés

  1. Közzététel: az oldal nyilvános címen elérhető.
  2. Feltérképezés: a kereső robotja meglátogatja.
  3. Indexelés: a kereső feldolgozhatja és nyilvántartásba veheti.
  4. Találati megjelenés: megfelelő keresésnél megjelenhet.
A közzététel nem garantálja az indexelést, az indexelés pedig nem garantál jó helyezést.

5. Search Console – tanári bemutató

  1. Nyiss meg egy igazolt tulajdonú webhelyet.
  2. Az URL Inspection mezőbe illeszd be a pontos URL-t.
  3. Nézd meg, szerepel-e az indexben.
  4. Vizsgáld meg az utolsó feltérképezés adatait.
  5. Szükség esetén válaszd a Request indexing lehetőséget.
Nem tanulói regisztrációs feladat. Webhelytulajdon és Google-fiók kellhet hozzá. A kérés nem azonnali, és nem garantál indexelést.

6. Záró ellenőrzőlista

  • Szemantikus HTML és címsorhierarchia.
  • Beszédes osztálynevek és külső CSS.
  • Dobozmodell, Flexbox, Grid és pozicionálás.
  • Rugalmas konténer, kép és töréspontok.
  • Meta title, description, favicon és alt szöveg.
  • Fókusz, kontraszt és Lighthouse.
  • Optimalizált képek, Network panel és böngészőtámogatás.
  • Közzététel és indexelés elkülönítése.
