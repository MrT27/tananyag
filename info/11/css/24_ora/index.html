11. évfolyam CSS Grid 24. óra

Teljes oldal elrendezése CSS Griddel

Ugyanazt a blogoldalt most Grid segítségével rendezzük el. A kisebb komponensekben közben megtartjuk a Flexboxot.

Esti ismétlés Jonas kurzusából:63. videó – Building a Simple CSS Grid Layout

Az óra célja

  • Megérteni, hogy a Flexbox és a Grid nem egymás helyett, hanem együtt használható.
  • A teljes oldal fő szerkezetét Gridre átépíteni.
  • 1fr 300px oszlopszerkezetet létrehozni.
  • A fejlécet és láblécet a teljes rácsszélességre kiterjeszteni.
  • A vízszintes és függőleges távolságokat column-gap és row-gap segítségével kezelni.
Kezdőcsomag letöltése

1. Flexbox vagy Grid? Mindkettő.

A navigáció, a szerzői sor és a kapcsolódó bejegyzések továbbra is egyszerű, egydimenziós komponensek. Ezekhez megtartjuk a Flexboxot.

Az oldal nagy szerkezete viszont kétdimenziós: fejléc, fő cikk, oldalsáv és lábléc. Erre most Gridet használunk.

2. A megfelelő grid container

A .container közvetlen gyermekei legyenek:

<div class="container">
  <header class="main-header">...</header>
  <article>...</article>
  <aside>...</aside>
  <footer>...</footer>
</div>

A korábbi, Flexboxhoz létrehozott .row wrapperre már nincs szükség.

3. Két oszlop létrehozása

.container {
  display: grid;
  grid-template-columns: 1fr 300px;
}

A fő cikk megkapja a fennmaradó helyet, az oldalsáv pedig 300 pixel széles marad.

Nem kell kiszámolnunk a cikk szélességét. A 1fr ezt automatikusan megoldja.

4. Fejléc és lábléc teljes szélességen

Alapból minden grid item egy cellát foglal el. A fejlécnek és láblécnek azonban mindkét oszlopon át kell érnie.

.main-header,
footer {
  grid-column: 1 / -1;
}

A -1 az utolsó rácsvonalat jelenti, ezért ez akkor is működik, ha később változik az oszlopok száma.

5. A távolságokat a rács kezelje

.container {
  display: grid;
  grid-template-columns: 1fr 300px;
  column-gap: 75px;
  row-gap: 60px;
}

Ahelyett, hogy külön elemekre raknánk sok margin-bottom-ot, az oldal nagyobb térközeit a grid containerben tartjuk. Így a layout kódja egy helyen áttekinthető.

6. Az oldalsáv ne nyúljon le

A grid itemek alapértelmezésben megnyúlhatnak a sor teljes magasságára. Ha az oldalsáv csak akkora legyen, amekkora a tartalma:

.container {
  align-items: start;
}

Gridben az érték neve start, nem flex-start.

7. A kész fő layout

.container {
  width: 900px;
  margin: 0 auto;

  display: grid;
  grid-template-columns: 1fr 300px;
  column-gap: 75px;
  row-gap: 60px;
  align-items: start;
}

.main-header,
footer {
  grid-column: 1 / -1;
}
A belső komponensekben továbbra is használhatunk Flexboxot. A Grid és a Flexbox együtt a leghasznosabb.

8. Órai feladat

  1. Töltsd le és csomagold ki a kezdőcsomagot.
  2. Távolítsd el az article és aside körüli .row elemet.
  3. A .container legyen grid container.
  4. Hozz létre egy rugalmas fő oszlopot és egy 300 pixeles oldalsávot.
  5. A fejléc és a lábléc érjen végig mindkét oszlopon.
  6. Állíts be 75 pixeles oszloprést és 60 pixeles sorrést.
  7. Az oldalsáv igazodjon a sor tetejére, ne nyúljon a cikk teljes magasságára.
  8. Ellenőrizd DevTools Grid overlay segítségével a két oszlopot és a rácsvonalakat.

9. Mit vigyél el ebből az órából?

  • A Flexbox kiváló kisebb, egydimenziós komponensekhez.
  • A Grid kiváló az oldal nagyobb, kétdimenziós szerkezetéhez.
  • 1fr leveszi rólunk a kézi szélességszámolást.
  • grid-column: 1 / -1 végignyújt egy elemet a teljes rácson.
  • A layout térközeit érdemes a grid containerben, gap-ekkel kezelni.
