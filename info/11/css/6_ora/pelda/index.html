11. évfolyam CSS Mini projekt

Melyik CSS-szabály nyer?

Egyetlen bekezdésen vizsgáljuk meg a szelektorok prioritását.

A HTML

<p id="szoveg" class="kiemelt szines">
  Ez egy próbaszöveg.
</p>

Ugyanazt az elemet ki tudjuk választani az elem nevével, valamelyik osztályával vagy az azonosítójával.

A jelenlegi eredmény

Ez egy próbaszöveg.

Tippelj előre: milyen színű lesz a bekezdés az alábbi CSS alapján?

1. Első konfliktus: elem, osztály és ID

p {
  color: green;
}

.kiemelt {
  color: blue;
}

#szoveg {
  color: red;
}

A szöveg piros, mert az ID-szelektor erősebb az osztály- és az elemszelektornál.

2. Kapcsold ki az ID-szabályt a DevToolsban

  1. Jobb kattintás a bekezdésen → Inspect.
  2. A Styles panelen keresd meg a #szoveg szabályt.
  3. Kapcsold ki a color: red; deklarációt.
Ha az ID-szabály nem érvényesül, a következő legerősebb szabály az osztály lesz, ezért a szöveg kékre változik.

3. Két azonos erősségű osztály

.kiemelt {
  color: blue;
}

.szines {
  color: orange;
}

A .kiemelt és a .szines azonos prioritású. Ha nincs erősebb szabály, a később szereplő nyer.

Eredmény: narancssárga.

4. Mit mutat a DevTools?

Figyeld meg a Styles panelt. A vesztes color deklarációk át vannak húzva, miközben maga a szabály továbbra is látható.

Kapcsold ki egyenként a színszabályokat, és figyeld meg, hogyan lép elő a következő szabály.

5. Az !important kipróbálása

A fájl végén található egy kikommentelt szabály:

/*
p {
  color: purple !important;
}
*/

Vedd ki a kommentből, mentsd el a fájlt, majd frissítsd az oldalt.

A szöveg lila lesz, pedig a p elemszelektor önmagában gyengébb lenne az ID-nál. Ezt az !important változtatja meg.

6. Rövid összefoglalás

ID > osztály > elem
  • azonos erősségnél a későbbi szabály nyer;
  • a DevTools megmutatja az elvesztett deklarációkat;
  • az !important képes felülírni a normál prioritást, ezért csak indokolt esetben használjuk.
