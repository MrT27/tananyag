11. évfolyam CSS 6. óra – elmélet

Ütköző CSS-szabályok és prioritás

Mi történik akkor, ha ugyanarra a HTML-elemre több CSS-szabály is vonatkozik?

Az óra célja

  • megérteni, hogy ugyanarra az elemre több CSS-szabály is vonatkozhat;
  • felismerni az egymással ütköző deklarációkat;
  • megérteni az ID-, osztály-, pszeudo-osztály- és elemszelektor prioritását;
  • tudni, mi történik azonos prioritás esetén;
  • felismerni az inline stílus és az !important szerepét;
  • a DevTools segítségével megvizsgálni, melyik szabály érvényesül.

1. Több szabály is vonatkozhat ugyanarra az elemre

Vegyünk egy bekezdést, amelynek van azonosítója és osztálya is:

<p id="author-text" class="author">Isaac Asimov</p>

Erre az elemre egyszerre több különböző szelektorral is hivatkozhatunk:

p {
  font-size: 18px;
  color: gray;
}

.author {
  font-size: 20px;
  font-style: italic;
}

#author-text {
  font-size: 22px;
  font-family: sans-serif;
}
Mindhárom szabály vonatkozik a bekezdésre. A kérdés csak az, mi történik azokkal a tulajdonságokkal, amelyek egymásnak ellentmondanak.

2. Nem az egész szabály „veszít”

Az előző példában a font-size három különböző értéket kapott. Ezt a konfliktust a böngészőnek fel kell oldania. A többi tulajdonság viszont továbbra is érvényes lehet.

  • a font-style: italic az osztályból származhat;
  • a font-family az ID-szelektorból származhat;
  • a color az elemszelektorból származhat;
  • a font-size értékéről viszont a prioritás dönt.

3. A szelektorok egyszerűsített prioritása

Kezdőként ezt a sorrendet érdemes megjegyezni:

ID > osztály / pszeudo-osztály > elem > univerzális szelektor
Szelektor típusa Példa Prioritás
!important color: red !important; Legmagasabb
Inline stílus <p style="color: red;"> Nagyon magas
ID szelektor #szoveg Magas
Osztály / pszeudo-osztály .kiemelt, :hover Közepes
Elem szelektor p, h1, a Alacsony
Univerzális szelektor * Legalacsonyabb

Ezért a fenti példában az ID-szelektorban szereplő font-size: 22px; fog érvényesülni. Ha két szabály azonos prioritású, akkor a CSS-ben később szereplő szabály nyer.

4. Azonos prioritás esetén a későbbi szabály nyer

Ha két szelektor ugyanolyan erősségű, akkor a CSS-ben később szereplő deklaráció érvényesül.

.copyright {
  color: blue;
}

.text {
  color: yellow;
}

Ha ugyanaz az elem mindkét osztályhoz tartozik, és nincs erősebb szelektor, akkor ebben a példában a szöveg sárga lesz.

5. Pszeudo-osztály és elemszelektor

A pszeudo-osztály magasabb prioritású, mint az egyszerű elemszelektor.

a {
  color: red;
}

a:hover {
  color: blue;
}

Amikor a link :hover állapotba kerül, a második szabály színe érvényesül.

6. Inline stílus

HTML-ben közvetlenül az elemhez is írhatunk stílust:

<p id="author-text" style="color: purple;">Isaac Asimov</p>

Az inline stílus nagyobb prioritást kap, mint egy hagyományos ID-szelektor. A tananyagban azonban továbbra is a külön CSS-fájl használata az ajánlott megoldás.

7. Az !important kulcsszó

p {
  color: green !important;
}

Az !important egy deklarációt nagyon magas prioritásúvá tesz.

Általában ne használd konfliktusok gyors elrejtésére. Jobb megoldás egyszerűbb, átláthatóbb szelektorokat írni.

8. DevTools: miért van áthúzva egy szabály?

A DevTools Styles paneljén egyszerre láthatjuk az elemre vonatkozó szabályokat. Ha egy deklaráció elveszít egy ütközést, a böngésző általában áthúzva jeleníti meg.

Ezért a DevTools az egyik legjobb eszköz annak kiderítésére, hogy miért nem azt a stílust látjuk, amelyet vártunk.

9. Amit meg kell jegyezni

  • ugyanarra az elemre egyszerre több CSS-szabály is vonatkozhat;
  • csak az egymásnak ellentmondó deklarációknál kell eldönteni, melyik nyer;
  • ID > osztály / pszeudo-osztály > elem;
  • azonos prioritás esetén a később szereplő szabály nyer;
  • az inline stílus még erősebb;
  • az !important csak végső megoldás legyen;
  • a DevToolsban az áthúzott deklaráció segít felismerni a konfliktust.

Külön magyarázó példa – mind a 6 prioritási szint egyszerre

Ebben a példában ugyanarra az egyetlen <p> elemre mind a hat szint egyszerre vonatkozik. A DevToolsban ezért jól megfigyelhető, melyik color deklaráció érvényesül, és melyek vannak áthúzva.

index.html

<!doctype html>
<html lang="hu">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>CSS prioritás – 6 szint</title>
    <link rel="stylesheet" href="style.css" />
  </head>
  <body>
    <p id="szoveg" class="kiemelt" style="color: orange">
      Lorem ipsum, dolor sit amet consectetur adipisicing elit. Ullam,
      laboriosam. Quod, ex?
    </p>
  </body>
</html>

style.css

/* 1. Univerzális szelektor – legalacsonyabb prioritás */
* {
  color: gray;
}

/* 2. Elem szelektor */
p {
  color: green;
  font-size: 28px;
}

/* 3. Osztály szelektor */
.kiemelt {
  color: blue;
}

/* 4. ID szelektor */
#szoveg {
  color: red;
}

/* 5. Inline stílus az index.html-ben van:
   style="color: orange;"
*/

/* 6. !important – legmagasabb prioritás */
p {
  color: purple !important;
}
Megfigyelés: alapállapotban a szöveg lila lesz az !important miatt. A DevToolsban kapcsold ki egymás után a szabályokat, és figyeld meg, hogyan lép elő a következő prioritási szint.
