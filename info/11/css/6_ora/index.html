Class és ID a meglévő cikken

Nem új projektet kezdünk: a már ismert Kód Magazin cikket fejlesztjük tovább a final projekt felé.

Miért kell most class és id?

Eddig több helyen elemszelektorokat és leszármazott szelektorokat használtunk. Ez működik, amíg minden azonos típusú elemet ugyanúgy akarunk formázni.

A final projektben azonban már külön szeretnénk formázni például a fő fejlécet, a cikk fejlécét, a szerző nevét és a kapcsolódó cikkek szerzőit.

Ezért most nem új példát készítünk, hanem a meglévő cikk HTML-jét nevezzük el class és id attribútumokkal.

1. A cikk fejléce kapjon class-t

<header class="post-header">

A post-header class később arra lesz jó, hogy csak a cikk fejlécét tudjuk formázni.

2. A szerző kapjon id-t

<p id="author">
  Posted by <strong>Laura Jones</strong> on Monday, June 21st 2027
</p>
#author {
  font-style: italic;
  font-size: 18px;
}

3. A kapcsolódó cikkek listája kapjon class-t

<ul class="related">
  ...
</ul>
.related {
  list-style: none;
}

4. Több szerző ugyanazt a class-t kapja

<p class="related-author">By Jonas Schmedtmann</p>
<p class="related-author">By Jim Dillon</p>
<p class="related-author">By Matilda</p>
.related-author {
  font-size: 18px;
  font-weight: bold;
}
Ez mutatja jól a class előnyét: ugyanazt a nevet több, azonos szerepű elem is használhatja.

5. A copyright kapjon id-t

<p id="copyright">
  Copyright © 2027 by The Code Magazine.
</p>
#copyright {
  font-size: 16px;
}

Class és ID – röviden

HTMLCSSMire jó?
classclass="related-author".related-authorTöbb azonos szerepű elemhez
idid="author"#authorEgy konkrét, egyedi elemhez

Közös órai feladat

  1. A meglévő cikk fejlécének adj post-header class-t.
  2. A szerző bekezdésének adj author id-t.
  3. A kapcsolódó cikkek listája kapjon related class-t.
  4. A három kapcsolódó szerző kapja meg ugyanazt a related-author class-t.
  5. A footer bekezdése kapjon copyright id-t.
  6. Írd meg hozzájuk a fenti CSS-szabályokat.

Az óra CSS-kódja

Órai CSS letöltése 
/* CLASS ÉS ID A MEGLÉVŐ CIKKEN */

#author {
  font-style: italic;
  font-size: 18px;
}

#copyright {
  font-size: 16px;
}

.related-author {
  font-size: 18px;
  font-weight: bold;
}

.related {
  list-style: none;
}
