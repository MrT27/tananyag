Flex elemek méretezése – a flex tulajdonság

Hogyan nőhetnek, zsugorodhatnak és oszthatják el a rendelkezésre álló helyet a flex elemek?

CSS-Tricks kiegészítés

A CSS-Tricks Flexbox útmutatója külön kezeli a flex konténeren és az egyes flex elemeken használható tulajdonságokat. Ebben az órában az elemenkénti beállításokat gyakoroljuk.

Jó kapaszkodó: amit a szülőn állítunk be, az általában az egész flex elrendezésre hat; amit egy flex elemen adunk meg, az csak az adott elem viselkedését módosítja.

1. A flex elemek mérete nem mindig merev

A Flexbox egyik fontos tulajdonsága, hogy az elemek mérete képes alkalmazkodni a rendelkezésre álló helyhez.

Ehhez három fogalom tartozik:

TulajdonságMit szabályoz?Alapérték
flex-growNőhet-e az elem, és mennyit kaphat a szabad helyből?0
flex-shrinkZsugorodhat-e az elem, ha kevés a hely?1
flex-basisMi legyen az elem kiinduló mérete?auto

2. flex-basis – kiinduló méret

Flex elemeknél gyakran a flex-basis segítségével adunk meg kiinduló szélességet.

.elem {
  flex-basis: 200px;
}

Ez nem feltétlenül jelent pontosan 200 pixelt. Ha a konténerben nincs elég hely, az elemek alapértelmezés szerint összezsugorodhatnak.

Fontos gondolat: a flex-basis inkább kiinduló méret, nem mindig merev végleges szélesség.

3. flex-shrink – zsugorodás

Alapértelmezés szerint:

flex-shrink: 1;

Ez azt jelenti, hogy ha a flex elemek együtt túl szélesek lennének, a böngésző csökkentheti a méretüket, hogy elférjenek.

Ha ezt megtiltjuk:

.elem {
  flex-shrink: 0;
  flex-basis: 200px;
}

akkor az elemek ragaszkodnak a 200 pixeles mérethez, és akár ki is lóghatnak a konténerből.

Nem az a cél, hogy mindig kikapcsoljuk a zsugorodást. A legtöbbször az alapértelmezett viselkedés hasznos.

4. flex-grow – a szabad hely kitöltése

Alapértelmezésben a flex elemek nem nőnek meg csak azért, mert maradt üres hely:

flex-grow: 0;

Ha minden elemre ezt írjuk:

.elem {
  flex-grow: 1;
}

akkor az elemek felosztják egymás között a rendelkezésre álló szabad helyet.

Ha minden elem ugyanazt a flex-grow értéket kapja, az üres helyből azonos arányban részesednek.

Ha csak egyetlen elem kap flex-grow: 1-et, akkor az az elem tölti ki a megmaradó helyet.

5. A rövidített flex tulajdonság

A három tulajdonság egyetlen sorban is megadható:

flex: grow shrink basis;

Példa:

.elem {
  flex: 0 0 200px;
}

Ez azt jelenti:

  • flex-grow: 0 – ne nőjön,
  • flex-shrink: 0 – ne zsugorodjon,
  • flex-basis: 200px – 200 px legyen a kiinduló méret.

6. A leggyakoribb egyszerű forma – flex: 1

.elem {
  flex: 1;
}

Gyakorlati értelemben ezzel azt mondjuk: az elemek osszák el egymás között a rendelkezésre álló helyet.

Ha minden flex elem flex: 1-et kap, akkor azonos arányban részesednek a helyből.

11. évfolyamon ezt érdemes megjegyezni: ha azonos szélességű, rugalmas elemeket szeretnénk egy sorban, a flex: 1 nagyon gyakori megoldás.

7. Órai gyakorlat

  1. Nyisd meg a kezdőcsomagot.
  2. Adj minden elemnek flex-basis: 200px; értéket.
  3. Csökkentsd a böngészőablak szélességét. Figyeld meg, hogyan zsugorodnak az elemek.
  4. Állítsd be ideiglenesen: flex-shrink: 0;. Mi történik?
  5. Távolítsd el ezeket, majd adj minden elemnek flex-grow: 1; értéket.
  6. Végül egyszerűsítsd a kódot erre: flex: 1;.
Az óra végére elérendő egyszerű megoldás
.container {
  display: flex;
  gap: 12px;
}

.elem {
  flex: 1;
}

Készíts három kártyát egy flex konténerben. A kártyák töltsék ki a teljes sort, legyenek azonos szélességűek, és legyen közöttük 20 px távolság.

</div>

.cards {
  display: flex;
  gap: 20px;
}

}

9. Ellenőrző kérdések

  1. Mit szabályoz a flex-basis?
  2. Mi a flex-shrink alapértéke?
  3. Mi történik flex-shrink: 0 esetén?
  4. Mit csinál a flex-grow: 1?
  5. Mit jelent nagy vonalakban a flex: 1?
  6. Mit jelent a flex: 0 0 200px három értéke?
Válaszok
  1. A flex elem kiinduló méretét.
  2. 1.
  3. Az elem nem zsugorodhat a helyhiány miatt.
  4. Az elem részt vesz a megmaradó szabad hely kitöltésében.
  5. Az elem rugalmasan részt vesz a hely elosztásában; azonos flex: 1 esetén az elemek azonos arányban osztoznak.
  6. grow = 0, shrink = 0, basis = 200px.
