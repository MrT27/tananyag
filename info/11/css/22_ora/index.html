CSS Grid – elemek elhelyezése és kiterjesztése

Most már nem csak a rácsot hozzuk létre: azt is megmondjuk, hogy egy grid item pontosan hol legyen, és hány cellát foglaljon el.

Esti ismétlés Jonas kurzusából:61. videó – Placing and Spanning Grid Items

Az óra célja

  • Grid item kézi elhelyezése oszlop- és sorvonalak között.
  • A grid-column és grid-row használata.
  • Több cella átfogása span segítségével.
  • Az utolsó rácsvonal elérése a -1 értékkel.
  • A Grid DevTools-vizualizáció értelmezése.
Kezdőcsomag letöltése

1. Eddig a böngésző helyezte el az elemeket

Alapértelmezés szerint a Grid a HTML sorrendjét követi. A böngésző balról jobbra, majd soronként tölti fel a rendelkezésre álló cellákat.

Mostantól: egyes elemeknél kézzel is megadhatjuk, mely rácsvonalak között helyezkedjenek el.

2. Rácsvonalak

Négy oszlophoz öt függőleges rácsvonal tartozik. Ezeket a böngésző 1-től számozza.

.container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
}

Az első oszlop az 1. és 2. vonal között, a második a 2. és 3. között van.

A DevTools Grid overlay nagyon hasznos: kapcsold be, és nézd meg a rácsvonalak számait.

3. grid-column és grid-row

Egy elemet például a 2. oszlopba és az 1. sorba így tehetünk:

.item-8 {
  grid-column: 2 / 3;
  grid-row: 1 / 2;
}

Az első szám a kezdő, a második a befejező rácsvonal.

Ha csak egyetlen cellát akarunk elfoglalni, a második érték gyakran elhagyható:

.item-8 {
  grid-column: 2;
  grid-row: 1;
}

4. Több cella átfogása

Ha a kezdő és a záró vonal között több cella van, az elem több oszlopot vagy sort foglal el.

.item-1 {
  grid-column: 1 / 4;
}

Ez az elem az 1. rácsvonaltól a 4.-ig tart, tehát három oszlopot fog át.

5. span – hány cellát foglaljon el?

Nem muszáj kiszámolni a záró rácsvonal számát:

.item-1 {
  grid-column: 1 / span 3;
}

Jelentése: induljon az 1. vonaltól, és foglaljon el három oszlopot.

6. A -1 trükk

Ha egy elemet a rács legvégéig szeretnénk kinyújtani:

.item-8 {
  grid-column: 2 / -1;
}

A -1 mindig az utolsó rácsvonalat jelenti. Ez akkor is működik, ha később megváltozik az oszlopok száma.

Hasznos minta: teljes szélességű fejléc vagy lábléc esetén gyakran látod majd a grid-column: 1 / -1; szabályt.

7. Ugyanez sorokkal

.item-6 {
  grid-row: 1 / 3;
}

Az elem két sort fog át. A span és a -1 soroknál is ugyanúgy használható.

8. Órai gyakorlat

  1. Nyisd meg a kezdőcsomagot.
  2. Kapcsold be a Grid overlayt a DevToolsban.
  3. Az 1-es elem foglalja el az első két oszlopot.
  4. A 2-es elem kerüljön a 4. oszlop 2. sorába.
  5. A 6-os elem foglaljon el két sort.
  6. A 8-as elem a 2. oszloptól tartson a rács végéig.
  7. Próbáld ki ugyanazt egyszer rácsvonalakkal, egyszer span használatával.
Mintamegoldás
.i1 { grid-column: 1 / 3; }
.i2 { grid-column: 4; grid-row: 2; }
.i6 { grid-row: 1 / 3; }
.i8 { grid-column: 2 / -1; }

9. Mit vigyél el ebből az órából?

  • A Grid elemek automatikusan helyezkednek el, de kézzel is mozgathatók.
  • grid-column és grid-row rácsvonalak között helyezi el az elemet.
  • span megadja, hány cellát foglaljon el.
  • -1 az utolsó rácsvonal.
  • A Grid overlay segít megérteni a rács szerkezetét.

10. Ellenőrző kérdések

  1. Hány függőleges rácsvonal van egy 4 oszlopos rácsban?
  2. Mit jelent a grid-column: 2 / 4?
  3. Mit jelent a grid-column: 1 / span 3?
  4. Mit jelent a -1?
  5. Melyik két tulajdonsággal helyezünk el kézzel grid itemeket?
Válaszok
  1. Öt.
  2. A 2. rácsvonaltól a 4.-ig tart, tehát két oszlopot fog át.
  3. Az 1. vonaltól indul, és három oszlopot foglal el.
  4. Az utolsó rácsvonalat.
  5. grid-column és grid-row.
