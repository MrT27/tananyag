CSS Grid – oszlopok és sorok méretezése

A fix pixelek után rugalmas rácsokat készítünk az fr, az auto és a repeat() használatával.

Esti ismétlés Jonas kurzusából:60. videó – Sizing Grid Columns and Rows

Az óra célja

  • Megérteni, miért előnyös az fr a fix pixelméretekkel szemben.
  • Azonos és eltérő arányú oszlopokat létrehozni.
  • Használni az auto értéket.
  • Rövidebben megadni ismétlődő oszlopokat a repeat() segítségével.
  • Megkülönböztetni az explicit és implicit sorokat.
Kezdőcsomag letöltése

1. Mi a gond a fix pixelekkel?

.container {
  display: grid;
  grid-template-columns: 200px 200px 200px 200px;
}

A négy oszlop mindig 200 pixel széles marad. Ha a rendelkezésre álló hely kisebb, a rács könnyen túlcsordulhat.

A Grid egyik nagy ereje: nem kell minden oszlop szélességét kézzel kiszámolnunk.

2. Az fr egység

Az fr a rendelkezésre álló hely egy részét jelenti.

grid-template-columns: 1fr 1fr 1fr 1fr;

Ebben az esetben a rendelkezésre álló hely négy egyenlő részre oszlik.

Ha az első oszlop kétszer akkora részt kapjon:

grid-template-columns: 2fr 1fr 1fr 1fr;
Fontos: a 2fr nem azt jelenti, hogy az oszlop mindig pontosan kétszer olyan széles. A rendelkezésre álló szabad helyből kap kétszeres részt.

3. repeat() – ne írjuk le ugyanazt négyszer

Ezt:

grid-template-columns: 1fr 1fr 1fr 1fr;

rövidebben így írhatjuk:

grid-template-columns: repeat(4, 1fr);

A repeat(4, 1fr) jelentése: hozz létre négy darab, egyenlő arányú oszlopot.

4. Az auto érték

Az auto használatakor az adott sáv alapvetően a tartalmához igazodik.

grid-template-columns: 1fr 1fr 1fr auto;

Ez hasznos lehet például akkor, ha az utolsó oszlopnak csak annyi hely kell, amennyit a tartalma elfoglal.

5. Sorok méretezése fr-rel

Az fr soroknál is használható, de akkor látványos igazán, ha a grid konténernek van megadott magassága.

.container {
  height: 600px;
  display: grid;
  grid-template-rows: 1fr 1fr;
}

A két sor ilyenkor azonos arányban osztozik a rendelkezésre álló magasságon.

grid-template-rows: 2fr 1fr;

Az első sor kétszeres részt kap a szabad magasságból.

6. Explicit és implicit sorok

Ha egy sort mi magunk megadunk a grid-template-rows segítségével, az explicit sor.

Ha elfogy a hely, és a böngésző automatikusan új sort hoz létre a további elemeknek, az implicit sor.

Egyelőre elég felismerni a különbséget. Az implicit sorok külön formázásával most még nem foglalkozunk.

7. Órai gyakorlat

  1. Nyisd meg a kezdőcsomagot.
  2. A négy fix, 200 pixeles oszlop helyett készíts négy egyenlő oszlopot fr használatával.
  3. Írd át a megoldást repeat() használatára.
  4. Ezután legyen az első oszlop kétszeres, a másik három egyszeres arányú.
  5. Adj a konténernek legalább 400px magasságot.
  6. A második sor legyen auto, az első pedig töltse ki a maradék helyet.
  7. Méretezd át a böngészőablakot, és figyeld meg, hogyan reagál a rács.
Mintamegoldás 
.container {
  display: grid;
  grid-template-columns: 2fr repeat(3, 1fr);
  grid-template-rows: 1fr auto;
  gap: 20px;
  min-height: 420px;
}

8. Mit vigyél el ebből az órából?

  • A pixel fix, az fr rugalmas.
  • Az azonos fr értékek azonos arányt jelentenek.
  • A nagyobb fr érték nagyobb részt kap a rendelkezésre álló helyből.
  • repeat() segítségével rövidebben írhatunk ismétlődő oszlopokat vagy sorokat.
  • auto esetén a sáv a tartalomhoz igazodhat.
  • A böngésző szükség esetén implicit sorokat hoz létre.

9. Ellenőrző kérdések

  1. Miért rugalmasabb az fr, mint a pixel?
  2. Mit jelent a repeat(4, 1fr)?
  3. Mit jelent a 2fr 1fr 1fr?
  4. Mire használható az auto?
  5. Mi a különbség az explicit és az implicit sor között?
Válaszok
  1. Az fr a rendelkezésre álló helyhez igazodik, a pixel fix méret.
  2. Négy egyenlő arányú oszlop létrehozását.
  3. Az első oszlop kétszeres részt kap a szabad helyből a másik kettőhöz képest.
  4. Olyan sávhoz, amely a tartalmához igazodjon.
  5. Az explicit sort mi adjuk meg, az implicit sort a böngésző hozza létre automatikusan.
