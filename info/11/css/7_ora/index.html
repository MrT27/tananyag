11. évfolyam CSS 7. óra

Box model és oldalelrendezés

A meglévő Kód Magazin cikket visszük tovább: margin, padding, width és margin: 0 auto.

Miért van szükség erre?

Eddig főleg azt szabályoztuk, hogy az elemek milyen színűek és milyen betűkkel jelenjenek meg. Most azt tanuljuk meg, hogyan helyezkedjenek el egymáshoz képest.

A cél továbbra is ugyanaz a Kód Magazin projekt – most csak a dobozok méretét és térközeit rendezzük.

1. A box model alapötlete

Minden HTML-elem felfogható egy dobozként.

  • content – maga a tartalom;
  • padding – belső térköz;
  • border – szegély;
  • margin – külső térköz.
Egyszerűen: padding belül, margin kívül.

2. Alapértelmezett térközök nullázása

A böngésző saját margókat és paddingeket ad bizonyos elemekhez. Ezeket lenullázhatjuk:

* {
  margin: 0;
  padding: 0;
}

A * az univerzális szelektor: minden elemre vonatkozik.

3. A teljes oldal szélessége – .container

HTML-ben a fő tartalmat egy közös dobozba tesszük:

<div class="container">
  ...
</div>

CSS-ben:

.container {
  width: 800px;
  margin: 0 auto;
}
width: 800px; beállítja a doboz szélességét. A margin: 0 auto; pedig vízszintesen középre igazítja.

4. Mit jelent a margin: 0 auto?

margin: 0 auto;
  • 0 – fent és lent nincs margó;
  • auto – bal és jobb oldalon a böngésző egyenlően osztja el a helyet.

Ez akkor működik jól, ha az elemnek van megadott szélessége.

5. Padding a fő fejlécben

.main-header {
  background-color: #f7f7f7;
  padding: 20px 40px;
}

A két érték jelentése:

  • 20px – fent és lent;
  • 40px – bal és jobb oldalon.

A padding tehát a fejléc tartalma és a doboz széle közötti hely.

6. Margin az elemek között

.main-header {
  margin-bottom: 60px;
}

article {
  margin-bottom: 60px;
}

.post-header {
  margin-bottom: 40px;
}

Ezekkel az elemek közötti külső térközt szabályozzuk.

7. Az aside mérete és belső térköze

aside {
  background-color: #f7f7f7;
  border-top: 5px solid #1098ad;
  border-bottom: 5px solid #1098ad;
  padding: 50px 0;
  width: 500px;
}

A padding: 50px 0; azt jelenti, hogy fent és lent 50 px belső térköz van, bal és jobb oldalon pedig 0.

8. A módosított HTML-részlet

<body>
  <div class="container">

    <header class="main-header">
      ...
    </header>

    <article>
      <header class="post-header">
        ...
      </header>

      ...
    </article>

    <aside>
      ...
    </aside>

    <footer>
      ...
    </footer>

  </div>
</body>

9. Közös órai feladat

  1. Tedd a teljes oldal tartalmát egy container class-ú divbe.
  2. Állítsd a container szélességét 800 px-re.
  3. Igazítsd középre margin: 0 auto; segítségével.
  4. Nullázd le az alapértelmezett margin és padding értékeket a * szelektorral.
  5. Adj a fő fejlécnek padding: 20px 40px; értéket.
  6. Adj a fő fejléc alá 60 px margót.
  7. Adj az article alá 60 px margót.
  8. Adj a post-header alá 40 px margót.
  9. Az aside szélessége legyen 500 px.
  10. Az aside felső és alsó paddingje legyen 50 px.

10. Ellenőrző kérdések

  1. Mi a különbség a margin és a padding között?
  2. Mit választ ki a * szelektor?
  3. Mire való a width?
  4. Mit jelent a margin: 0 auto;?
  5. Miért kell szélességet adni a containernek a középre igazításhoz?
  6. Mit jelent a padding: 20px 40px;?
  7. Mi a különbség a margin-bottom és a padding-bottom között?

Az óra CSS-kódja

Órai CSS letöltése 
/* BOX MODEL ÉS OLDAL ELRENDEZÉS */

/* Alapértelmezett margók és belső térközök nullázása */
* {
  margin: 0;
  padding: 0;
}

/* Az oldal fő tartalmi doboza */
.container {
  width: 800px;
  margin: 0 auto;
}

/* Fő fejléc */
.main-header {
  background-color: #f7f7f7;
  padding: 20px 40px;
  margin-bottom: 60px;
}

/* Cikk */
article {
  margin-bottom: 60px;
}

/* A cikk saját fejléce */
.post-header {
  margin-bottom: 40px;
}

/* Kapcsolódó tartalom */
aside {
  background-color: #f7f7f7;
  border-top: 5px solid #1098ad;
  border-bottom: 5px solid #1098ad;
  padding: 50px 0;
  width: 500px;
}
