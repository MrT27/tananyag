CSS Grid – fogalmak és áttekintés

Az alapok után rendszerezzük a CSS Grid működését: 2 dimenziós elrendezés, rácsvonalak, cellák, sávok és rések.

Esti ismétlés Jonas kurzusából:59. videó – A CSS Grid Overview

Az óra célja

  • Megérteni, miért kétdimenziós elrendezési rendszer a CSS Grid.
  • Elkülöníteni a Flexbox és a Grid tipikus szerepét.
  • Megismerni a legfontosabb Grid-fogalmakat: grid container, grid item, grid line, grid cell, gap, grid track.
  • Áttekinteni, mely tulajdonságok tartoznak a konténerhez és melyek az elemekhez.
Kezdőcsomag letöltése

1. Mi a CSS Grid?

A CSS Grid olyan CSS-tulajdonságok rendszere, amellyel egy konténert sorokra és oszlopokra osztunk, majd a gyermekelemeket ebben a rácsban helyezzük el.

CSS Grid = kétdimenziós elrendezés. Egyszerre gondolkodunk sorokban és oszlopokban.

2. Flexbox vagy Grid?

A két technológia nem egymás helyett van. Jól kiegészítik egymást.

FlexboxCSS Grid
Elsősorban 1 dimenzió2 dimenzió
Sor vagy oszlopSorok és oszlopok egyszerre
Komponensek, navigációk, kisebb elrendezésekNagyobb, rácsszerű elrendezések
Ne azt kérdezd, melyik a jobb. Azt kérdezd: egy vagy két dimenzióban szeretném elrendezni az elemeket?

3. Grid container és grid item

.container {
  display: grid;
}

A grid container az a szülőelem, amelyen display: grid van. A közvetlen gyermekei a grid itemek.

4. Sor- és oszloptengely

A Gridben van sorirány és oszlopirány. A Flexboxszal ellentétben itt nem cserélgetjük a tengelyek irányát: a sor mindig sor, az oszlop mindig oszlop.

5. Rácsvonalak – grid lines

A sorokat és oszlopokat rácsvonalak választják el. Ha három oszlop van, akkor négy függőleges rácsvonal van.

Ezeket a vonalakat a böngésző megszámozza, és később ezek segítségével tudjuk pontosan megadni, hol kezdődjön és hol végződjön egy elem.

Fontos: 3 oszlophoz 4 oszlopvonal, 2 sorhoz 3 sorvonal tartozik.

6. Grid cell – rácscella

A sor- és oszlopvonalak által körbezárt egy-egy terület a grid cell. Egy cella lehet üres is: nem szükséges minden cellában grid itemnek lennie.

Három oszlop és két sor esetén összesen 6 cella jön létre.

7. Gap és grid track

A rácselemek közötti tér a gap. Külön is szabályozható:

column-gap: 30px;
row-gap: 60px;

A grid track egy teljes sor vagy egy teljes oszlop által elfoglalt sáv.

Ezeket a fogalmakat nem kell bemagolni. A következő gyakorlati órákon folyamatosan használni fogjuk őket.

8. Melyik tulajdonság hová tartozik?

Grid container

  • grid-template-columns
  • grid-template-rows
  • gap, row-gap, column-gap
  • justify-items
  • align-items

Grid item

  • grid-column
  • grid-row
  • justify-self
  • align-self

Ezek közül több tulajdonságot még csak név szerint látunk. A következő órákon fogjuk őket használni.

9. Órai mini gyakorlat

Nyisd meg a kezdőcsomagot, majd a DevTools segítségével vizsgáld meg a rácsot.

  1. Keresd meg, melyik elem a grid container.
  2. Számold meg a grid itemeket.
  3. Állapítsd meg, hány oszlop és hány sor van.
  4. Számold meg, hány függőleges és hány vízszintes rácsvonal tartozik hozzá.
  5. Próbáld meg a gap értékét 10px-ről 30px-re állítani.
Ellenőrzés

A mintában 3 oszlop és 2 sor van, tehát 6 cella. Ehhez 4 függőleges és 3 vízszintes rácsvonal tartozik.

10. Mit vigyél el ebből az órából?

  • A CSS Grid kétdimenziós elrendezési rendszer.
  • A Flexbox és a Grid nem riválisok, hanem különböző feladatokra valók.
  • display: grid hozza létre a grid containert.
  • A grid line rácsvonal, a grid cell rácscella, a grid track teljes sor- vagy oszlopsáv.
  • A gap a rácselemek közötti tér.
  • A következő fontos lépés a grid elemek pontos méretezése és elhelyezése lesz.

11. Ellenőrző kérdések

  1. Miért mondjuk a Gridre, hogy kétdimenziós?
  2. Mi a különbség a grid container és a grid item között?
  3. Hány függőleges rácsvonal tartozik egy 4 oszlopos rácshoz?
  4. Mi a grid cell?
  5. Mi a grid track?
  6. Mikor választanál Flexboxot és mikor Gridet?
Válaszok
  1. Mert egyszerre kezeli a sorokat és az oszlopokat.
  2. A container a rácsot létrehozó szülő, a közvetlen gyermekei a grid itemek.
  3. Ötöt.
  4. A sor- és oszlopvonalak által körbezárt egy rácsterület.
  5. Egy teljes sor vagy oszlop által elfoglalt sáv.
  6. Flexboxot főleg egy dimenzióhoz, Gridet főleg kétdimenziós elrendezéshez.
