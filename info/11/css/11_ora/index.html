11. évfolyam CSS 11. óra

A Kód Magazin projekt végleges összeállítása

Az eddig tanult HTML- és CSS-elemeket egyetlen kész projektben fésüljük össze.

Mi a cél?

Ezen az órán már nem új CSS-tulajdonságot tanulunk, hanem az eddigiekből összeállítjuk a projekt végleges változatát.

A Like gombot kihagyjuk. A TOP címke marad, mert azon gyakoroltuk a relative és absolute pozicionálást.

1. Oldal alapjai

* {
  margin: 0;
  padding: 0;
}

body {
  color: #444;
  font-family: sans-serif;
  border-top: 10px solid #1098ad;
}

.container {
  width: 800px;
  margin: 0 auto;
}

2. Szekciók elrendezése

.main-header {
  background-color: #f7f7f7;
  padding: 20px 40px;
  margin-bottom: 60px;
}

article {
  margin-bottom: 60px;
}

.post-header {
  margin-bottom: 40px;
}

aside {
  background-color: #f7f7f7;
  border-top: 5px solid #1098ad;
  border-bottom: 5px solid #1098ad;
  padding: 50px 0;
  width: 500px;
}

3. Tipográfia

Itt találkozik a szelektorlista, a betűméret, a margó, a sormagasság, a nagybetűsítés és a középre igazítás. 

h1,
h2,
h3 {
  color: #1098ad;
}

p {
  font-size: 22px;
  line-height: 1.5;
  margin-bottom: 15px;
}

4. Class és ID

#author {
  font-style: italic;
  font-size: 18px;
}

#copyright {
  font-size: 16px;
}

.related-author {
  font-size: 18px;
  font-weight: bold;
}

.related {
  list-style: none;
}

5. Linkek – LVHA

a:link { ... }
a:visited { ... }
a:hover { ... }
a:active { ... }
Link → Visited → Hover → Active

6. Kép és navigáció

.post-img {
  width: 100%;
  height: auto;
}

nav a:link {
  margin-right: 30px;
  margin-top: 10px;
  display: inline-block;
}

7. Pozicionálás – TOP címke

h2 {
  position: relative;
}

h2::before {
  content: "TOP";
  position: absolute;
  top: -10px;
  right: -25px;
}

8. Végső ellenőrzőlista

  • Az oldal tartalma 800 px széles és középre igazított.
  • A fő fejlécnek van háttérszíne, paddingje és alsó margója.
  • A címsorok megfelelő méretűek és színűek.
  • A bekezdések sormagassága megfelelő.
  • A kapcsolódó lista nem jelenít meg felsorolásjelet.
  • A szerzők külön class/id szelektorral formázottak.
  • A linkek LVHA szerint működnek.
  • A fő kép kitölti a rendelkezésre álló szélességet.
  • A navigációs linkek között megfelelő térköz van.
  • A TOP címke a h2-höz képest van pozicionálva.
