11. évfolyam CSS 4. óra

Hiperhivatkozások formázása pszeudo-osztályokkal

A linkek négy fontos állapota: :link, :visited, :hover, :active.

Az óra célja

  • megérteni a linkek különböző állapotait;
  • használni a :link, :visited, :hover és :active pszeudo-osztályokat;
  • aláhúzást eltávolítani és visszaadni;
  • színt és betűstílust állapot szerint változtatni;
  • megjegyezni az LVHA sorrendet.

1. Miért pszeudo-osztállyal formázzuk a linkeket?

Egy egyszerű a szelektor minden horgonyelemet kijelölne. A pszeudo-osztályokkal külön tudjuk kezelni a link állapotait.

a {
  color: #1098ad;
}

2. :link – normál link

a:link {
  color: #1098ad;
  text-decoration: none;
}
A :link azokat a hivatkozásokat célozza, amelyeknek van href attribútumuk.

3. :visited – meglátogatott link

a:visited {
  color: #1098ad;
}

A tananyag példájában ugyanazt a színt használjuk, mint a normál linknél.

4. :hover – amikor fölé visszük az egeret

a:hover {
  color: orangered;
  font-weight: bold;
  text-decoration: underline orangered;
}

Hover állapotban megváltozik a szín, félkövér lesz a szöveg, és visszatér az aláhúzás.

5. :active – kattintás közben

a:active {
  background-color: black;
  font-style: italic;
}

Ez az állapot a kattintás pillanatában látható.

6. Az LVHA sorrend

Link → Visited → Hover → Active 
a:link { ... }
a:visited { ... }
a:hover { ... }
a:active { ... }

7. Közös órai feladat

  1. A normál link színe legyen #1098ad.
  2. Távolítsd el az aláhúzást text-decoration: none; segítségével.
  3. A meglátogatott link maradjon ugyanolyan színű.
  4. Hover állapotban legyen orangered és félkövér.
  5. Hover állapotban jelenjen meg az aláhúzás.
  6. Active állapotban legyen fekete háttér és dőlt szöveg.
  7. Próbáld ki mind a négy állapotot a böngészőben.

8. Ellenőrző kérdések

  1. Mit választ ki az a:link?
  2. Mire való az a:visited?
  3. Mikor érvényesül az a:hover?
  4. Mikor érvényesül az a:active?
  5. Mit csinál a text-decoration: none;?
  6. Mit jelent az LVHA rövidítés?
