Flexbox alapok

Egyetlen display: flex szabállyal egymás mellé rendezhetjük az elemeket, majd nagyon egyszerűen igazíthatjuk őket.

Esti ismétlés Jonas kurzusából:51. videó – Introduction to Flexbox

Az óra célja

  • Megérteni, mi a flex konténer és a flex elem.
  • A display: flex használata.
  • Az elemek függőleges igazítása align-items segítségével.
  • Az elemek vízszintes elhelyezése justify-content segítségével.
  • Megtapasztalni, miért egyszerűbb a Flexbox a régi elrendezési trükköknél.
Kezdőcsomag letöltése

1. Miért kell a Flexbox?

Ha több elemet egymás mellé szeretnénk tenni, igazítani és a közöttük maradó helyet elosztani, a Flexbox ezt néhány CSS-sorral megoldja.

Fontos: a Flexbox elsősorban elemek egy sorban vagy egy oszlopban történő elrendezésére és igazítására való.

2. Flex konténer és flex elemek

A Flexboxot mindig egy szülőelemen kapcsoljuk be:

.container {
  display: flex;
}

Ettől a konténer közvetlen gyermekei flex elemekké válnak.

Flex konténer: az az elem, amelyen display: flex van.
Flex elemek: a konténer közvetlen gyermekei.

3. Az első látványos változás

A kezdőfájlban a színes elemek egymás alatt jelennek meg. Add hozzá:

.container {
  display: flex;
}

A gyermekelemek azonnal egymás mellé kerülnek.

Alapértelmezésben az elemek vízszintesen sorakoznak fel.

4. Függőleges igazítás – align-items

Ha az egyik elem magasabb, alapértelmezésben a többi elem is megnyúlik. Az alapérték:

align-items: stretch;

Az elemeket középre igazíthatjuk:

.container {
  display: flex;
  align-items: center;
}

További fontos értékek:

ÉrtékHatás
stretchAlapértelmezés: az elemek megnyúlnak.
centerFüggőlegesen középre igazít.
flex-startA konténer elejéhez igazít.
flex-endA konténer végéhez igazít.

5. Vízszintes elhelyezés – justify-content

A justify-content azt szabályozza, hogyan helyezkedjenek el az elemek a konténerben vízszintesen.

.container {
  display: flex;
  justify-content: center;
}

Az órán két fontos értéket próbálunk ki:

  • center – az elemeket középre rendezi.
  • space-between – a fennmaradó helyet egyenletesen az elemek közé osztja.
justify-content: space-between;
A space-between esetén az első elem a konténer elején, az utolsó a végén helyezkedik el, a köztes hely pedig eloszlik a flex elemek között.

6. Órai gyakorlat

  1. Nyisd meg a kezdőcsomagot.
  2. Add a .container-hez a display: flex; szabályt.
  3. Próbáld ki az align-items értékeit: stretch, flex-start, center, flex-end.
  4. Végül hagyd center értéken.
  5. Próbáld ki a justify-content: center; beállítást.
  6. Ezután változtasd space-between-re.
  7. Méretezd át a böngészőablakot, és figyeld meg, hogyan alkalmazkodik az elrendezés.
Az óra végére elérendő CSS
.container {
  display: flex;
  align-items: center;
  justify-content: space-between;
}

7. Mini kihívás

Készíts egy egyszerű navigációs sávot három linkkel:

<nav class="menu">
  <a href="#">Kezdőlap</a>
  <a href="#">Cikkek</a>
  <a href="#">Kapcsolat</a>
</nav>

A cél: a linkek legyenek egy sorban, függőlegesen középre igazítva, és a rendelkezésre álló hely oszoljon el közöttük.

Segítség
.menu {
  display: flex;
  align-items: center;
  justify-content: space-between;
}

8. Ellenőrző kérdések

  1. Melyik elemen kell megadni a display: flex szabályt?
  2. Mit nevezünk flex elemnek?
  3. Mire használjuk az align-items tulajdonságot?
  4. Mit csinál az align-items: center?
  5. Mit csinál a justify-content: space-between?
Válaszok
  1. A szülő-, vagyis flex konténeren.
  2. A flex konténer közvetlen gyermekét.
  3. Az elemek keresztirányú, ebben a példában függőleges igazítására.
  4. Középre igazítja a flex elemeket a konténer magasságán belül.
  5. A szabad helyet egyenletesen az elemek közé osztja.
