Flexbox alapok

Flex konténer, főtengely és kereszttengely, irány, igazítás, térköz és tördelés.

  • Megérteni a főtengely és a kereszttengely szerepét.

  • Az elemek elhelyezése justify-content és align-items segítségével.

Kezdőcsomag letöltése

1. Miért kell a Flexbox?

Ha több elemet szeretnénk egy sorban vagy egy oszlopban elrendezni, középre igazítani, közöttük helyet hagyni vagy a fennmaradó helyet elosztani, a Flexbox erre készült.

Alapötlet: a Flexbox egy egydimenziós elrendezési rendszer. Egyszerre főként egy sor vagy egy oszlop elrendezését kezeljük vele.

2. Flex konténer és flex elemek

A Flexboxot a szülőelemen kapcsoljuk be:

.container {
  display: flex;
}

A konténer közvetlen gyermekei flex elemekké válnak.

Flex konténer: amelyen display: flex van.
Flex elemek: a flex konténer közvetlen gyermekei.

3. Főtengely és kereszttengely

A Flexbox megértéséhez ezt a két irányt kell fejben tartani:

kereszttengely
1234
főtengely →

Alapértelmezett flex-direction: row esetén a főtengely vízszintes, a kereszttengely függőleges.

Megjegyzendő: a justify-content mindig a főtengelyen, az align-items mindig a kereszttengelyen igazít.

4. Az első látványos változás – display: flex

A kezdőfájlban a színes elemek egymás alatt jelennek meg. Add hozzá:

.container {
  display: flex;
}

A közvetlen gyermekek alapértelmezésben egy sorba kerülnek.

5. Az irány megadása – flex-direction

A flex-direction határozza meg a főtengely irányát.

ÉrtékMit csinál?
rowBalról jobbra, sorban. Ez az alapérték.
row-reverseSorban, de fordított irányban.
columnFentről lefelé, oszlopban.
column-reverseOszlopban, fordított irányban.
.container {
  display: flex;
  flex-direction: column;
}
HTMLésCSS
Fontos: ha column-ra váltunk, a főtengely függőleges lesz. Emiatt a justify-content és az align-items látható iránya is megváltozik.

6. Elhelyezés a főtengelyen – justify-content

A justify-content a főtengely mentén osztja el a flex elemeket és a szabad helyet.

ÉrtékHatás
flex-startAz elemek a főtengely elején vannak.
flex-endAz elemek a főtengely végén vannak.
centerAz elemek egy csoportban középre kerülnek.
space-betweenAz első és utolsó elem a két szélen, a köztes hely az elemek között oszlik el.
space-aroundMinden elem körül jut hely; a széleken fele akkora tér látszik.
space-evenlyMinden rés azonos méretű, a széleken is.
.container {
  display: flex;
  justify-content: space-between;
}

7. Igazítás a kereszttengelyen – align-items

Az align-items a kereszttengely mentén igazítja a flex elemeket.

ÉrtékHatás
stretchAlapértelmezés: az elemek kitöltik a rendelkezésre álló keresztirányú méretet, ha nincs saját méretük.
flex-startA kereszttengely elejéhez igazít.
centerKözépre igazít a kereszttengely mentén.
flex-endA kereszttengely végéhez igazít.
baselineA szövegek alapvonalát igazítja egymáshoz.
.container {
  display: flex;
  align-items: center;
}

8. Térköz az elemek között – gap

Flexboxban nem kell minden elemnek külön jobb margót adni. A konténeren megadhatjuk a közös térközt:

.container {
  display: flex;
  gap: 20px;
}

A gap csak az elemek között hoz létre helyet, a konténer szélén nem.

row-gap és column-gap külön is megadható, de kezdésként a gap a legegyszerűbb.

9. Mi történik, ha nem férnek el? – flex-wrap

Alapból a Flexbox megpróbálja egy sorban tartani az elemeket. Ezt a nowrap alapérték adja.

.container {
  display: flex;
  flex-wrap: wrap;
}

A wrap engedi, hogy az elemek új sorba kerüljenek, ha elfogy a hely.

12345678

wrap-reverse is létezik, de ezt elég most felismerni.

10. Egyben a legfontosabb konténer-tulajdonságok

.container {
  display: flex;
  flex-direction: row;
  justify-content: space-between;
  align-items: center;
  gap: 20px;
  flex-wrap: wrap;
}
Ne magold a kódot vakon: először mindig döntsd el, mi a főtengely, majd azt, hogy a főtengelyen vagy a kereszttengelyen szeretnél igazítani.

11. Órai gyakorlat

  1. Nyisd meg a kezdőcsomagot.
  2. Add a .container-hez a display: flex; szabályt.
  3. Próbáld ki: flex-direction: row, majd column.
  4. Állítsd vissza row-ra.
  5. Próbáld ki a justify-content értékeit: flex-start, center, space-between, space-around, space-evenly.
  6. Próbáld ki az align-items értékeit: stretch, flex-start, center, flex-end, baseline.
  7. Adj 20px értékű gap-et.
  8. Kapcsold be a flex-wrap: wrap-ot, majd szűkítsd a böngészőablakot.
Az óra végére elérendő CSS
.container {
  display: flex;
  flex-direction: row;
  align-items: center;
  justify-content: space-between;
  gap: 20px;
  flex-wrap: wrap;
}

12. Mini kihívás – navigációs sáv

Készíts három linkből egyszerű menüt:

<nav class="menu">
  <a href="#">Kezdőlap</a>
  <a href="#">Cikkek</a>
  <a href="#">Kapcsolat</a>

Segítség
.menu {
  display: flex;
  align-items: center;
  gap: 30px;
}

13. Ellenőrző kérdések

  1. Melyik elemen adjuk meg a display: flex szabályt?
  2. Mik lesznek flex elemek?
  3. Mi a főtengely alapértelmezett row esetén?
  4. Mire hat a justify-content?
  5. Mire hat az align-items?
  6. Mit változtat meg a flex-direction: column?
  7. Mi a különbség a gap és az elemekre adott margó között?
  8. Mikor hasznos a flex-wrap: wrap?
Válaszok
  1. A szülőelemen, amely flex konténerré válik.
  2. A flex konténer közvetlen gyermekei.
  3. Vízszintes.
  4. A főtengely menti elhelyezésre.
  5. A kereszttengely menti igazításra.
  6. A főtengelyt függőlegesre állítja, ezért az igazítások iránya is ehhez igazodik.
  7. A gap a konténeren ad egységes helyet a flex elemek között, nem kell minden elem margóját külön kezelni.
  8. Ha kevés a hely, és szeretnénk, hogy az elemek új sorba törhessenek.
