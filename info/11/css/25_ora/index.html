11. évfolyam Reszponzív webdesign 25. óra

Reszponzív webdesign alapjai

Mitől lesz egy weboldal jól használható asztali gépen, tableten és mobilon is?

Esti ismétlés Jonas kurzusából:104. videó – Responsive Design Principles

Az óra célja

  • Megérteni a reszponzív webdesign fogalmát.
  • Megismerni a reszponzív oldalak négy fontos építőelemét.
  • Megérteni, miért nem külön technológia a reszponzív webdesign.
  • Különbséget tenni a desktop-first és a mobile-first megközelítés között.
  • Felkészülni a következő órák rem, max-width és media query témáira.

1. Mit jelent az, hogy reszponzív?

A reszponzív weboldal elrendezése és megjelenése alkalmazkodik az aktuális nézetablak méretéhez. Nem csak az eszköz számít: ugyanazon a számítógépen is lehet keskeny vagy széles a böngészőablak.

Cél: ugyanaz az oldal maradjon jól olvasható és használható asztali gépen, tableten és telefonon is.

2. Nem egy új technológia

A reszponzív webdesign nem egy külön nyelv vagy új CSS-rendszer. A már ismert HTML- és CSS-eszközöket használjuk úgy, hogy az oldal képes legyen alkalmazkodni.

FlexboxGrid%remmax-widthmedia query

A Flexbox és a Grid már önmagában is sokkal rugalmasabbá teszi az elrendezést, mint a kizárólag fix pixeles méretezés.

4. Folyékony elrendezés

Korábban sokszor fix szélességet használtunk:

.container {
  width: 1200px;
}

Ez nagy képernyőn működhet, de egy keskeny kijelzőn könnyen kilóghat. Reszponzív oldalon gyakran a rendelkezésre álló helyhez igazítjuk az elemeket.

.container {
  width: 90%;
  max-width: 1200px;
}
A max-width működését a következő Jonas-videóban és a következő órán részletesen megnézzük.

5. Rugalmas képek

Egy nagy kép fix mérete könnyen szélesebb lehet a mobil kijelzőjénél. Gyakori alapbeállítás:

img {
  max-width: 100%;
}

Így a kép legfeljebb akkora lesz, amekkora hely a szülőelemben rendelkezésre áll, de nem kényszerítjük feleslegesen nagyobbra.

6. Media query – egyelőre csak az ötlet

A media query segítségével megmondhatjuk: ha a nézetablak elér egy adott szélességet, használj más CSS-szabályokat.

@media (max-width: 700px) {
  .cards {
    grid-template-columns: 1fr;
  }
}
A media queryt most még nem kell megtanulni. Külön órán fogjuk gyakorolni.

7. Töréspont – breakpoint

Azt a szélességet, ahol az oldal elrendezésén vagy stílusán változtatunk, töréspontnak nevezzük.

Például lehet, hogy három kártya szépen elfér egymás mellett nagy képernyőn, de keskenyebb ablaknál már egy oszlopba kell őket rendezni.

A töréspontot nem azért választjuk, mert „ez egy iPhone szélessége”, hanem azért, mert ott kezd rosszul működni az adott elrendezés.

8. Desktop-first és mobile-first

Desktop-first

Először a nagy képernyős változat készül el, majd media querykkel igazítjuk kisebb képernyőkre.

Jonas ebben a projektben ezt használja.

Mobile-first

Először a kis képernyős változat készül el, majd media querykkel bővítjük nagyobb képernyőkre.

Modern projektekben nagyon gyakori megközelítés.

Mindkettővel lehet jó reszponzív oldalt készíteni. A lényeg az, hogy értsük az alkalmazkodó elrendezés működését.

9. Gyors vizsgálat a böngészőben

  1. Nyiss meg egy általad készített oldalt.
  2. Nyisd meg a DevTools-t.
  3. Kapcsold be az eszköznézetet / responsive módot.
  4. Fokozatosan szűkítsd a nézetet.
  5. Figyeld meg, melyik résznél kezd szétesni az oldal.
Feladat: jegyezz fel legalább három problémát, amely keskeny képernyőn jelentkezik. Például: kilógó tartalom, túl nagy betű, egymásra csúszó elemek, túl széles navigáció vagy kép.

Mit vigyél el ebből az órából?

  • A reszponzív webdesign célja, hogy az oldal különböző nézetablakokon is jól használható legyen.
  • Nem külön technológia, hanem több CSS-technika együttese.
  • A négy fontos elem: folyékony layout, reszponzív egységek, rugalmas képek és media queryk.
  • A Flexbox és a Grid már jó alapot ad a rugalmas elrendezéshez.
  • A következő lépés a rem és a max-width részletes megértése.
