Media query-k alapjai

Megírjuk az első media queryt, megvizsgáljuk a max-width feltételt, és megnézzük, mi történik, amikor több media query egyszerre érvényes.

Esti ismétlés Jonas kurzusából:129. videó – How Media Queries Work

Az óra célja

  • Megérteni, hogy a media query egy feltételes CSS-blokk.
  • Használni a desktop-first max-width feltételt.
  • Megfigyelni a globális CSS és a media queryben lévő felülírás kapcsolatát.
  • Megérteni, hogy több media query egyszerre is érvényes lehet.
  • Responsive módban pontosan ellenőrizni a töréspontot.
Kezdőcsomag letöltése Megoldás letöltése

1. Mi a media query?

A media query egy CSS-feltétel. A benne lévő szabályokat a böngésző csak akkor alkalmazza, ha a feltétel igaz.

@media (max-width: 600px) {
  .main-header {
    background-color: blue;
  }
}

A feltétel kérdése: a nézetablak szélessége legfeljebb 600 px? Ha igen, a szabály érvényes; ha nem, a böngésző nem alkalmazza.

Nézetablak: a böngészőoldal számára rendelkezésre álló látható terület. Nem feltétlenül azonos az eszköz teljes képernyőjével.

2. Desktop-first és max-width

Ebben a projektben először a nagy képernyős változat készül el. Ezután max-width media querykkel módosítjuk az oldalt a keskenyebb nézetekhez.

/* A közlekedési oldal nagy képernyős fejléce */
.main-header {
  background-color: #087f5b;
}

/* 1200 px-en és alatta */
@media (max-width: 1200px) {
  .main-header {
    background-color: orangered;
  }
}
max-width: 1200px esetén a media query 1200 px-en még működik, 1201 px-en már nem.

Mobile-first megközelítésnél gyakran min-width feltételeket használunk. Ezt most csak összehasonlításként jegyezzük meg.

3. Nem cseréljük le a teljes CSS-t

A media queryben csak azt írjuk felül, aminek az adott szélességnél változnia kell. Minden más globális szabály továbbra is érvényes.

.related-post {
  padding: 32px;
  background-color: white;
}

@media (max-width: 600px) {
  .related-post {
    padding: 20px;
  }
}

600 px-en és alatta csak a padding változik. A fehér háttér megmarad, mert azt a media query nem írja felül.

4. Két media query egyszerre

@media (max-width: 1200px) {
  .main-header { background-color: orangered; }
}

@media (max-width: 600px) {
  .main-header {
    background-color: blue;
    border: 8px solid lightblue;
  }
}

400 px mindkét maximumértéknél kisebb, ezért mindkét media query szabályai alkalmazhatók.

5. Mi történik ütközéskor?

Ha két egyszerre érvényes media query azonos szelektorral ugyanazt a tulajdonságot állítja, a kaszkád szabályai döntenek. Azonos eredet, fontosság és specifikusság esetén a CSS-ben később szereplő deklaráció nyer.

Nem azért nyer a 600 px-es szabály, mert kisebb a száma, hanem azért, mert ebben a példában később szerepel a kódban és azonos erősségű.
Kísérlet: cseréld fel a két media query sorrendjét! Figyeld meg, hogy a közös background-color eredménye megváltozik, de a csak egy helyen megadott keret továbbra is látszik.

6. Első közös kísérlet

  1. Nyisd meg a kezdőcsomagot Live Serverrel.
  2. A CSS végére írj egy max-width: 1200px media queryt.
  3. Változtasd a .main-header hátterét narancsvörösre.
  4. Írj alá egy max-width: 600px media queryt.
  5. Adj a közlekedési oldal fejlécének kék hátteret és feltűnő keretet.
  6. Méretezd át az ablakot, és figyeld meg a két határértéket.
  7. DevToolsban ellenőrizd, mely deklaráció aktív és melyik van áthúzva.
A feltűnő színek most kizárólag a működés szemléltetésére szolgálnak. A kész Közlekedési magazinban a töréspontoknál az elrendezést módosítjuk, nem ilyen színeket használunk.

7. DevTools Responsive mód

  1. Nyisd meg a fejlesztői eszközöket.
  2. Kapcsold be az eszköznézetet / Toggle device toolbar módot.
  3. Az eszközlistán válaszd a Responsive lehetőséget.
  4. Írj be pontosan 600 px szélességet: a 600-as query érvényes.
  5. Írj be 601 px-et: a 600-as query már nem érvényes.
  6. Próbáld ki ugyanezt 1200 és 1201 px-en.
A Responsive módot használjuk az elrendezés vizsgálatára. A következő órán tanuljuk meg, hogyan választunk valódi töréspontokat; a 600 és 1200 px most szemléltető érték.

8. Önálló feladat – valódi elrendezési változás

  1. A 600 px-es media queryben rendezd a három közlekedési témát egyetlen oszlopba.
  2. Csökkentsd a főcím méretét és a fejléc függőleges térközét.
  3. Csökkentsd a konténer oldalsó paddingjét.
  4. Ellenőrizd, hogy 600 px-en a mobilos szabályok érvényesek, 601 px-en pedig nem.
  5. DevToolsban keresd meg a globális és a felülíró deklarációkat.
Segítség
@media (max-width: 600px) {
  .related {
    grid-template-columns: 1fr;
  }
}

9. Ellenőrző kérdések

  1. Mit vizsgál a @media (max-width: 600px) feltétel?
  2. Érvényes-e a feltétel pontosan 600 px-en? És 601 px-en?
  3. Mi történik a media queryn kívüli szabályokkal?
  4. 400 px-en melyik érvényes a 600 és 1200 px-es queryk közül?
  5. Mi dönt azonos erősségű, ütköző deklarációknál?
  6. Mire használjuk a DevTools Responsive módját?
  7. Miért csak példák most a 600 és 1200 px-es értékek?
Válaszok
  1. Azt, hogy a nézetablak szélessége legfeljebb 600 px-e.
  2. 600 px-en igen, 601 px-en nem.
  3. Továbbra is érvényesek, ha nem írjuk felül őket.
  4. Mindkettő.
  5. Azonos specifikusságnál a később szereplő deklaráció.
  6. Különböző nézetablak-szélességek pontos vizsgálatára.
  7. Mert a valódi töréspontot az elrendezés tartalma alapján választjuk ki; ezt a következő órán tanuljuk.

Mit vigyél el ebből az órából?

  • A media query feltételesen alkalmaz CSS-szabályokat.
  • A max-width desktop-first megközelítésben a megadott szélességen és az alatt érvényes.
  • Több media query egyszerre is működhet.
  • A media querykben célzottan felülírjuk a globális CSS egy részét.
  • Az ütközéseket továbbra is a kaszkád és a specifikusság szabályai döntik el.
  • A következő lépés a megfelelő töréspontok kiválasztása.
