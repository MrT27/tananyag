11. évfolyam Reszponzív webdesign 26. óra

rem és max-width

Rugalmas méretezés úgy, hogy az oldal alkalmazkodjon a rendelkezésre álló helyhez és a felhasználó beállításaihoz.

Esti ismétlés Jonas kurzusából:105. videó – How rem and max-width Work

Az óra célja

  • Megérteni a width és a max-width közötti különbséget.
  • Megérteni, mit jelent a rem egység.
  • Látni, hogyan függ a rem a gyökérelem betűméretétől.
  • Megismerni a 62.5%-os gyökér-betűméret technikát.
  • Gyakorlatban rugalmasabb konténert és méretezést készíteni.

1. Mi a gond a fix width-del?

.test {
  width: 1000px;
}

Az elem akkor is 1000 pixel széles marad, ha a rendelkezésre álló hely ennél kisebb. Emiatt a tartalom kilóghat a nézetablakból.

Fix szélesség: jó lehet bizonyos helyzetekben, de reszponzív layout fő konténerénél könnyen problémát okozhat.

2. A max-width működése

.test {
  max-width: 1000px;
}

A max-width azt mondja: az elem legfeljebb 1000 pixel széles lehet.

  • Ha a szülő ennél szélesebb, az elem 1000 px marad.
  • Ha a szülő keskenyebb, az elem hozzá igazodik.
Röviden: a max-width felső korlátot ad, de engedi, hogy az elem kisebb legyen.

3. Mi az a rem?

A rem a dokumentum gyökérelemének, vagyis a html elemnek a betűméretéhez viszonyított egység.

Ha nem állítunk be mást, a böngésző alapértelmezett betűmérete általában 16 px:

1rem = 16px
2rem = 32px
4rem = 64px

Például:

.box {
  max-width: 50rem;
  padding: 4rem;
  font-size: 2rem;
}

Alapértelmezett 16 px-es gyökérméretnél ez 800 px maximális szélességet, 64 px paddinget és 32 px betűméretet jelent.

4. Miért hasznos a rem?

Ha sok méretet rem-ben adunk meg, akkor a gyökér-betűméret változtatása egyszerre több méretet is arányosan módosít.

html {
  font-size: 20px;
}

Ekkor 1rem = 20px, tehát minden rem-ben megadott érték nagyobb lesz.

Ezért a rem jól használható reszponzív méretezéshez: a méretek egymással arányban maradnak.

5. A 62.5%-os technika

Jonas azt a gyakori trükköt használja, hogy a gyökér betűméretét 62.5%-ra állítja:

html {
  font-size: 62.5%;
}

Ha a böngésző alapértéke 16 px, akkor:

16px × 0.625 = 10px

Így a számolás egyszerűvé válik:

1rem = 10px
1.6rem = 16px
2.4rem = 24px
5rem = 50px
Miért százalék és nem fix 10px? Így a beállítás továbbra is a felhasználó böngészőben választott alap-betűméretéhez viszonyul.

6. Együtt használva

html {
  font-size: 62.5%;
}

.container {
  max-width: 120rem;
  margin: 0 auto;
  padding: 0 3.2rem;
}

A konténer legfeljebb 1200 px széles, kisebb nézetablaknál azonban össze tud húzódni. A belső térközök is rem-ben vannak megadva.

7. Órai gyakorlat

Töltsd le a kezdőcsomagot, majd alakítsd át a merev dobozt rugalmasabbá.

  1. Próbáld ki először a width: 1000px beállítást.
  2. Szűkítsd a böngészőablakot, és figyeld meg a problémát.
  3. Cseréld max-width: 1000px-re.
  4. Állítsd be a html { font-size: 62.5%; } szabályt.
  5. A szélességet, paddinget és betűméretet írd át rem-re.
  6. Szűkítsd újra a böngészőt, és hasonlítsd össze az eredményt.
Cél: a doboz nagy képernyőn ne nőjön egy megadott méret fölé, kis képernyőn pedig ne lógjon ki.

8. Ellenőrző kérdések

  1. Mi a különbség a width és a max-width között?
  2. Mihez viszonyul a rem?
  3. Alapértelmezett 16 px-es gyökérméretnél hány pixel a 2rem?
  4. Miért használ Jonas 62.5%-ot a html betűméreténél?
  5. Miért jobb ebből a szempontból a százalékos gyökérméret, mint a fix 10px?
  6. Mitől lesz a max-width-es konténer rugalmas?

Mit vigyél el ebből az órából?

  • A max-width maximális szélességet ad, de engedi az elemet összemenni.
  • A rem a gyökérelem betűméretéhez viszonyul.
  • A 62.5%-os technikával alapbeállítás mellett könnyen számolhatóvá válik: 1rem ≈ 10px.
  • A százalékos gyökérméret megtartja a kapcsolatot a böngésző alap-betűméretével.
  • A max-width és a rem fontos alapjai a reszponzív oldalaknak.
