11. évfolyam CSS Alapok

Betű- és szövegformázás CSS-ben

A képernyőképeken szereplő alapvető CSS-tulajdonságok leírva, rövid magyarázattal.

A teljes kód

Az alábbi CSS a képeken látható szabályokat foglalja össze. 

h1 {
  font-size: 26px;
  font-family: sans-serif;
  text-transform: uppercase;
  font-style: italic;
}

h2 {
  font-size: 40px;
  font-family: sans-serif;
}

h3 {
  font-size: 30px;
  font-family: sans-serif;
}

h4 {
  font-size: 20px;
  font-family: sans-serif;
  text-transform: uppercase;
  text-align: center;
}

p {
  font-size: 22px;
  font-family: sans-serif;
  line-height: 1.5;
}

li {
  font-size: 20px;
  font-family: sans-serif;
}
CSS-kód letöltése

Mit csinálnak ezek a tulajdonságok?

Tulajdonság Jelentése
font-size A betű méretét állítja be.
font-family A használt betűcsaládot adja meg.
text-transform: uppercase A megjelenő szöveget nagybetűssé alakítja.
font-style: italic Dőlt betűs megjelenítést állít be.
text-align: center Középre igazítja a szöveget.
line-height: 1.5 A sorok közötti távolságot a betűméret másfélszeresére állítja.

Fontos megfigyelés

A font-family: sans-serif; több szabályban is ismétlődik. Ez vezet át a következő CSS-témához: hogyan tudjuk a szelektorokat kombinálni, és ugyanazt a szabályt egyszerre több elemre alkalmazni.
