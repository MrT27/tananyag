11. évfolyam HTML/CSS lezárás 38. óra

CSS-effektek és mozgás

Állapotváltozásokat teszünk láthatóvá úgy, hogy a mozgás segítse, ne zavarja a használatot.

Az óra célja

  • Az opacity és outline szerepe.
  • Finom átmenetek készítése transition segítségével.
  • Mozgatás és méretezés transform használatával.
  • Egyszerű @keyframes animáció és csökkentett mozgás.
Kezdőcsomag letöltése

1. opacity

.halvany { opacity: 0.55; }

A 0 teljesen átlátszó, az 1 teljesen látható. Az érték az elemre és gyermekeire is hat.

Az opacity: 0 nem távolítja el az elemet: továbbra is helyet foglalhat és fókuszálható lehet.

2. outline és billentyűzetes fókusz

a:focus {
  outline: 3px solid #f08c00;
  outline-offset: 4px;
}

Az outline nem növeli a doboz méretét. A fókuszjelzést ne tüntessük el anélkül, hogy legalább ilyen jól látható jelzést adnánk helyette.

3. transition

.kartya {
  transition: transform 0.25s, box-shadow 0.25s;
}
.kartya:hover {
  transform: translateY(-6px);
  box-shadow: 0 12px 24px rgba(0, 0, 0, 0.15);
}

Az átmenetet az alapállapotba írjuk, így oda-vissza működik. all helyett a valóban változó tulajdonságokat soroljuk fel.

4. transform

.ikon:hover { transform: rotate(8deg) scale(1.08); }
.gomb:active { transform: scale(0.97); }
  • translate(): eltolás;
  • scale(): méretezés;
  • rotate(): forgatás.

A transzformáció nem rendezi át úgy a környező elemeket, mint a margin módosítása.

5. @keyframes

@keyframes jelzes {
  0%, 100% { opacity: 1; }
  50% { opacity: 0.45; }
}
.allapotjelzo {
  animation: jelzes 1.5s ease-in-out 3;
}

A kulcskockák az animáció állomásai. A példában az animáció csak háromszor fut le.

6. Csökkentett mozgás

@media (prefers-reduced-motion: reduce) {
  * {
    animation: none;
    transition: none;
  }
}

A felhasználó kérheti a mozgások csökkentését. Az oldal ehhez médiakérdéssel alkalmazkodhat.

7. Órai feladat

  1. A kártyák két tulajdonsága kapjon transitiont.
  2. Hover állapotban emelkedjenek 6 pixelt és kapjanak árnyékot.
  3. A gomb aktív állapotban legyen kissé kisebb.
  4. A fókusz kapjon jól látható outline-t.
  5. Egy jelzőn készíts háromszor lefutó opacity animációt.
  6. Adj prefers-reduced-motion szabályt.
  7. Tab billentyűvel és egérrel is ellenőrizd.

8. Kitekintés: preprocesszor

A Sass/SCSS kényelmi lehetőségeket ad, majd hagyományos CSS-t készít.

// SCSS – a böngésző ezt nem közvetlenül olvassa
$kiemelo: #e8590c;
.gomb { background-color: $kiemelo; }

/* Elkészített CSS */
.gomb { background-color: #e8590c; }
Nem telepítünk preprocesszort; a fogalom felismerése a cél.
