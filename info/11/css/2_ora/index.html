11. évfolyam CSS 2. óra

Színek, háttérszínek és szegélyek CSS-ben

RGB, hexadecimális színek, háttérszín, szegélyek és a VS Code színválasztója.

Az óra célja

  • megérteni az RGB színmodell alapját;
  • RGB és hexadecimális színeket felismerni;
  • szöveg- és háttérszínt beállítani;
  • szegélyeket készíteni;
  • a VS Code színválasztóját használni.

1. RGB színmodell

Az RGB a Red, Green, Blue rövidítése. Mindhárom csatorna 0 és 255 közötti értéket kaphat.

rgb(255, 0, 0)     /* piros */
rgb(0, 255, 0)     /* zöld */
rgb(0, 0, 255)     /* kék */
rgb(255, 255, 255) /* fehér */
rgb(0, 0, 0)       /* fekete */

2. Hexadecimális színek

#1098ad
#444444
#f7f7f7

Rövidíthető például: #444444 → #444, #ffffff → #fff.

3. Átlátszóság

rgba(244, 179, 63, 0.3)

Az utolsó érték az alfa: 0 teljesen átlátszó, 1 teljesen fedő.

4. Szövegszín

h1,
h2,
h3 {
  color: #1098ad;
}

body {
  color: #444;
}

5. Háttérszín és osztály

.main-header {
  background-color: #f7f7f7;
}
A .main-header osztályszelektor. Így csak a fő fejlécet formázzuk, nem minden header elemet.

6. Szegély

border: 5px solid #1098ad;

A három érték: vastagság, stílus, szín.

7. Szegély csak felül és alul

aside {
  background-color: #f7f7f7;
  border-top: 5px solid #1098ad;
  border-bottom: 5px solid #1098ad;
}

8. VS Code színválasztó

Ha a színkód fölé visszük az egeret, a VS Code színválasztót jeleníthet meg. Ezzel gyorsan válthatunk színt és átlátszóságot.

9. Közös órai feladat

  1. A body szövegszíne legyen #444.
  2. A h1, h2, h3 legyen #1098ad.
  3. A fő fejléc kapjon main-header osztályt.
  4. A fő fejléc háttere legyen #f7f7f7.
  5. Az aside kapja meg ugyanezt a hátteret.
  6. Az aside felső és alsó szegélye legyen 5px solid #1098ad.
  7. Próbáld ki a VS Code színválasztóját.

10. Ellenőrző kérdések

  1. Mit jelent az RGB?
  2. Milyen értékeket vehet fel egy RGB-csatorna?
  3. Mit jelent a #1098ad jelölés?
  4. Mire való a color?
  5. Mire való a background-color?
  6. Mit jelent a border: 5px solid #1098ad;?
  7. Miért jobb itt a .main-header, mint a sima header?
