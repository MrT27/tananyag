Flexbox igazítás és térközök

A flex elemek igazítása, egyetlen elem külön beállítása, a sorrend módosítása és a gap használata.

Esti ismétlés Jonas kurzusából:53. videó – Spacing and Aligning Flex Items

Az óra célja

  • A főtengely és a kereszttengely szerepének megértése.
  • A justify-content és az align-items biztos használata.
  • Egyetlen flex elem külön igazítása align-self segítségével.
  • A flex elemek sorrendjének módosítása az order tulajdonsággal.
  • Egységes térköz létrehozása a flex elemek között a gap segítségével.
Kezdőcsomag letöltése

1. Ismétlés: két tengely

Alapértelmezésben a flex elemek egy sorban helyezkednek el. Ilyenkor a főtengely vízszintes, a kereszttengely függőleges.

Gyakorlati szabály:
justify-content → igazítás a főtengely mentén
align-items → igazítás a kereszttengely mentén
.container {
  display: flex;
  justify-content: center;
  align-items: center;
}
Most még maradunk a normál, vízszintes flex elrendezésnél. A tengelyek irányának megváltoztatását később vesszük elő.

2. Egyetlen elem külön igazítása – align-self

Az align-items minden flex elemre egyszerre hat. Ha viszont csak egy elemet szeretnénk másképp igazítani, akkor az align-self tulajdonságot használjuk.

.container {
  display: flex;
  align-items: center;
}

.elem-1 {
  align-self: flex-start;
}

Így minden elem középen marad, az első viszont a konténer tetejéhez igazodik.

Hasznos értékek: flex-start, center, flex-end, stretch.

3. Sorrend módosítása – order

A flex elemek alapértelmezett order értéke 0. Kisebb érték előrébb, nagyobb érték hátrébb helyezi az elemet.

.elem-6 {
  order: -1;
}

Az elem így a többi, order: 0 értékű elem elé kerül.

.elem-5 {
  order: 1;
}

Ez az elem a többi után jelenik meg.

Fontos: az order csak a vizuális sorrendet módosítja. A HTML-ben az elemek eredeti sorrendje nem változik meg. Emiatt csak indokolt esetben használjuk.

4. Térköz a flex elemek között – gap

Régebben gyakran margókkal hoztunk létre helyet az elemek között:

.elem {
  margin-right: 30px;
}

Ennek hátránya, hogy az utolsó elem után is marad margó, amit külön kellene eltávolítani.

Flexboxnál egyszerűbb megoldás:

.container {
  display: flex;
  gap: 30px;
}
A gap a flex elemek közé tesz helyet. Nem kell külön az egyes elemek margóival foglalkoznunk.

5. justify-content és gap nem ugyanaz

A két megoldás gyakran együtt szerepel, de más feladatuk van:

TulajdonságFeladata
justify-contentA konténerben rendelkezésre álló szabad hely elosztását és az elemek főtengely menti igazítását szabályozza.
gapKonkrét, állandó távolságot ad a szomszédos flex elemek közé.
.container {
  display: flex;
  justify-content: center;
  gap: 30px;
}

Ebben az esetben az egész elemsor középre kerül, az egyes elemek között pedig 30 px távolság lesz.

6. Órai gyakorlat

  1. Nyisd meg a kezdőcsomagot.
  2. Állítsd be: justify-content: center;.
  3. Próbáld ki ugyanezt space-between értékkel is, majd állítsd vissza flex-start-ra.
  4. Az első elemet igazítsd külön a konténer tetejéhez: align-self: flex-start;.
  5. A hatodik elemet helyezd a sor elejére order: -1; segítségével.
  6. Adj 30px távolságot az elemek közé a gap tulajdonsággal.
  7. Módosítsd az ablak méretét, és figyeld meg az eredményt.
Az óra végére elérendő lényeg
.container {
  display: flex;
  align-items: center;
  justify-content: flex-start;
  gap: 30px;
}

.elem-1 {
  align-self: flex-start;
}

.elem-6 {
  order: -1;
}

7. Mini feladat – navigáció

Készíts négy linkből álló navigációt. A linkek legyenek egy sorban, függőlegesen középre igazítva, és legyen közöttük 24 px távolság.

<nav class="menu">
  <a href="#">Kezdőlap</a>
  <a href="#">Cikkek</a>
  <a href="#">Rólunk</a>
  <a href="#">Kapcsolat</a>
</nav>
Segítség
.menu {
  display: flex;
  align-items: center;
  gap: 24px;
}

8. Ellenőrző kérdések

  1. Melyik tulajdonság igazítja az elemeket a főtengely mentén?
  2. Melyik tulajdonság igazítja az összes flex elemet a kereszttengely mentén?
  3. Hogyan tudunk csak egyetlen flex elemet külön igazítani?
  4. Mi az alapértelmezett order érték?
  5. Mit csinál az order: -1?
  6. Miért kényelmesebb a gap, mint minden flex elemre külön margót tenni?
Válaszok
  1. justify-content.
  2. align-items.
  3. Az adott flex elemen az align-self tulajdonsággal.
  4. 0.
  5. A többi, 0 értékű elem elé helyezi az elemet.
  6. A távolságot a konténeren adjuk meg, csak az elemek közé kerül, és nem kell az utolsó elem margóját külön kezelni.
