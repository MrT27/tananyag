Logikai operátorok a gyakorlatban

Jonas példájában a program arról dönt, hogy Sarah vezessen-e.

Az && és a || operátorhoz kétszer gépeld be ugyanazt a jelet, szóköz nélkül. Az ! egyszer szerepel.

Ha más jel jelenik meg, ellenőrizd az aktív beviteli kiosztást. Macen a menüsor beviteli menüjében válaszd a Billentyűzetnéző megjelenítése lehetőséget.

Jogosítvány és jó látás

Az előző leckében a jogosítvány volt az A, a jó látás a B feltétel. Most adjunk nekik beszédes változónevet.

const hasDriversLicense = true;
const hasGoodVision = true;

console.log(hasDriversLicense && hasGoodVision);
console.log(hasDriversLicense || hasGoodVision);
console.log(!hasDriversLicense);

Így a kimenet sorban true, true, false. Írd át a hasGoodVision kezdőértékét false-ra. Az ÉS eredménye hamis lesz, mert az egyik feltétel nem teljesül. A VAGY igaz marad, mert a jogosítvány megvan. A ! az adott kifejezésben megfordítja az értéket, a változó értéke közben megmarad.

Az eredményt felhasználjuk egy döntéshez

Írd az előző példa alá. A shouldDrive a két feltétel közös eredményét tárolja.

const shouldDrive = hasDriversLicense && hasGoodVision;

if (shouldDrive) {
  console.log("Sarah vezethet.");
} else {
  console.log("Valaki más vezessen.");
}

Ha a látás feltétele hamis, az else fut. Ha mindkét feltétel igaz, Sarah vezethet. Jonas ezután közvetlenül az if-be írja a kifejezést: if (hasDriversLicense && hasGoodVision). Mindkét változat ugyanazt a döntést hozza.

Három feltétel összekapcsolása

Állítsd vissza a hasGoodVision értékét igazra, majd add hozzá a harmadik feltételt. Jonas ezt nevezi C-nek.

const isTired = true;

console.log(hasDriversLicense || hasGoodVision || isTired);
console.log(hasDriversLicense && hasGoodVision && isTired);

Ha mindhárom érték igaz, mindkét kiírás true. Állítsd az isTired értékét false-ra. A háromtagú ÉS eredménye hamis lesz, a VAGY eredménye igaz marad.

Sarah akkor vezessen, ha nem fáradt

Kommentezd ki a korábbi if / else blokkot, majd írd a következőt a három változó deklarációja után.

if (hasDriversLicense && hasGoodVision && !isTired) {
  console.log("Sarah vezethet.");
} else {
  console.log("Valaki más vezessen.");
}

Ha Sarah fáradt, az isTired igaz, ezért a !isTired hamis. Az első két feltétel hiába igaz, az else fut. Ha Sarah kipihent, a !isTired igaz lesz. Ekkor mindhárom feltétel teljesül.

Önálló próba

Tippeld meg a kiírást, majd futtasd a programot háromszor. Először Sarah fáradt, utána kipihent, végül kipihent, de nincs jogosítványa. Minden esetben mondd meg, melyik feltétel dönti el az eredményt.
