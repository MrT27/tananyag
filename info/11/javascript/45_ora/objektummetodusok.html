Objektummetódusok

Függvények az objektumban, a this kulcsszó és számított adatok tárolása.

Függvény is lehet egy tulajdonság értéke

Egy objektum szöveget, számot, logikai értéket, tömböt, sőt másik objektumot is tartalmazhat. A függvény szintén érték, ezért tulajdonságként függvényt is tárolhatunk. Az objektumhoz kapcsolódó függvényt metódusnak nevezzük.

Az előző objektumot most alakítsd át: az előre kiszámított age helyére birthYear kerül, és hozzáadunk egy jogosítványt jelző logikai értéket. A korábbi objektumot cseréld le, ne deklaráld újra ugyanabban a fájlban!

const janos = {
  firstName: 'János',
  lastName: 'Kovács',
  birthYear: 1991,
  job: 'tanár',
  friends: ['Michael', 'Peter', 'Steven'],
  hasDriversLicense: true,

  calcAge: function (birthYear) {
    return 2037 - birthYear;
  }
};

A 2037 a példák rögzített referenciaéve; most is ezzel számolunk.

Kapcsolat a függvénykifejezésekkel

// Korábban: függvényérték egy változóban
const calcAge = function (birthYear) {
  return 2037 - birthYear;
};

Az objektumban ugyanezt a függvénykifejezést használjuk. Ott a calcAge tulajdonságnév után kettőspont áll, nem értékadó egyenlőségjel. A metódus tehát olyan tulajdonság, amelynek az értéke függvény. A tulajdonságokat, így a metódusokat is, vessző választja el.

Egy önálló function calcAge(...) { ... } deklarációt nem illeszthetünk az objektum tulajdonságai közé. A most használt calcAge: után értéket előállító függvénykifejezés kell. Később más, rövidebb metódusszintaxissal is találkozhatunk.

Metódus elérése és meghívása

console.log(janos.calcAge(1991));    // 46
console.log(janos['calcAge'](1991)); // 46

Mindkét jelöléssel elérjük a függvényértéket, majd a kerek zárójelekkel meghívjuk és átadjuk az argumentumot. A janos.calcAge önmagában a függvényt jelenti; a janos.calcAge(1991) már a hívás eredménye.

Először a tulajdonság-elérés történik meg, majd a kapott függvény meghívása. A ['calcAge'] a nevet választja ki; az utána álló (1991) a híváshoz tartozik.

Miért ne ismételjük meg a születési évet?

Az 1991 már az objektumban is szerepel. Ha a hívásnál véletlenül 1992-t adnánk át, más eredményt kapnánk. Ugyanazt az adatot több helyen karbantartani hibalehetőség.

A DRY (Don’t Repeat Yourself, azaz „ne ismételd magad”) elv szerint az ilyen ismétlést érdemes elkerülni. Olvassuk ki a születési évet közvetlenül a hívó objektumból!

A this kulcsszó: a hívó objektum

Az objektum calcAge tulajdonságát cseréld erre a második változatra. A régi változatot megőrizheted kommentben, de egyszerre csak az egyik legyen aktív!

calcAge: function () {
  console.log(this);
  return 2037 - this.birthYear;
}
console.log(janos.calcAge()); // az objektum, majd 46

Ennél a normál függvénnyel írt, objektumon keresztül meghívott metódusnál a this arra az objektumra mutat, amelyen meghívjuk. A janos.calcAge() esetén ez a janos. A this.birthYear így ennek az objektumnak az 1991 értékét olvassa ki. Már nem kell paraméter és argumentum.

A this értékét a hívás módja határozza meg; nem minden függvényben automatikusan a körülötte leírt objektumot jelenti. Ebben a leckében maradunk az objektumon keresztüli hívásnál és a function alaknál.

Miért this.birthYear, miért nem janos.birthYear?

A konkrét janos.birthYear itt szintén működne, de a metódust ehhez a változónévhez kötné. Ha az objektum változónevét és a hívást janos2-re neveznénk át, a metódusban maradt régi nevet is javítanunk kellene. A this.birthYear a hívó objektum adatát használja, így a metódus belsejét nem kell átírni.

Az eredmény eltárolása az objektumban

Ha négyszer meghívjuk a második változatot, a számítás négyszer fut le. Egy kivonásnál ez elhanyagolható, de egy drágább műveletnél hasznos lehet az eredményt eltárolni, és később kiolvasni. Cseréld le a metódust a harmadik változatra:

calcAge: function () {
  this.age = 2037 - this.birthYear;
  return this.age;
}
console.log(janos.age);       // undefined: még nem számítottuk ki
console.log(janos.calcAge()); // 46: kiszámítja, eltárolja és visszaadja
console.log(janos.age);       // 46
console.log(janos.age);       // 46
console.log(janos.age);       // 46

A this.age = ... új tulajdonságot hoz létre a hívó objektumon. A későbbi kiolvasás nem futtatja újra a metódust. Minden új calcAge() hívás viszont újraszámol; ez nem automatikus gyorsítótár. Ha a kiinduló adat megváltozik, az eltárolt értéket is frissíteni kell.

A return nélkül is létrejönne az age, de a hívás eredménye undefined lenne. A visszatérési érték miatt a számított életkort közvetlenül is használhatjuk.

VS Code-ban a következő egyező előfordulás kijelölése Windows alatt Ctrl + D, Macen Command + D. Többszöri használatával több helyen egyszerre szerkeszthetsz.

Önálló próba: getSummary metódus

Adj az objektumhoz getSummary nevű metódust! Adjon vissza egy összefoglaló szöveget a névből, az életkorból, a foglalkozásból és a jogosítvány meglétéből:

János egy 46 éves tanár, és van jogosítványa.

Ha a hasDriversLicense hamis, a mondat vége „nincs jogosítványa.” legyen. Használd a this kulcsszót és a feltételes operátort! Ne feltételezd, hogy a calcAge()-t már meghívtuk!

Teljes megoldás
const janos = {
  firstName: 'János',
  lastName: 'Kovács',
  birthYear: 1991,
  job: 'tanár',
  friends: ['Michael', 'Peter', 'Steven'],
  hasDriversLicense: true,

  calcAge: function () {
    this.age = 2037 - this.birthYear;
    return this.age;
  },

  getSummary: function () {
    return `${this.firstName} egy ${this.calcAge()} éves ${this.job}, és ${this.hasDriversLicense ? 'van' : 'nincs'} jogosítványa.`;
  }
};

console.log(janos.getSummary());
// János egy 46 éves tanár, és van jogosítványa.

janos.hasDriversLicense = false;
console.log(janos.getSummary());
// János egy 46 éves tanár, és nincs jogosítványa.

A teljes példát külön próbáld ki, vagy cseréld le vele a korábbi objektumot; ne deklaráld kétszer ugyanazt a const janos változót.

Hogyan működik az összefoglalás?

A janos.getSummary() hívásban a this a janos objektum. A sablonliterálban a this.calcAge() meghív egy másik metódust ugyanazon az objektumon. A visszaadott szám bekerül a szövegbe. Ez akkor is működik, ha az age tulajdonság korábban még nem létezett.

A this.hasDriversLicense ? 'van' : 'nincs' kifejezés a logikai érték alapján választ szöveget. A feltételes operátor kifejezés, ezért használható a sablonliterál helyőrzőjében. A getSummary visszaadja a kész szöveget, a külső console.log() jeleníti meg.

Ne felejtsd el a két metódus közötti vesszőt! Próbáld ki a jogosítvány mindkét értékét, és változtasd meg a születési évet is!

Kapcsolat a tömbmetódusokkal

janos.friends.push('Jay');
console.log(janos.friends);

A tömbök a JavaScriptben speciális objektumok. Ezért rendelkezhetnek metódusokkal, például push(), pop(), shift() és unshift() műveletekkel. Korábban a tömbök beépített metódusait használtuk; most a saját objektumunkhoz írtunk saját metódusokat.
