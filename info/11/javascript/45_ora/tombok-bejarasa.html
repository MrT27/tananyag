Tömbök bejárása

Új tömbök építése, continue és break.

A tömb elemeinek kiolvasása

A for ciklus gyakori feladata egy tömb bejárása: az elemeket sorban, egyenként feldolgozzuk. Vegyük elő a személy adatait tartalmazó tömböt! Ha már létezik a fájlodban, ne deklaráld újra.

const janosArray = [
  'János',
  'Kovács',
  2037 - 1991,
  'tanár',
  ['Michael', 'Peter', 'Steven']
];

Ciklus nélkül külön sorokban írnánk ki az elemeket:

// console.log(janosArray[0]);
// console.log(janosArray[1]);
// console.log(janosArray[2]);
// console.log(janosArray[3]);
// console.log(janosArray[4]);

Az első index 0, az utolsó 4. Az ötödik indexű elem még nem létezik: a janosArray[5] most undefined.

Az index helyére számláló kerül

for (let i = 0; i < 5; i++) {
  console.log(janosArray[i]);
}

Az i hagyományosan használt számlálónév, nem különleges kulcsszó. Nulláról indul, mert a tömb első elemének indexe nulla. Minden ismétlésben az aktuális i alapján választunk elemet.

A feltétel i < 5, így a számláló 0, 1, 2, 3 és 4 értékkel jut be a törzsbe. Ötnél megállunk. A belső barátok tömbje itt egyetlen elemként kerül a konzolra; a külső ciklus nem járja be automatikusan annak elemeit is.

Rögzített hossz helyett length

Ha a tömb végére egy true elemet írunk, már hat elemünk lesz. Az i < 5 feltétellel az új, 5-ös indexű elem kimaradna. Módosítsd a tömböt erre, és a további példákban ezt használd:

const janosArray = [
  'János',
  'Kovács',
  2037 - 1991,
  'tanár',
  ['Michael', 'Peter', 'Steven'],
  true
];

A rögzített felső határt cseréljük a tömb hosszára:

for (let i = 0; i < janosArray.length; i++) {
  console.log(janosArray[i]);
}

A length az elemek száma. Hat elemhez a 0–5 indexek tartoznak, tehát az utolsó index mindig length - 1. Ezért kisebb jelet használunk, nem kisebb-egyenlőt. Így a ciklus a tömbhöz igazodik, nem kell átírni, ha elemet adunk hozzá.

Az értékek és a típusok kiírása

for (let i = 0; i < janosArray.length; i++) {
  console.log(janosArray[i], typeof janosArray[i]);
}

A typeof az aktuális elem típusát adja szövegként. A típusok sorrendben: string, string, number, string, object, boolean.

A barátok tömbjére a typeof eredménye 'object', mert a tömb is objektum. A typeof önmagában nem különbözteti meg a tömböt a többi objektumtól.

Új tömb építése indexelt értékadással

Ne csak írjuk ki a típusokat, hanem gyűjtsük egy új tömbbe! Az üres tömböt a ciklus előtt hozzuk létre. A [] üres tömböt jelent.

const types = [];

for (let i = 0; i < janosArray.length; i++) {
  console.log(janosArray[i], typeof janosArray[i]);
  types[i] = typeof janosArray[i];
}

console.log(types);
// ['string', 'string', 'number', 'string', 'object', 'boolean']

Az első ismétlésben a types[0] a typeof janosArray[0] eredményét kapja, majd az 1-es, 2-es és további indexek következnek. Ugyanabban a ciklusban olvasunk az eredeti tömbből és írunk az újba.

Ez szemléltető példa: a fontos gondolat az, hogyan építünk új tömböt egy másik tömb adataiból. A const mellett a tömb tartalmát továbbra is módosíthatjuk.

Ugyanez push() használatával

Az előző változat helyett használd ezt; a types deklarációját és a feltöltést ne futtasd kétszer ugyanazzal a névvel! A két feltöltési sort se hagyd egyszerre aktívan.

const types = [];

for (let i = 0; i < janosArray.length; i++) {
  types.push(typeof janosArray[i]);
}

console.log(types);
// ['string', 'string', 'number', 'string', 'object', 'boolean']

A push() a tömb végére illeszti az új típust, ezért az eredeti sorrend megmarad. Az unshift() az elejére tenne minden új elemet, ami megfordítaná ezt a sorrendet. Az indexelt értékadás és a push() ebben a példában ugyanazt az eredményt adja.

Gyakorlatiasabb példa: születési évekből életkorok

const years = [1991, 2007, 1969, 2020];
const ages = [];

for (let i = 0; i < years.length; i++) {
  ages.push(2037 - years[i]);
}

console.log(ages); // [46, 30, 68, 17]

A korábbi példákhoz hasonlóan a rögzített referenciaév 2037. Minden ismétlésben egy születési évet olvasunk ki, kivonjuk 2037-ből, majd az eredményt az ages végére tesszük. Az első lépésben 46, a másodikban 30, majd 68 és 17 kerül az új tömbbe.

A 2037 - years nem számítana minden elemhez külön életkort: ennél a több elemből álló tömbnél az eredménye NaN. A JavaScript ilyen kivonása nem elemenkénti tömbművelet. Ezért dolgozzuk fel az adatokat egyenként.

Az egymás után álló ciklusok fejléceiben újra használhatjuk a let i nevet: az egyes ciklusok saját számlálóval rendelkeznek. Ugyanezzel a mintával például több számla összegéből is készíthetnénk borravalókat tartalmazó tömböt a kézi indexelés helyett.

continue: csak az aktuális ismétlés maradéka marad ki

Térjünk vissza a hat elemű janosArray tömbhöz! Most kizárólag a szöveges elemeket szeretnénk kiírni:

console.log('--- Csak a szövegek ---');

for (let i = 0; i < janosArray.length; i++) {
  if (typeof janosArray[i] !== 'string') continue;

  console.log(janosArray[i], typeof janosArray[i]);
}
// János string
// Kovács string
// tanár string

Ha az aktuális elem nem karakterlánc, a continue kihagyja a ciklustörzs hátralévő részét. A kiírás az adott elemre nem fut le. Ennél a for ciklusnál ezután a frissítés, vagyis az i++ következik, majd újra ellenőrizzük a feltételt.

A 46-os számot átugorjuk, de a következő 'tanár' szöveget már kiírjuk. A tömb és a logikai érték szintén kimarad. A continue nem állítja le az egész ciklust.

Az if itt egyetlen utasítást tartalmaz, ezért a kapcsos zárójelek elhagyhatók. A if (...) { continue; } forma ugyanígy működik.

break: a teljes ciklus befejeződik

Most az első szám elérésekor fejezzük be a bejárást:

console.log('--- Megállás az első számnál ---');

for (let i = 0; i < janosArray.length; i++) {
  if (typeof janosArray[i] === 'number') break;

  console.log(janosArray[i], typeof janosArray[i]);
}
// János string
// Kovács string

A harmadik elem, a 46 szám. A feltétel ekkor igaz, és a break azonnal befejezi a ciklust. Maga a 46 sem kerül kiírásra, mert a kiírás a megszakítás után áll. A 'tanár' és az összes további elem is kimarad.

A program a ciklus utáni kóddal folytatódik. A break a switch utasításból már ismerős; itt a ciklusból lépünk ki vele.

A két utasítás közötti különbség

  • continue: az aktuális ismétlés maradéka kimarad, a bejárás folytatódhat a következő elemmel.
  • break: a ciklus befejeződik, a további elemeket már nem vizsgáljuk.

Pythonban ugyanezekkel a kulcsszavakkal találkozhattál: az alapvető különbség itt is ugyanaz. A JavaScript most használt for alakjában a continue után a fejléc frissítési része is végrehajtódik.

A lecke legfontosabb mintája a tömb teljes bejárása: let i = 0, i < tomb.length, i++, és a törzsben az aktuális tomb[i] feldolgozása.
