Egyenlőségi operátorok

Hogyan vizsgáljuk meg, hogy két érték megegyezik-e, és hogyan kezelünk több lehetséges választ?

Pontosan 18 éves?

const age = 18;
if (age === 18) console.log("Most lettél nagykorú!");

A === eredménye logikai érték. A 18 === 18 igaz, a 19 === 18 hamis. Írd át az életkort 19-re, és futtasd újra. A feltétel pontosan 18-at keres. Egyetlen utasításnál a kapcsos zárójelek elhagyhatók. Több utasítást közös blokkba írunk.

Szigorú és laza egyenlőség

A === típusátalakítás nélkül hasonlít össze. A == bizonyos esetekben átalakítja az értékeket. A következő példában a laza összehasonlítás számmá alakítja a "18" szöveget.

console.log(18 === 18);   // true
console.log(18 == 18);    // true
console.log("18" === 18); // false
console.log("18" == 18);  // true

Jonas a === használatát javasolja. Ha egy beírt számmal szeretnél összehasonlítani, a típusátalakítást külön is megadhatod, hogy a kódból látszódjon a szándékod.

A kedvenc szám bekérése

const favourite = prompt("Mi a kedvenc számod?");
console.log(favourite, typeof favourite);

if (favourite == 23) {
  console.log("A 23 nagyszerű szám!");
}

Írj be 23-at. A prompt() szövegként adja vissza. Ha ===-re cseréled a ==-t, a feltétel hamis lesz. A szigorú összehasonlításhoz használd a Number(prompt("Mi a kedvenc számod?")) kifejezést. Ekkor a beírt "23" számmá alakul, és a feltétel igaz lesz. A következő próbákhoz adj meg számot.

Több válasz az else if segítségével

Cseréld le az előző példát erre. A program felülről lefelé vizsgálja a feltételeket, és az első igaz feltétel ágát futtatja. Ha egyik feltétel sem igaz, az else ág következik.

const favourite = Number(prompt("Mi a kedvenc számod?"));

if (favourite === 23) {
  console.log("A 23 nagyszerű szám!");
} else if (favourite === 7) {
  console.log("A 7 is jó szám!");
} else if (favourite === 9) {
  console.log("A 9 is jó szám!");
} else {
  console.log("Más számot választottál.");
}

if (favourite !== 23) {
  console.log("Miért nem a 23?");
}

A !== a szigorú különbözőséget vizsgálja. A laza változata !=. Jonas itt is a szigorú operátort használja. Az utolsó if külön utasítás, így 9 esetén a számhoz tartozó üzenet és a „Miért nem a 23?” is megjelenik.
