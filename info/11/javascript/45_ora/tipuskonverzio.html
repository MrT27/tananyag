Típuskonverzió és típuskényszerítés

Számoláshoz a beírt szöveget gyakran számmá kell alakítani.

Kifejezett típuskonverzió

Jonas példájában a születési év egy beviteli mezőből érkezik. Szövegként kapjuk meg, akárcsak a prompt()-ba írt választ. A + ezért először összefűzi a két értéket.

const inputYear = "1991";
console.log(inputYear + 18); // "199118"

const birthYear = Number(inputYear);
console.log(birthYear + 18); // 2009
console.log(typeof inputYear, typeof birthYear); // string number

A Number() eredménye egy új érték. Az inputYear továbbra is szöveg. A Number(inputYear) + 18 alakban egy sorban is megteheted ugyanezt.

console.log(Number("Jonas"));        // NaN
console.log(typeof Number("Jonas")); // number
console.log(String(23), typeof String(23)); // 23 string

A NaN jelentése Not a Number. Itt azt jelzi, hogy az átalakításból nem kaptunk használható számot, bár a typeof eredménye "number". A String() szöveggé alakít. Mindkét név nagybetűvel kezdődik. A konzolon a szám és a szöveg hasonlóan nézhet ki, ezért használd a typeof-ot. A null és az undefined külön értékek. Ezeket közvetlenül is megadhatod. A harmadik gyakori átalakítás a Boolean(). Automatikus átalakítás

Típuskényszerítéskor a JavaScript az operátor szabályai alapján alakítja át az értékeket. Szám és szöveg esetén a + szöveget fűz össze. A sablonliterál is szövegként illeszti be a számot. Az alábbi kivonásnál, szorzásnál és osztásnál a numerikus szövegből szám lesz.

console.log("Én " + 23 + " éves vagyok."); // Én 23 éves vagyok.
console.log("23" - "10" - 3); // 10
console.log("23" + "10" + 3); // "23103"
console.log("23" * "2");      // 46
console.log("24" / "2");      // 12

Tippeld meg az értéket és a típust

let n = "1" + 1;
n = n - 1;
console.log(n);

console.log(2 + 3 + 4 + "5");
console.log("10" - "4" - "3" - 2 + "5");
Megoldás
  • "1" + 1 eredménye "11". A kivonás ebből számot csinál, így 10 lesz.
  • Az első három szám összege 9. Az utolsó összefűzés eredménye a "95" szöveg.
  • A kivonások eredménye sorban 6, 3 és 1. Az utolsó összefűzés eredménye "15".
