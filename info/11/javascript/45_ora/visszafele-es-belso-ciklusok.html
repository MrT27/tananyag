Visszafelé bejárás és egymásba ágyazott ciklusok

Csökkenő számláló, külső és belső ciklus.

A tömb utolsó elemétől az elsőig

Az előző leckében a tömb elejétől haladtunk a végéig. Most fordított sorrendben olvassuk ki ugyanazokat az adatokat. Először az öt elemű változattal dolgozz; a korábbi tömböt cseréld le, ne deklaráld újra ugyanabban a fájlban!

const janosArray = [
  'János',
  'Kovács',
  2037 - 1991,
  'tanár',
  ['Michael', 'Peter', 'Steven']
];

Előrefelé az indexek: 0, 1, 2, 3, 4. Visszafelé: 4, 3, 2, 1, 0. Ennek megfelelően a kezdőértéket, a feltételt és a frissítést is át kell gondolnunk.

A visszafelé haladó for ciklus

for (let i = janosArray.length - 1; i >= 0; i--) {
  console.log(janosArray[i]);
}
  • Kezdőérték: janosArray.length - 1, vagyis az utolsó érvényes index. Öt elemnél ez 4. Nem rögzített számot írunk, így a ciklus a tömb hosszához igazodik.
  • Feltétel: i >= 0. A nulladik elemet is ki akarjuk olvasni, ezért az egyenlőség szükséges.
  • Frissítés: i--, vagyis eggyel csökkentjük a számlálót. Itt ez ugyanazt a változást végzi, mint az i = i - 1.

Először a barátok tömbje, majd a foglalkozás, a 46-os életkor, a vezetéknév és végül a keresztnév jelenik meg. A belső tömb itt továbbra is egyetlen elemként kerül kiírásra.

A számláló követése

A sorrendet könnyebb ellenőrizni, ha az indexet is kiíratjuk:

for (let i = janosArray.length - 1; i >= 0; i--) {
  console.log(i, janosArray[i]);
}
// 4 ['Michael', 'Peter', 'Steven']
// 3 'tanár'
// 2 46
// 1 'Kovács'
// 0 'János'

A 0 még megfelel a 0 >= 0 feltételnek. A nulladik elem kiírása után a számláló −1 lesz. A -1 >= 0 már hamis, így befejeződik a ciklus. Ha i > 0 lenne a feltétel, az első elem kimaradna.

A tömb tartalmát nem fordítjuk meg és nem módosítjuk: csak az olvasás sorrendje változik.

Mi történik, ha hosszabb lesz a tömb?

Próbaként adj egy új elemet a végéhez, majd futtasd újra a bejárást:

janosArray.push(true);

for (let i = janosArray.length - 1; i >= 0; i--) {
  console.log(i, janosArray[i]);
}

Most a hossz 6, ezért a kezdőindex 6 - 1, vagyis 5. Elsőként az új true jelenik meg, utána a korábbi elemek. A cikluson semmit nem kellett változtatni. Ha újra csak ezt a push() sort futtatod, újabb elemet adsz a tömbhöz.

A gyakorlat lényege a ciklus három részének tudatos megválasztása, nem egy rögzített fejléc bemagolása.

Ciklus egy másik cikluson belül

Térjünk vissza az edzőtermi példához! Most három különböző gyakorlatot végzünk, mindegyikből öt ismétlést. Ehhez a külső ciklus a gyakorlatokat, a belső az ismétléseket számlálja.

Először csak a három gyakorlat kezdetét írjuk ki:

for (let exercise = 1; exercise < 4; exercise++) {
  console.log(`--- A(z) ${exercise}. gyakorlat kezdete ---`);
}

A exercise < 4 ebben az 1-ről induló, egyesével növekvő ciklusban ugyanazokat az értékeket engedi át, mint a exercise <= 3: 1, 2 és 3.

Öt ismétlés minden gyakorlaton belül

A külső ciklus törzsébe helyezzük az ismétléseket végző második ciklust:

for (let exercise = 1; exercise < 4; exercise++) {
  console.log(`--- A(z) ${exercise}. gyakorlat kezdete ---`);

  for (let rep = 1; rep < 6; rep++) {
    console.log(`Súlyemelés – ${rep}. ismétlés 🏋️`);
  }
}

A rep < 6 mellett a belső számláló 1-től 5-ig halad. Itt ez ugyanaz, mint a rep <= 5. A külső ciklus egyetlen ismétlésén belül a teljes belső ciklus lefut.

Mielőtt futtatod, gondold végig: hány gyakorlatkezdő és hány súlyemelést jelző üzenet fog megjelenni?

A végrehajtás sorrendje

  1. exercise = 1: kiírjuk az első gyakorlat kezdetét, majd a belső ciklus 1-től 5-ig végigfut.
  2. A belső ciklus befejeződik, a külső számláló 2-re nő. Kiírjuk a második gyakorlat kezdetét, majd egy új belső ciklus indul rep = 1 értékkel.
  3. exercise = 3: ugyanígy újra lefut az öt ismétlés.
  4. A külső számláló 4-re nő. A 4 < 4 hamis, így a külső ciklus is befejeződik.

A belső ciklus mindhárom alkalommal újra 1-ről indul. Összesen 3 × 5 = 15 súlyemelés történik. A három gyakorlatkezdő sorral együtt 18 konzolkiírás jelenik meg.

A külső számláló a belső ciklusban is használható

Tegyük az ismétlések szövegébe az aktuális gyakorlat számát is:

for (let exercise = 1; exercise < 4; exercise++) {
  console.log(`--- A(z) ${exercise}. gyakorlat kezdete ---`);

  for (let rep = 1; rep < 6; rep++) {
    console.log(`${exercise}. gyakorlat – ${rep}. súlyemelés 🏋️`);
  }
}

Az exercise a teljes külső ciklustörzsben elérhető, így az abba ágyazott belső ciklusban is. A rep a saját belső ciklusához tartozik; azon kívül nem használhatjuk.

Az első öt súlyemelésnél az exercise 1, a következő ötnél 2, az utolsó ötnél 3. A két számlálónak külön szerepe van: a külső választja a gyakorlatot, a belső az azon belüli ismétlést.

Kapcsolat a Pythonban tanultakkal

# Python
for exercise in range(1, 4):
    print(f'--- A(z) {exercise}. gyakorlat kezdete ---')
    for rep in range(1, 6):
        print(f'{exercise}. gyakorlat – {rep}. súlyemelés')

Az egymásba ágyazás elve ugyanaz: a belső ciklus teljes egészében lefut a külső minden ismétlésekor. Pythonban a behúzás, JavaScriptben a kapcsos zárójelek jelölik a ciklustörzseket. A következetes behúzás JavaScriptben is segít látni, melyik sor melyik ciklushoz tartozik.
