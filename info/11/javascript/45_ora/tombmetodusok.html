Alapvető tömbmetódusok

Elemeket adunk hozzá, veszünk ki és keresünk meg a barátok tömbjében.

Elemek hozzáadása

A metódus egy objektumhoz kapcsolódó függvény. A ponttal elérjük, zárójelekkel meghívjuk. A korábbi friends példát kommentezd ki, és indíts új tömbbel.

'use strict';

const friends = ["Michael", "Steven", "Peter"];

const newLength = friends.push("Jay");
console.log(newLength); // 4
console.log(friends); // ["Michael", "Steven", "Peter", "Jay"]

friends.unshift("John");
console.log(friends); // ["John", "Michael", "Steven", "Peter", "Jay"]

A push() a végére, az unshift() az elejére teszi az argumentumot. Mindkettő az eredeti tömböt módosítja, és az új hosszt adja vissza. A const mellett is módosíthatjuk a tömb tartalmát. A visszaadott értéket csak akkor kell eltárolni, ha később felhasználjuk.

Elemek eltávolítása

Folytasd ugyanazzal a tömbbel. A pop() a végéről, a shift() az elejéről vesz ki egy elemet. Argumentum nélkül hívjuk őket, mert a helyet a metódus neve meghatározza.

friends.pop(); // Jay eltávolítása
const popped = friends.pop(); // Peter eltávolítása
console.log(popped); // Peter

const shifted = friends.shift(); // John eltávolítása
console.log(shifted); // John
console.log(friends); // ["Michael", "Steven"]

A visszaadott érték az eltávolított elem. Az unshift() hozzáad az elejéhez, a shift() eltávolít onnan. Ügyelj a két eltérő művelet nevére.

Index keresése

console.log(friends.indexOf("Steven")); // 1
console.log(friends.indexOf("Bob"));    // -1

Az indexOf() az első egyezés nullától számított indexét adja. Hiányzó elemnél -1 az eredmény.

Benne van-e a tömbben?

console.log(friends.includes("Steven")); // true
console.log(friends.includes("Bob"));    // false

friends.push(23);
console.log(friends.includes("23")); // false
console.log(friends.includes(23));   // true

if (friends.includes("Peter")) {
  console.log("Van egy Peter nevű barátod.");
}
if (friends.includes("Steven")) {
  console.log("Van egy Steven nevű barátod.");
}

Az includes() logikai értéket ad. A "23" szöveget és a 23 számot külön kezeli, típusátalakítást nem végez. Ezért közvetlenül feltételként is használhatjuk. Peter már kikerült a tömbből, így csak Steven üzenete jelenik meg.

Az includes() az ES2016 kiadásban jelent meg. Összehasonlításának neve SameValueZero. A fenti példákban a szigorú egyenlőséghez hasonlóan viselkedik, de például a NaN értéket is képes megtalálni.

Önálló próba

Az eredményül kapott tömb elejére tedd Bobot, és tárold az új hosszt. Ezután vedd ki a végéről a 23-at, és tárold az eltávolított értéket. Ellenőrizd, hogy a hossz először 4, az eltávolított érték 23, végül az includes(23) hamis.
