Bevezetés a tömbökbe

Összetartozó értékeket tárolunk egy adatszerkezetben.

Három külön változó helyett egy tömb

A barátok neveit külön friend1, friend2 és friend3 változóban is tarthatnánk. Egy tömb egy név alatt, meghatározott sorrendben tárolja az értékeket. A tömb és az objektum a JavaScript két fontos adatszerkezete.

'use strict';

const friends = ["Michael", "Steven", "Peter"];
console.log(friends);

const birthYears = new Array(1991, 1984, 2008, 2020);
console.log(birthYears);

A szögletes zárójeles alak a tömbliterál, ezt fogjuk legtöbbször használni. Az értékek közötti vessző a szöveget lezáró idézőjel után áll. A new Array(...) egy másik létrehozási forma. A példában több számot adunk át neki.

Index és elemszám

console.log(friends[0]); // Michael
console.log(friends[2]); // Peter
console.log(friends.length); // 3
console.log(friends[friends.length - 1]); // Peter

A tömb indexelése nullával kezdődik. A három elem indexe 0, 1 és 2. A length az elemszám, ezért az utolsó elem indexe length - 1. Az index helyén kifejezés is állhat, például ez a kivonás.

Elem módosítása const mellett

friends[2] = "Jay";
console.log(friends[2]); // Jay

// friends = ["Bob", "Alice"]; // TypeError

A const a változó új értékadását tiltja. A már tárolt tömb elemeit módosíthatjuk. Az egész tömb helyére másik tömböt rendelő, kikommentelt sor viszont hibát okoz. Próbáld ki külön, majd kommentezd vissza. A konzolban később kibontott objektum mutathatja a módosított tartalmat, ezért a változás ellenőrzéséhez az egyes elemeket is írd ki.

Különböző típusok és beágyazott tömb

const firstName = "János";
const janos = [firstName, "Kovács", 2037 - 1991, "tanár", friends];
console.log(janos);
console.log(janos.length); // 5

Az egyes helyeken kiértékelhető kifejezések állnak. Itt szövegek, számítás eredménye és egy másik tömb kerül a tömbbe. A barátok tömbje egyetlen elem a janos tömbben.

Életkorok kiszámítása

const calcAge = function (birthYear) {
  return 2037 - birthYear;
};

const years = [1990, 1967, 2002, 2010, 2018];

console.log(calcAge(years)); // NaN
console.log(years + 10); // "1990,1967,2002,2010,201810"
console.log(years - 10); // NaN

const age1 = calcAge(years[0]);
const age2 = calcAge(years[1]);
const age3 = calcAge(years[years.length - 1]);
console.log(age1, age2, age3); // 47 70 19

const ages = [
  calcAge(years[0]),
  calcAge(years[1]),
  calcAge(years[years.length - 1])
];
console.log(ages); // [47, 70, 19]

A calcAge itt egyetlen évszámmal számol. A teljes tömb átadásától nem fut le automatikusan minden elemre. A + a példában szöveggé alakítja a tömböt, a kivonás pedig NaN-t ad. Az egyes elemeket argumentumként átadhatjuk. A függvényhívás kifejezés, ezért a visszaadott életkorokat közvetlenül az új tömbbe írhatjuk.

Ha az Identifier has already been declared üzenetet kapod, ellenőrizd, nem deklaráltad-e ugyanazt a const nevet korábbi példában is. Az előző kódot kommenteld ki, vagy válassz másik nevet.

Önálló próba

Számítsd ki a years harmadik és negyedik eleméhez tartozó életkort is, és tárold az eredményeket egy új tömbben. Ellenőrizd, hogy 35 és 27 szerepel benne. Mondd meg, miért a 2-es és a 3-as indexet használod.
