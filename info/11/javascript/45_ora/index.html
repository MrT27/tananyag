Elemi és összetett adattípusok

Mi a különbség a 23 és a "23" között? Miben tárolnád egy ember adatait vagy a barátai nevét?

Elemi értékek és dinamikus típusosság

A JavaScriptben minden érték vagy elemi (primitív) érték, vagy objektum. Hét elemi típus van. Az objektumok közé tartoznak az óra második felében bemutatott tömbök, Map és Set gyűjtemények is.

  • Number: lebegőpontos szám, például 23 vagy 3.5. A 23 és a 23.0 ugyanazt a számértéket jelöli.
  • String: szöveg, például "Jonas" vagy "23".
  • Boolean: logikai érték, amely true vagy false lehet. Az 55. órán ilyen értékek alapján döntünk majd az if utasításban.
  • undefined: például egy let változó értéke, ha még nem adtunk neki értéket.
  • null: külön érték, amellyel például szándékosan jelezhetjük egy adat hiányát.
  • Symbol: az ES2015-ben bevezetett típus. A Symbol() minden híváskor egyedi értéket hoz létre.
  • BigInt: az ES2020-ban bevezetett egészszámtípus. Akkor is pontos egész számot tárolhatunk vele, amikor a Number pontossága már kevés. Példa: 9007199254740993n.

Pythonban a 23 típusa int, a 3.5 típusa float. JavaScriptben mindkettő Number típusú, ezért a typeof mindkettőre "number"-t ad.

Változó létrehozásakor nem kell megadnod az adattípust. A let year = 1991; sorban a JavaScript az 1991 értékből tudja, hogy számot tárolunk. A típus az értékhez tartozik. A let változóba később más típusú értéket is tehetsz. Ezt hívjuk dinamikus típusosságnak.

Megjegyzések a JavaScript-kódban

A megjegyzés magyarázatot adhat az olvasónak, vagy ideiglenesen kikapcsolhat egy kódrészletet. A JavaScript a megjegyzést nem futtatja.

  • A // jeltől a sor végéig tart az egysoros megjegyzés. A jel állhat egy külön sor elején vagy egy utasítás után is.
  • A /* és a */ közötti megjegyzés több soron át tarthat. Jonas így hagyja meg a korábbi leckék kódját a script.js-ben, miközben az új példán dolgozik.
// A korábbi óra számítása
console.log(40 + 8 + 23 - 10); // 61

/*
console.log("Jonas");
console.log(23);
*/

Futtasd a példát. Csak a 61 jelenik meg. Tegyél // jelet a számítást kiíró sor elé, mentsd a fájlt, és frissítsd az oldalt. Az új futás már nem írja ki a 61-et. Vedd le a jelet, és próbáld újra. A VS Code-ban a sor megjegyzéssé alakítását a ⌘ + / (Mac), illetve a Ctrl + / (Windows, Linux) kapcsolja ki és be.

Az érték típusának ellenőrzése

A typeof operátor eredménye egy szöveg, amely megnevezi a vizsgált érték típusát. A konzol megjelenése eltérhet böngészőnként. A típust a typeof eredményéből olvasd le. Először tippeld meg az eredményeket, majd futtasd a kódot.

console.log(typeof 23);      // number
console.log(typeof 3.5);     // number
console.log(typeof "23");    // string
console.log(typeof true);    // boolean
console.log(typeof "true");  // string

Az idézőjel itt a jelentést változtatja meg

console.log("Jonas");
console.log('Jonas');
// console.log(Jonas); // ReferenceError, ha nincs Jonas nevű változó

A szöveg két végén azonos idézőjelet használj. Az idézőjelek nélküli Jonas névként értelmeződik. Ha ilyen változót nem hoztál létre, a harmadik sor bekapcsolása hivatkozási hibát (ReferenceError) eredményez.

A változóban tárolt érték típusa változhat

Jonas példájában a javascriptIsFun változó először a true logikai értéket kapja, később az "Igen!" szöveget. A typeof mindig az éppen tárolt érték típusát mutatja. Hibát okozhat, ha a kód szöveget kap ott, ahol számmal szeretnénk számolni.

A példában az utasítások fentről lefelé futnak le. A let javascriptIsFun deklaráció után használjuk a nevet. Ha a kiírást a deklaráció elé teszed, ReferenceError keletkezik. Az új értéket a változó nevével és az = jellel adjuk meg, második let nélkül.

let javascriptIsFun = true;
console.log(typeof javascriptIsFun); // boolean

javascriptIsFun = "Igen!";
console.log(typeof javascriptIsFun); // string

let year;
console.log(year, typeof year); // undefined undefined

year = 1991;
console.log(year, typeof year); // 1991 number

let middleName = null;
console.log(middleName, typeof middleName); // null object

A let year; után az érték maga undefined, a typeof year eredménye pedig az "undefined" szöveg. Az 1991 értékadás után az eredmény "number".

A null elemi érték. A typeof null történeti okból az "object" szöveget adja.

Négy adatszerkezet több értékhez

  • Array (tömb): rendezett lista. Az első elem indexe 0.
  • Object (objektum): névvel ellátott tulajdonságok egy helyen, például egy személy adatai.
  • Map: kulcsokhoz rendel értékeket. A kulcs például szám is lehet. A get() a kulcshoz tartozó értéket adja vissza.
  • Set: egyedi értékek gyűjteménye. Ha egy név többször szerepel, egyszer kerül bele.
const friends = ["Michael", "Peter", "Steven"];
console.log(friends[0]); // Michael

const person = { firstName: "Jonas", job: "tanár" };
console.log(person.job); // tanár

const namesById = new Map([[101, "Michael"], [102, "Peter"]]);
console.log(namesById.get(102)); // Peter

const uniqueNames = new Set(["Michael", "Peter", "Michael"]);
console.log(uniqueNames.size); // 2

A négy adatszerkezetre a typeof egyaránt "object"-et ad. Egy értékről az Array.isArray(friends) segítségével ellenőrizheted, hogy tömb-e. A példákban a const miatt a változóhoz nem rendelünk másik értéket. Ettől a gyűjtemény tartalma még módosítható.

Önálló feladat – tippelj, majd ellenőrizd

  1. Adj egy age változónak "23" értéket. Írd ki a típusát, majd adj neki 23 értéket, és írd ki újra a típusát.
  2. Hozz létre egy job változót kezdőérték nélkül. Nézd meg a konzolban az értékét. Adj neki null értéket, ha szándékosan jelölöd, hogy az adat hiányzik.
  3. Válassz a négy adatszerkezet közül az alábbi helyzetekhez. Indokold a választásodat. Egy személy neve és foglalkozása. Három barát neve sorrendben. Egy névlista ismétlések nélkül. Azonosítókhoz rendelt nevek.
Ellenőrzés

Az életkor először string, majd number. A foglalkozás értéke először undefined, majd null. A négy helyzethez sorrendben az Object, Array, Set és Map illik.
