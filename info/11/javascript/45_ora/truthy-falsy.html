Truthy és falsy értékek

Mi történik, ha az if feltételébe egy számot vagy egy szöveget írunk?

Átalakítás logikai értékké

A falsy értékből false, a truthy értékből true lesz logikai átalakításkor. Jonas öt gyakori falsy értéket emel ki. Ezek a 0, az üres szöveg (""), az undefined, a null és a NaN. Maga a false is falsy. A -0 és a 0n szintén false-t ad.

A Boolean() segítségével közvetlenül ellenőrizheted az átalakítást. Próbáld ki Jonas példáit.

console.log(Boolean(0));         // false
console.log(Boolean(undefined)); // false
console.log(Boolean("Jonas"));   // true
console.log(Boolean({}));        // true
console.log(Boolean(""));        // false

A nem üres szöveg truthy, ezért a Boolean("false") és a Boolean("0") eredménye is true. Az üres objektum ({}) is truthy. A Boolean() itt megmutatja azt az átalakítást, amelyet az if magától elvégez. A logikai operátoroknál is találkozunk ezzel a vizsgálattal.

Jonas pénzes példája

const money = 0;

if (money) {
  console.log("Ne költsd el az egészet!");
} else {
  console.log("Keress munkát!");
}

Az if a money értékét logikai értékként vizsgálja. A 0 falsy, így az else ág fut. Írd át a kezdőértéket 100-ra. Ekkor az if ág fut, mert a 100 truthy. A money típusa közben szám marad.

A magasság példája és a nulla esete

let height;

if (height) {
  console.log("Meg van adva a magasság.");
} else {
  console.log("Nincs megadva a magasság.");
}

Kezdőérték nélkül a height értéke undefined, ezért a második üzenet jelenik meg. Próbáld ki a let height = 123; kezdősort. Most az első üzenetet kapod. Ezután állítsd az értéket 0-ra. A program ismét hiányzónak jelzi az adatot, mert a nulla is falsy.

Ha ennél a példánál az undefined jelöli a hiányzó adatot, a feltételt pontosíthatjuk. Az if (height !== undefined) azt ellenőrzi, hogy az érték eltér-e az undefined-tól. Így a nulla is megadott adatnak számít. Az egyenlőségi operátorokat a következő videóban vesszük részletesen.

Önálló próba

Tippeld meg, melyik ág fut le a magasságos példában undefined, 0 és 123 esetén. Futtasd mindhárom változatot először az if (height), majd az if (height !== undefined) feltétellel. Melyik értéknél változik a kiírás?
