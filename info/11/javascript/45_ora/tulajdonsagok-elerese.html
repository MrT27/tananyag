Tulajdonságok elérése

Pontjelölés, szögletes zárójeles jelölés, adatbekérés és az objektum bővítése.

Az előző objektum megtekintése

Folytasd az előző lecke objektumával. Ha már szerepel a fájlban, ne deklaráld újra, csak egészítsd ki a kódot!

const janos = {
  firstName: 'János',
  lastName: 'Kovács',
  age: 2037 - 1991,
  job: 'tanár',
  friends: ['Michael', 'Peter', 'Steven']
};

console.log(janos);

A konzolban megvizsgálhatod az objektum tulajdonságait. A fejlesztői eszköz megjelenítheti őket ábécérendben is; ez böngészőfüggő megjelenítés. A tulajdonságokat névvel érjük el, nem a konzolban látható helyük alapján.

Pontjelölés és szögletes zárójeles jelölés

console.log(janos.lastName);    // Kovács
console.log(janos['lastName']); // Kovács

A pont utáni név megadja, melyik tulajdonságot szeretnénk kiolvasni. A pont a tulajdonság-elérés operátora. A második alakban a szögletes zárójelek közé a tulajdonság nevét tartalmazó karakterláncot írjuk. Mindkettő ugyanazt az értéket adja.

A zárójelek hasonlítanak a tömbök indexelésére, de itt egy elnevezett tulajdonságot választunk ki.

Kifejezés a szögletes zárójelek között

const nameKey = 'Name';

console.log(janos['first' + nameKey]); // János
console.log(janos['last' + nameKey]);  // Kovács

A firstName és lastName közös része a Name. Először a szögletes zárójelben álló kifejezés értékelődik ki: a 'first' + nameKey eredménye 'firstName'. Ezután a JavaScript az így kapott nevű tulajdonságot olvassa ki. Az összefűzés helyett sablonliterál is használható.

console.log(janos[`first${nameKey}`]); // János

// Hibás szintaxis, ne futtasd így:
// console.log(janos.'first' + nameKey);

A pont után közvetlenül a tulajdonság azonosítóként használható nevét írjuk, nem számítást vagy idézőjeles szöveget. Ha a név kiszámított, vagy változóban érkezik, szögletes zárójelet használunk. Egy ismert, egyszerű névhez általában a rövidebb pontjelölést választjuk.

A felhasználó választja ki az adatot

A böngészőben a prompt() beviteli ablakot nyit. A megadott szöveget visszaadja, ezért eltárolhatjuk egy változóban. A Mégse gomb eredménye null.

const interestedIn = prompt(
  'Mit szeretnél tudni Jánosról? Válassz: firstName, lastName, age, job, friends'
);

console.log(interestedIn);
console.log(janos.interestedIn); // undefined
console.log(janos[interestedIn]);

Ha job a válasz, akkor a változó értéke a 'job' szöveg. A janos.interestedIn szó szerint az interestedIn nevű tulajdonságot keresi. Ilyen nincs, ezért undefined az eredmény. A janos[interestedIn] a változó értékét használja névként, így a job értékét, a 'tanár' szöveget kapjuk.

Próbáld ki a location választ is! Ezt a tulajdonságot még nem adtuk meg, ezért a zárójeles elérés is undefined értéket ad. Figyelj a kis- és nagybetűkre: a firstName és a firstname különböző név.

Nem létező tulajdonság kezelése

A korábbi interestedIn változót használva a kiírásokat cseréld erre:

if (janos[interestedIn]) {
  console.log(janos[interestedIn]);
} else {
  console.log('Hibás kérés! Válassz: firstName, lastName, age, job, friends');
}

A hiányzó tulajdonság értéke undefined, amely falsy, ezért az else ág fut. A példában szereplő nem üres szövegek, a nem nulla életkor és a barátok tömbje truthy értékek.

Ez az ellenőrzés az érték igazságértékét vizsgálja, nem általánosan a tulajdonság létezését. Egy létező tulajdonság 0, false vagy üres karakterlánc értéke szintén az else ágba vezetne. A mostani objektumnál ez nem okoz problémát.

A kódsorok mozgatásához a VS Code-ban Windows alatt az Alt + fel/le nyíl, Macen az Option + fel/le nyíl használható.

Új tulajdonság hozzáadása és meglévő módosítása

janos.location = 'Portugália';
janos['twitter'] = '@janos';
console.log(janos);

Mindkét jelöléssel hozzáadhatunk új tulajdonságot: az elérés bal oldalára értéket adunk. A konzolban már a location és a twitter is megjelenik. Zárójelek között itt is használhatunk változót vagy más kifejezést.

janos.job = 'programozó';
janos['job'] = 'tanár';

Ha a tulajdonság már létezik, ugyanígy módosítjuk az értékét. A const mellett az objektum tartalma módosítható, de a janos változóhoz nem rendelhetünk egy másik objektumot.

A kód felülről lefelé fut: ha a location hozzáadása a bekérés után van, az első bekéréskor még nem létezik. Frissítéskor a prompt() ismét megjelenik; a bekérést tartalmazó részt ideiglenesen kikommentezheted, ha csak az új példákat próbálod.

Önálló próba: mondat az objektum adataiból

Írasd ki a következő mondatot úgy, hogy a nevet, a barátok számát és az első barát nevét az objektumból veszed, nem kézzel írod be:

János barátainak száma 3, és a legjobb barátját Michaelnek hívják.

A példában az első barátot tekintjük a legjobb barátnak. Tipp: a friends egy tömb; a hosszához a length, az első eleméhez a [0] tartozik. Próbáld meg önállóan, mielőtt megnyitod a megoldást!

Megoldás és magyarázat
console.log(
  `${janos.firstName} barátainak száma ${janos.friends.length}, és a legjobb barátját ${janos.friends[0]}nek hívják.`
);

A janos.friends eredménye a barátok tömbje. A length minden tömbön rendelkezésre álló tulajdonság, nem kell külön létrehoznunk. A janos.friends[0] pedig ennek a tömbnek az első elemét adja.

Miért működik a láncolás?

A pontjelölés és a számított, szögletes zárójeles tulajdonság-elérés magas precedenciájú művelet. A láncot balról jobbra követjük:

janos.friends.length
// 1. janos.friends → ['Michael', 'Peter', 'Steven']
// 2. a kapott tömb .length tulajdonsága → 3

janos.friends[0]
// 1. janos.friends → a barátok tömbje
// 2. a kapott tömb [0] eleme → 'Michael'

A ponttal előbb az objektum tömböt tartalmazó tulajdonságát érjük el, majd a kapott tömbbel dolgozunk tovább. A zárójeleken belüli kifejezés külön kiértékelődik. A használat gyakorlással válik természetessé; nem kell teljes precedenciatáblázatot bemagolnod.
