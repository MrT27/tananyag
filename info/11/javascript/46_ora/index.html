Alapműveletek

Számítás, szövegek összefűzése, értékadás és összehasonlítás.

Számoljunk életkort

Az operátor értékeken végez műveletet. A - például két szám különbségét adja. Jonas a példában 2037-et használ. Az évszám a now változóban szerepel, így egy helyen kell átírni. A const azért illik ide, mert a program később nem ad új értéket ezeknek a változóknak.

const now = 2037;
const ageJonas = now - 1991;
const ageSarah = now - 2018;
console.log(ageJonas, ageSarah); // 46 19
console.log(ageJonas * 2, ageJonas / 10, 2 ** 3); // 92 4.6 8

A console.log() vesszővel elválasztva több értéket is kiír. A * szoroz, a / oszt, a ** hatványoz. A 2 ** 3 ugyanannyi, mint a 2 * 2 * 2.

Szövegek összefűzése

Két számnál a + összead, két szövegnél összefűz. A szóközt külön adjuk hozzá. Később ugyanezt sablonliterállal is megoldjuk.

const firstName = "Jonas";
const lastName = "Schmedtmann";
console.log(firstName + lastName);       // JonasSchmedtmann
console.log(firstName + " " + lastName); // Jonas Schmedtmann

Az előző leckében a typeof operátorral állapítottuk meg egy érték típusát.

Értékadás lépésenként

A let x = 10 + 5; sorban először az összeadás történik meg, majd az eredmény kerül az x-be. Azért használunk let-et, mert később új értékeket adunk neki.

let x = 10 + 5; // 15
x += 10;        // x = x + 10 → 25
x *= 4;         // x = x * 4 → 100
x++;            // eggyel nő → 101
x--;            // eggyel csökken → 100
x--;            // 99
console.log(x); // 99

Hasonló rövidítés a -= és a /=. Írj a sorok közé console.log(x) kiírásokat, hogy lásd a köztes értékeket is.

Összehasonlítás

A >, <, >= és <= művelet eredménye true vagy false. A „legalább 18” feltételbe a 18 is beleszámít.

console.log(ageJonas > ageSarah); // true
console.log(ageSarah >= 18);     // true
const isFullAge = ageSarah >= 18;
console.log(isFullAge);         // true
console.log(now - 1991 > now - 2018); // true

Futtasd ezt az életkoros kód után. Ha Sarah születési évét 2019-re írod át, 18 éves lesz, és az isFullAge értéke true marad. Ha 2020-ra írod át, 17 éves lesz, és false-t kapsz. A tárolt logikai értéket később feltételként is használhatod.

Az oldal betöltése után a konzolban is kipróbálhatod az ageSarah >= 18 kifejezést. A konzolban végzett próbák nem kerülnek automatikusan a script.js fájlba. Az utolsó sorban mindkét kivonás megelőzi az összehasonlítást. A következő, 14. videó megmutatja, miért.

Önálló feladat

Indulj let x = 15; értékről. Adj hozzá 5-öt, szorozd meg hárommal, majd csökkentsd eggyel. Használj rövidített operátorokat, és ellenőrizd, hogy a végeredmény 59.
