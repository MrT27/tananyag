Utasítások és kifejezések

Mi kerülhet egy sablonliterál helyőrzőjébe?

A kifejezésnek értéke van

A 3 + 4 kiértékelve 7. Egy önálló szám, például a 1991, szintén kifejezés. A logikai operátorokat összekapcsoló kifejezésnek is van értéke. Az alábbi példákat írd be egyenként a böngésző konzoljába.

3 + 4                       // 7
1991                        // 1991
true && false && !false     // false

Az utasítás megadja, mit tegyen a program

János hasonlatában az utasítás olyan, mint egy mondat, a benne lévő kifejezések pedig a mondat részei. Az if és a switch utasítás vezérli, melyik kódrész fusson le.

if (23 > 10) {
  const str = "A 23 nagyobb.";
}

A 23 > 10 logikai kifejezés. A "A 23 nagyobb." szöveg szintén kifejezés, a teljes const sor pedig deklaráció. Egy kifejezés önálló utasításként is szerepelhet. A pontosvessző önmagában ezért nem dönti el, hogy a soron belül mi számít kifejezésnek.

A helyőrzőbe kifejezés kerül

const firstName = "János";
console.log(`A nevem ${firstName}, ${2037 - 1991} éves vagyok.`);

A név kiértékelésekor a tárolt szöveget, a kivonásból a 46-ot kapjuk. Mindkét érték bekerül a mondatba.

Mi történik, ha if-et írsz a helyőrzőbe?

Ezt külön próbáld ki. Az if utasítás helyén a JavaScript kifejezést vár, ezért SyntaxError-t jelez.

console.log(`${if (23 > 10) { "A 23 nagyobb." }}`);

Önálló próba

Hozz létre egy birthYear változót 2012-es értékkel. Írj sablonliterált, amelyben a helyőrző a 2037 - birthYear kifejezéssel számolja ki az életkort. Ellenőrizd, hogy a mondatban 25 jelenik meg.
