A feltételes operátor

Válassz két érték közül egy feltétel alapján.

Három rész, két lehetséges eredmény

A minta feltétel ? igaz_ág : hamis_ág. A kérdőjel után az igaz eset kifejezése áll, a kettőspont után a hamis eseté. Mindhárom rész kötelező. Innen ered a ternáris elnevezés. Csak a kiválasztott ág értékelődik ki. Mindkét ág egy kifejezést tartalmaz, amely több sorban is állhat.

const age = 23;
age >= 18 ? console.log("Szeretek bort inni.") : console.log("Szeretek vizet inni.");

A 23 éves szereplőnél az első kiírás fut. Írd át a kort 15-re, és a második fut. A 18 is az igaz ághoz tartozik a >= miatt.

A kiválasztott érték eltárolása

Jonas először közvetlenül az ágakban írta ki az üzenetet. Gyakrabban magát az értéket választjuk ki, majd egyszer írjuk ki. Tartsd meg az előző age deklarációt, és a kiíró sort cseréld erre:

const drink = age >= 18 ? "bor" : "víz";
console.log(drink);

Az egész feltételes kifejezés eredménye egy szöveg. A drink a deklarációkor megkapja ezt az értéket, így itt használható a const.

Kapcsolat a Pythonban tanultakkal

Pythonban már találkozhattál a feltételes kifejezéssel. Mindkét nyelvben egy feltétel alapján választunk két érték közül, de eltér a részek sorrendje.

Python

age = 23
drink = "bor" if age >= 18 else "víz"
print(drink)  # bor

JavaScript

const age = 23;
const drink = age >= 18 ? "bor" : "víz";
console.log(drink); // bor

A JavaScript-példát külön futtasd, mert az előző példákban már létrehoztuk az age és drink változót.

  • Pythonban a sorrend igaz_érték if feltétel else hamis_érték.
  • JavaScriptben a sorrend feltétel ? igaz_érték : hamis_érték.

Mindkét teljes kifejezés eredménye egy kiválasztott érték, amelyet a drink változóban tárolunk. Írd át mindkét példában az életkort 15-re. Mindkét nyelvben a "víz" értéket kell kapnod.

Ugyanez if és else segítségével

let drink2;
if (age >= 18) {
  drink2 = "bor";
} else {
  drink2 = "víz";
}
console.log(drink2);

A drink2 az elágazás előtt jön létre, mert utána is használjuk. Az ágakban csak értéket adunk neki. Próbáld ki mindkét megoldást 23 és 15 éves korral. Mindkettő ugyanazt az italt adja.

Feltételes érték a sablonliterálban

console.log(`Szeretek ${age >= 18 ? "bort" : "vizet"} inni.`);

Az előző leckében az if utasítás hibát okozott a ${…} helyőrzőben. A feltételes operátor itt használható, mert a teljes kifejezés értéke a mondatba illeszthető "bort" vagy "vizet". Ha egy feltételtől több külön utasítás függ, az if / else blokkban áttekinthetőbb marad a kód.

Önálló próba

Futtasd a sablonliterálos példát 17, 18 és 19 éves korral. Ezután tárold a "bort" vagy "vizet" egy változóban, és a helyőrzőbe ennek a nevét írd. Ellenőrizd, hogy ugyanazt a mondatot kapod.
