Szigorú mód bekapcsolása

Egy elgépelt változónév példáján nézzük meg, milyen hibát segít megtalálni a szigorú mód.

Hova kerül a „use strict”?

Írd a "use strict"; direktívát a script.js elejére, a változók és egyéb utasítások elé. Felette lehet üres sor vagy megjegyzés. A szigorú mód tilt bizonyos műveleteket, és egyes korábban észrevétlen hibákat a konzolon is jelez.

Jogosítványos példa

Próbáld ki egy új, hagyományos böngészős szkriptben. Az első futtatáskor hagyd kommentben a direktívát. Mentsd a fájlt, töltsd újra az oldalt, és figyeld a konzolt.

// "use strict";

let hasDriversLicense = false;
const passTest = true;

if (passTest) {
  hasDriverLicense = true;
}

if (hasDriversLicense) {
  console.log("Vezethetek.");
}

A vizsga sikerült, mégsem jelenik meg az üzenet. Az értékadásból hiányzik egy s. A hasDriverLicense így egy másik név. Szigorú mód nélkül az értékadás létrehozhat egy tulajdonságot a globális objektumon, a böngészőben a window-n. A valódi változó értéke false marad.

  1. Vedd le a //-t az első sorról, mentsd és frissíts. A konzol ReferenceError-t jelez az elgépelt névnél. Keresd meg a hibaüzenetben a fájlt és a sorszámot.
  2. Javítsd a nevet hasDriversLicense-ra. Újratöltés után megjelenik a Vezethetek. üzenet.

A passTest itt egyszer kap értéket, ezért const. A hasDriversLicense a sikeres vizsga után új értéket kap, ezért let.

Foglalt változónevek

Próbáld ki a következő két deklarációt külön-külön, a fájl elején aktív "use strict"; mellett.

const interface = "hangkártya";
const private = 23;

Mindkettő SyntaxError-t okoz már beolvasáskor, mert szigorú módban ezek foglalt szavak. Hasonló névadási szabállyal találkoztunk A korábbi leckében. Az if például mindkét módban foglalt. A próbák után kommentezd ki a hibás sorokat.

A példa a következő leckék hagyományos szkriptjeiben bekapcsolva hagyja a szigorú módot. A következő téma a függvények használata.
