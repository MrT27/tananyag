Műveleti sorrend

Miért számolja ki a JavaScript mindkét életkort az összehasonlítás előtt?

Melyik operátor köt erősebben?

const now = 2037;
const ageJanos = now - 1991;
const ageSarah = now - 2018;

console.log(now - 1991 > now - 2018); // true
console.log(ageJanos > ageSarah);     // true

A kivonás elsőbbséget élvez a > operátorral szemben. Az első összehasonlítás ezért úgy csoportosul, mintha ezt írnánk: (now - 1991) > (now - 2018). A 46 > 19 eredménye true.

Az elsőbbséget az MDN műveleti sorrend táblázatában ellenőrizheted. Keresd meg benne a kivonást és a relációs operátorokat. A táblázat azt is mutatja, hogyan csoportosulnak az azonos szintű műveletek.

Balról vagy jobbról csoportosítunk?

A kivonás balról csoportosul. Ha zárójellel a jobb oldali kivonást csoportosítod, más eredményt kapsz.

console.log(25 - 10 - 5);   // 10
console.log((25 - 10) - 5); // 10
console.log(25 - (10 - 5)); // 20

A láncolt értékadás jobbról csoportosul. A kivonások eredménye 10. A y = 10 értékadás eredménye maga a 10, ezért az x is ezt kapja. A csoportosítás így olvasható: x = (y = (25 - 10 - 5)).

let x, y;
x = y = 25 - 10 - 5;
console.log(x, y); // 10 10

Átlagéletkor zárójellel

Futtasd ezt az első példa változóival. Az osztás erősebben köt az összeadásnál, így az első sorban csak Sarah életkora feleződik. Az 55,5 nagyobb mindkét életkornál, ezért nem lehet a kettő átlaga. A zárójellel a két életkor összegét osztjuk el kettővel.

console.log(ageJanos + ageSarah / 2); // 55.5
const averageAge = (ageJanos + ageSarah) / 2;
console.log(averageAge); // 32.5
