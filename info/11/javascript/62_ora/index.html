A switch utasítás

Jonas a hét napjaihoz rendel feladatokat. A program a nap értéke alapján választ közülük.

Egy érték, több eset

A switch (day) megkeresi az egyező case címkét. Az egyezés szigorú, mint a day === "hétfő" összehasonlítás. A címke után kettőspont áll. A break kilép a switch-ből, a default pedig az egyező eset nélkül érkező értékeket kezeli.

const day = "hétfő";

switch (day) {
  case "hétfő":
    console.log("Megtervezem a kurzus felépítését.");
    console.log("Elmegyek egy programozói találkozóra.");
    break;
  case "kedd":
    console.log("Előkészítem az elméleti videókat.");
    break;
  case "szerda":
  case "csütörtök":
    console.log("Kódpéldákat írok.");
    break;
  case "péntek":
    console.log("Videókat veszek fel.");
    break;
  case "szombat":
  case "vasárnap":
    console.log("Pihenek a hétvégén.");
    break;
  default:
    console.log("Érvénytelen nap.");
}

A szerda és a csütörtök közös utasításokat kap, ahogy a szombat és a vasárnap is. Próbáld ki a "csütörtök" és az "ünnepnap" értéket is.

Mi történik a break nélkül?

Állítsd vissza a day értékét hétfőre, és vedd ki csak az első break-et. A hétfő két feladata után a keddi feladat is megjelenik. Ha egyszer elindult egy eset, a futás a következő címke utáni utasításokra is átmegy a következő break-ig vagy a blokk végéig. Ez teszi lehetővé a szerdai és csütörtöki eset összevonását is. A próba után tedd vissza az első break-et.

Ugyanez if és else if utasításokkal

Írd át a feladatot if / else if / else szerkezetre. Szerdán vagy csütörtökön kell kódpéldát írni, ezért itt || kapcsolja össze a két összehasonlítást.

Megoldás megnyitása

A korábban megadott day változót használd. Ha a két megoldás egymás alatt van, ugyanazok az üzenetek kétszer jelennek meg.

if (day === "hétfő") {
  console.log("Megtervezem a kurzus felépítését.");
  console.log("Elmegyek egy programozói találkozóra.");
} else if (day === "kedd") {
  console.log("Előkészítem az elméleti videókat.");
} else if (day === "szerda" || day === "csütörtök") {
  console.log("Kódpéldákat írok.");
} else if (day === "péntek") {
  console.log("Videókat veszek fel.");
} else if (day === "szombat" || day === "vasárnap") {
  console.log("Pihenek a hétvégén.");
} else {
  console.log("Érvénytelen nap.");
}

A switch jól illik egy érték konkrét eseteihez. Az if akkor is használható, ha például tartományt vizsgálsz a >= operátorral.
