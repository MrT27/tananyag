Függvények összefoglalása

Az életkorszámítás, az egymást hívó függvények és a visszatérés közös példája.

A nyugdíjas példa újraírása

A 36. lecke nyílfüggvényét hagyományos függvénykifejezéssé alakítjuk. A számítást először így írd meg, a korábbi azonos nevű függvényt kommentezd ki:

'use strict';

const yearsUntilRetirement = function (birthYear, firstName) {
  const age = 2037 - birthYear;
  const retirement = 65 - age;
  return retirement;
};

console.log(yearsUntilRetirement(1991, "János")); // 19
console.log(yearsUntilRetirement(1970, "Mike"));  // -2

A példa választott éve 2037, a feltételezett nyugdíjkorhatár 65. Mike eredménye negatív, ezért külön kezeljük a korhatárt már elért személyt.

Külön életkorszámító, feltételes visszatérés

Cseréld az előző példát erre. A calcAge külön végzi az életkorszámítást, a másik függvény ezt hívja meg.

const calcAge = function (birthYear) {
  return 2037 - birthYear;
};

const yearsUntilRetirement = function (birthYear, firstName) {
  const age = calcAge(birthYear);
  const retirement = 65 - age;

  if (retirement > 0) {
    console.log(`${firstName} ${retirement} év múlva megy nyugdíjba.`);
    return retirement;
  } else {
    console.log(`${firstName} már elérte a példában megadott nyugdíjkorhatárt.`);
    return -1;
  }
};

console.log(yearsUntilRetirement(1991, "János"));
console.log(yearsUntilRetirement(1950, "Mike"));

A két birthYear két külön helyi paraméter. Az 1991 először a yearsUntilRetirement paraméterébe kerül. A calcAge(birthYear) hívás ezt az értéket adja tovább a calcAge saját paraméterének. Innen 46 tér vissza, így 19 év marad. Ha a calcAge paraméterét és a törzsében használt nevét együtt átírod year-re, az eredmény ugyanaz marad.

A -1 ebben a függvényben választott jelzőérték arra, hogy a számított hátralévő idő nem pozitív. A jelentését a saját programunk határozza meg. A függvény mindkét ágban számot ad vissza, ezért az eredményt később számításban vagy feltételben is felhasználhatjuk.

A return azonnal befejezi a hívást

Tedd az ágakban lévő console.log() sort a hozzá tartozó return alá. Az üzenet eltűnik, mert a futás már visszatért a hívás helyére. Ezután mozgasd a kiírást vissza a return elé.

A VS Code-ban a sor feljebb mozgatása Windowson Alt + ↑, Macen Option + ↑. A kijelölt név következő előfordulását Windowson Ctrl + D, Macen Command + D jelöli ki. Ellenőrizd a kijelöléseket átnevezés előtt.

A három megismert alak

  • Függvénydeklaráció. Például function calcAge(birthYear) { return 2037 - birthYear; }. A saját hatókörén belül a szövegbeli helye előtt is hívható.
  • Függvénykifejezés. Például const calcAge = function (birthYear) { return 2037 - birthYear; };. A függvényértéket változó tárolja, amelynek a hívás előtt meg kell kapnia az értékét.
  • Nyílfüggvény. Például const calcAge = birthYear => 2037 - birthYear;. Kifejezéstörzzsel implicit a visszatérés. Saját this kötése nincs, a környezetét használja, ezt később részletezzük.

Mindegyik forma fogadhat bemeneti adatokat, dolgozhat velük és visszaadhat eredményt. Paraméter nélküli függvény is lehet, és a kifejezett return is elhagyható, ilyenkor a szokásos blokkos függvény visszatérési értéke undefined.

A console.log és a return szerepe

A calcAge név a függvényértékre hivatkozik. A calcAge(1991) meghívja azt, és a return miatt a kifejezés értéke 46 lesz. A const age = calcAge(1991); ezt tárolja el.

A függvényen belüli console.log() egy másik függvényhívás, amely a konzolba ír. A saját függvényünk visszaadott értékét a return határozza meg. A fenti külső console.log(yearsUntilRetirement(...)) ezért először a belső üzenetet, aztán a visszaadott számot írja ki.

Önálló ellenőrzés

Tippeld meg a visszaadott értéket 1991-es, 1972-es és 1950-es születési évnél. Futtasd a példákat különböző keresztnevekkel. A példában 1972-nél nulla év marad, ezért az else ág fut és -1 tér vissza. Mutasd meg a paramétert, az argumentumot, a függvénytestet, a belső hívást és a visszatérést.
