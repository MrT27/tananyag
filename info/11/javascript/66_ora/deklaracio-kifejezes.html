Függvénydeklarációk és függvénykifejezések

Ugyanazt az életkorszámítást kétféle alakban írjuk meg.

Függvénydeklaráció

'use strict';

function calcAge1(birthYear) {
  return 2037 - birthYear;
}

const age1 = calcAge1(1991);
console.log(age1); // 46

A birthYear paraméter a függvényen belüli bemenet neve, az 1991 argumentum a híváskor átadott érték. A return közvetlenül visszaadhatja a kivonás eredményét. A hívás 46-ot ad, ezt tároljuk az age1 változóban. A 2037 itt a példa választott éve.

Függvénykifejezés

Írd az előző példa alá. Itt a function után nincs külön függvénynév. A névtelen függvénykifejezés értékét a calcAge2 változóban tároljuk.

const calcAge2 = function (birthYear) {
  return 2037 - birthYear;
};

const age2 = calcAge2(1991);
console.log(age1, age2); // 46 46

Mindkét függvényt névvel és zárójelpárral hívjuk meg, és ugyanúgy használhatjuk a visszaadott értéket. A calcAge2 maga a függvényérték, a calcAge2(1991) a hívás eredménye. A függvények JavaScriptben értékek, ezért változóban tárolhatók, és később más függvénynek is átadhatók. Ez lesz fontos az eseménykezelésnél is.

Mi történik, ha előbb hívjuk meg?

A következő két változatot külön-külön próbáld ki, az előző példákat előbb kommentezd ki. A fájl legfelső 'use strict'; sorát tartsd meg.

console.log(calcAge1(1991)); // 46

function calcAge1(birthYear) {
  return 2037 - birthYear;
}
console.log(calcAge2(1991)); // ReferenceError

const calcAge2 = function (birthYear) {
  return 2037 - birthYear;
};

A függvénydeklaráció a saját hatókörén belül már a szövegbeli helye előtt is hívható. A const-ban tárolt függvénykifejezéshez a változó inicializálása előtt nem férünk hozzá. A konzol például a Cannot access 'calcAge2' before initialization üzenettel jelzi ezt.

A háttérben a deklarációk feldolgozása, az úgynevezett hoisting és a változó inicializálásának szabályai állnak. Ezeket később részletesebben vizsgáljuk. Most a hívás helyével kapcsolatos különbséget gyakorold.

Melyiket használjuk?

A függvénykifejezés használata segíthet, mert így a függvény létrehozása a hívások elé kerül. Ez személyes kódolási szokás. Mindkét alakot ismernünk kell, mert mindkettővel találkozunk mások kódjában.

Hívd meg mindkét életkorszámító függvényt 1980-as argumentummal is. Előbb tippelj, majd ellenőrizd, hogy mindkét eredmény 57. Ezután mondd el, mi a különbség a birthYear, az 1980, a calcAge2 és a calcAge2(1980) között.
