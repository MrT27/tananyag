Nyílfüggvények

A függvénykifejezés ES2015-ben bevezetett rövidebb alakja.

Életkorszámítás röviden

A példa az előző függvénykifejezésből indul ki. A nyílfüggvényt is változóban tároljuk, és ugyanúgy hívjuk meg.

'use strict';

const calcAge2 = function (birthYear) {
  return 2037 - birthYear;
};

const calcAge3 = birthYear => 2037 - birthYear;
const age3 = calcAge3(1991);
console.log(age3); // 46

A => egy egyenlőségjel és egy nagyobb jel egymás után. Egyetlen egyszerű paraméternél a név körüli kerek zárójel elhagyható. A nyíl után itt egy kifejezés áll, amelynek értékét a függvény automatikusan visszaadja. Ez az implicit visszatérés.

Több utasítás a függvénytestben

A következő példában a választott év 2037, a feltételezett nyugdíjkorhatár 65 év. A számítás két lépésből áll, ezért kapcsos zárójelű blokkot írunk, és a visszaadott értéket return jelöli.

const yearsUntilRetirement = birthYear => {
  const age = 2037 - birthYear;
  const retirement = 65 - age;
  return retirement;
};

console.log(yearsUntilRetirement(1991)); // 19

Kapcsos zárójelű törzsnél a visszatéréshez ki kell írni a return-t. Ha ezt elhagyod, a hívás eredménye undefined. A döntő különbség a kifejezéstörzs és a blokkos törzs között van, akkor is, ha a kódot egy sorba rendezed.

Két paraméter és visszaadott mondat

Az előző yearsUntilRetirement példát kommentezd ki, és cseréld erre. Több paraméter köré kötelező a kerek zárójel. A hívás első argumentuma a születési évhez, a második a keresztnévhez kerül.

const yearsUntilRetirement = (birthYear, firstName) => {
  const age = 2037 - birthYear;
  const retirement = 65 - age;
  return `${firstName} ${retirement} év múlva megy nyugdíjba.`;
};

console.log(yearsUntilRetirement(1991, "János"));
console.log(yearsUntilRetirement(1980, "Bob"));

Jánosnál 19 év, Bobnál 8 év jelenik meg. A közös függvény ugyanazzal a számítással, különböző bemenetekből állítja elő a két mondatot.

Mikor használjuk?

Egyelőre az egyszerű kifejezésekhez használ nyílfüggvényt, az összetettebb példákban többnyire hagyományos függvénykifejezéssel dolgozik. A nyílfüggvénynek saját this kötése nincs, a környezetéből veszi át. Ennek jelentőségét később az objektumoknál vizsgáljuk meg.

Önálló próba

Hívd meg a calcAge3 függvényt 2000-rel. Ellenőrizd, hogy 37-et kapsz. A számmal visszatérő nyugdíjas példában kommentezd ki a return retirement; sort, és nézd meg az eredményt. Végül állítsd vissza a sort.
