Függvények

Írj meg egy kódrészletet egyszer, majd használd többször, akár különböző adatokkal.

Deklaráció és meghívás

A function kulcsszó után megadjuk a függvény nevét, majd kerek zárójelet írunk. A kapcsos zárójelek közötti rész a függvénytest. A test akkor fut le, amikor meghívjuk a függvényt a nevével és a zárójelpárral.

"use strict";

function logger() {
  console.log("A nevem Jonas.");
}

logger();
logger();
logger();

A három hívás háromszor írja ki ugyanazt az üzenetet. Kommentezd ki a hívásokat, majd töltsd újra az oldalt. A deklaráció megmarad, a kiírás eltűnik.

Paraméterek és argumentumok

Jonas gyümölcsfeldolgozója almát és narancsot kap, majd elkészíti a gyümölcslé leírását. Az apples és az oranges a deklarációban megadott paraméterek. A híváskor megadott konkrét értékek az argumentumok. A fruitProcessor(5, 0) hívásnál az első paraméter értéke 5, a másodiké 0.

function fruitProcessor(apples, oranges) {
  console.log(apples, oranges);
  const juice = `Gyümölcslé ${apples} db almából és ${oranges} db narancsból.`;
  return juice;
}

const appleJuice = fruitProcessor(5, 0);
console.log(appleJuice);

const appleOrangeJuice = fruitProcessor(2, 4);
console.log(appleOrangeJuice);

A paraméterek az adott függvényhíváson belül használhatók. A második hívásban új értékeket kapnak, így ugyanaz a függvény másik leírást készít. A függvénytörzs első kiírása megmutatja a bemeneteket, ezért a konzolon az első hívásnál előbb 5 0 jelenik meg, utána a gyümölcslé leírása.

Visszaadott érték és kiírás

A return juice; befejezi a függvény futását, és átadja a szöveget a hívás helyének. Így az eredményt eltárolhatjuk vagy közvetlenül kiírhatjuk.

console.log(fruitProcessor(5, 0));

A logger() paraméterek nélkül is működik. Ha logger(23) alakban hívod, a függvény ebben a példában nem használja a 23-at. Mivel nincs return utasítása, a hívás értéke undefined, miközben a függvény kiírja az üzenetet. Próbáld ki a console.log(logger()); sort, és figyeld meg mindkét kiírást.

A console.log() és a Number() hívását már ismered. A Number("23") hívás argumentuma a "23" szöveg, a visszaadott értéke a 23 szám.

Önálló próba

Készíts leírást három narancsból és nulla almából, majd egy másik hívással egy almából és két narancsból. Az egyik eredményt tárold változóban, a másikat írd ki közvetlenül. Ezután módosítsd a leírás szövegét a függvényben, és figyeld meg, hogy mindkét hívás az új formát adja. Ez a DRY elv (Don't Repeat Yourself) egyik példája. A közös kódot egy helyen tartjuk karban.
