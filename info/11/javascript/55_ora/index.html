Döntések az if és else segítségével

A program a feltétel eredménye alapján választ a kódblokkok közül.

Egy feltétel, egy ág

A jogosítványos példában 18 év a feladatban választott korhatár. A >= miatt a pontosan 18 éves személy is megfelel.

const age = 19;
const isOldEnough = age >= 18;

if (isOldEnough) {
  console.log("Sarah elkezdheti a jogosítvány megszerzését.");
}

Az if után kerek zárójelbe írjuk a feltételt, kapcsos zárójelbe pedig a hozzá tartozó utasításokat. A blokk több sorból is állhat. Futtasd 19, majd 15 éves korral. A második futásnál a feltétel hamis, ezért a blokk kimarad, és ebből az elágazásból nem érkezik üzenet.

Mi történjen a másik esetben?

Cseréld le az előző példát erre. A feltételt most közvetlenül az if-be írjuk. Ha hamis, az else blokk fut le. Az else opcionális, nélküle a program az if után folytatódik.

const age = 15;

if (age >= 18) {
  console.log("Sarah elkezdheti a jogosítvány megszerzését.");
} else {
  const yearsLeft = 18 - age;
  console.log(`Sarah még túl fiatal. Várnia kell még ${yearsLeft} évet.`);
}

15 éves korban három év van hátra. Próbáld ki 17, 18 és 19 éves korral is. Az if / else vezérlési szerkezet, mert a feltétel dönti el, melyik blokk fut le. A két ág után a program a következő utasítással folytatódik.

Értékadás az ágakban

A második példa az 1901 és 2100 közötti évekre ad választ. A 2000 még a 20. századhoz, a 2001 már a 21. századhoz tartozik.

const birthYear = 1998;
let century;

if (birthYear <= 2000) {
  century = 20;
} else {
  century = 21;
}

console.log(century); // 20

A century változót az elágazás előtt deklaráljuk, így utána is elérhető. Az ágakban csak értéket adunk neki. Ha a külső let century; sort törlöd, és mindkét ágban külön let century változót hozol létre, a blokk utáni kiírás ReferenceError-t ad. Próbáld ki külön, majd állítsd vissza a működő változatot. A birthYear értékét írd át 2012-re, és ellenőrizd, hogy 21-et kapsz.

Önálló próba

A százados példát futtasd 2000-rel és 2001-gyel. Előbb tippelj, majd ellenőrizd, hogy melyik ág ad értéket a century változónak.
