A játék logikája

Titkos számot sorsolunk, összehasonlítjuk a tippel, és vezetjük a pontszámot.

Véletlen szám 1 és 20 között

A Math a JavaScript beépített objektuma. A konzolban egymás után próbáld ki ezeket:

Math.random()
Math.random() * 20
Math.trunc(Math.random() * 20)
Math.trunc(Math.random() * 20) + 1

A Math.random() legalább 0, de 1-nél kisebb számot ad. Szorzás után az érték 0-tól 20 alá esik. A Math.trunc() levágja a törtrészt, így 0–19 közötti egészet kapunk. A hozzáadott 1 ezt 1–20-ra tolja.

A titkos számot az eseménykezelőn kívül hozzuk létre. Így egy oldalbetöltéskor egyszer sorsolunk. A kezelőn belül minden kattintás új számot eredményezne.

A négy eset és a pontozás

Cseréld le a 77. lecke eseménykezelőjét az alábbi teljes kódra. A korábbi próbákat kommentezd ki. Először az üres bemenetet, aztán az egyezést, majd a túl magas és túl alacsony tippet vizsgáljuk.

'use strict';

const secretNumber = Math.trunc(Math.random() * 20) + 1;
let score = 20;

// Fejlesztés közben láthatóvá tesszük a számot.
document.querySelector('.number').textContent = secretNumber;

document.querySelector('.check').addEventListener('click', function () {
  const guess = Number(document.querySelector('.guess').value);

  if (!guess) {
    document.querySelector('.message').textContent = "⛔ Nem adtál meg számot!";
  } else if (guess === secretNumber) {
    document.querySelector('.message').textContent = "🎉 Helyes szám!";
  } else if (guess > secretNumber) {
    if (score > 1) {
      document.querySelector('.message').textContent = "📈 Túl magas!";
      score--;
      document.querySelector('.score').textContent = score;
    } else {
      document.querySelector('.message').textContent = "💥 Elvesztetted a játékot!";
      score = 0;
      document.querySelector('.score').textContent = score;
    }
  } else if (guess < secretNumber) {
    if (score > 1) {
      document.querySelector('.message').textContent = "📉 Túl alacsony!";
      score--;
      document.querySelector('.score').textContent = score;
    } else {
      document.querySelector('.message').textContent = "💥 Elvesztetted a játékot!";
      score = 0;
      document.querySelector('.score').textContent = score;
    }
  }
});

A score állapotváltozó. A pontszámot a programban tároljuk, majd a DOM-ban megjelenítjük. A secretNumber is az alkalmazás állapotának része. Az állapot azokból az adatokból áll, amelyekre a működéshez szükségünk van. A pontszám let, mert változik. A score-- ugyanazt a csökkentést végzi, mint a score = score - 1.

Miért score > 1?

Ha a feltétel score > 0 lenne, az 1 pontos játékos hibás tippjénél még a csökkentő ág futna. A vesztes üzenet csak a következő hibás tippnél jelenne meg. A score > 1 feltétellel már az utolsó pont elvesztésekor a vesztes ágba lépünk, és a pontszámot nullára állítjuk.

A két hibás tipp ága most hasonló kódot tartalmaz. Jonas ezt később közösíti. A fejlesztéshez megmutatott titkos számot is el fogjuk rejteni. Ebben a változatban a további kattintásokat még nem tiltjuk le, így a nulla pont utáni helyes tipp is találatot jelezhet. A teljes körlezárás külön kiegészítés lesz.

Próbáld ki az eseteket

  1. Üres mezővel kattints. A pontszám maradjon 20.
  2. Adj a látható titkos számnál nagyobb, majd kisebb tippet. Mindkét hibás tipp csökkentse a pontszámot. Teszteléskor akár 21-et és -1-et is használhatsz, mert most még nincs tartományellenőrzés.
  3. Tippelj helyesen, és ellenőrizd az üzenetet.
  4. Frissítés után ismételj hibás tippeket nulláig. Figyeld meg az 1-ről 0-ra lépést. Újratöltéssel új számot és 20 pontot kapsz.
