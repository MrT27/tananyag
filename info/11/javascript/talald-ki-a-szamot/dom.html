Mi a DOM?

A böngészőben megjelenő HTML-dokumentumot JavaScriptből is elérhetjük.

A dokumentum objektummodellje

A DOM a Document Object Model rövidítése. A böngésző a HTML feldolgozása közben létrehozza a dokumentum strukturált, objektumokból álló ábrázolását. Ezen keresztül hozzáférhetünk az elemekhez, szövegekhez, attribútumokhoz és stílusokhoz. Ezek kiolvasását, módosítását, létrehozását vagy eltávolítását használjuk a DOM-mal végzett munkában.

A számkitalálós játékban például így olvastuk ki az üzenet szövegét:

document.querySelector('.message').textContent

A document a dokumentum objektuma. A querySelector() metódusa megkeresi az elemet, a textContent tulajdonságból pedig kiolvassuk a szöveget. A következő leckében módosítani is fogjuk.

A DOM fa szerkezetű

A következő egyszerű HTML-részletben a beágyazás határozza meg a kapcsolatokat:

<html lang="hu">
  <head>
    <title>Példa</title>
  </head>
  <body>
    <section>
      <p>Nézd meg a <a href="#">játékot</a>!</p>
    </section>
    <section>
      <h1>Találd ki a számot!</h1>
    </section>
  </body>
</html>
document
└── html
    ├── head
    │   └── title
    └── body
        ├── section
        │   └── p
        │       └── a
        └── section
            └── h1

A document a DOM belépési pontja, a html a dokumentum gyökéreleme. A head és a body a html gyermekelemei, egymásnak testvérei. A két section közös szülője a body. A bekezdés a link szülőeleme.

A fa elemeket mutató vázlat. A teljes DOM-ban a szövegeknek és a megjegyzéseknek is külön csomópontjuk van. A bekezdésben a „Nézd meg a ” és a „!” szövegcsomópont, köztük az a elem áll. Az attribútumokat, például a href értékét, az elemhez kapcsolva érjük el.

A böngésző biztosítja a DOM-ot

Az ECMAScript a JavaScript nyelv működését határozza meg. A document és a DOM műveletei a böngésző által biztosított webes API-khoz tartoznak. Az API az Application Programming Interface, vagyis alkalmazásprogramozási felület rövidítése.

A böngésző ezeket automatikusan elérhetővé teszi a weboldal szkriptjének, ezért a document használatához külön könyvtárat nem kell betöltenünk. A DOM működését szabvány írja le, ezt valósítják meg a böngészők. A webes API-kat JavaScriptből használjuk, a böngésző belső megvalósítása többféle programozási nyelvet használhat.

További példák az időzítők és a hálózati kérésekhez használható fetch(). Ezekkel később találkozhatunk. A JavaScript a DOM-on keresztül kapcsolódik a felhasználó által látott oldalhoz.
