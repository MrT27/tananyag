Kattintások kezelése

Az Ellenőrzés! gomb megnyomásakor olvassuk ki a tippet.

Az első eseménykezelő

Az esemény lehet kattintás, egérmozgás vagy billentyűleütés. Az eseményfigyelőhöz megadjuk, melyik eseményre milyen függvény reagáljon. Kommentezd ki a 76. lecke próbakódját, a 'use strict'; sort tartsd meg, és az alábbi kóddal folytasd.

document.querySelector('.check').addEventListener('click', function () {
  console.log(document.querySelector('.guess').value);
});

A HTML-ben az Ellenőrzés! gomb két osztálya btn check. A .btn az Újra! gombhoz is tartozik, ezért a .check szelektorral választunk. Az addEventListener() első argumentuma a kisbetűs 'click', a második az eseménykezelő függvény.

A function () { … } névtelen függvénykifejezés. Függvényt is átadhatunk argumentumként, ahogy szöveget vagy számot. Itt a függvényértéket adjuk át. A böngésző kattintáskor hívja meg, ezért az oldal betöltésekor a függvénytest még nem fut le.

Írj be 9-et, majd kattints az Ellenőrzés! gombra. A konzolban 9 jelenik meg. Írj be másik számot, és kattints újra. Minden kattintás az éppen aktuális mezőértéket olvassa ki.

A kattintás a felületet is módosíthatja

Próbaképpen a függvénytesten belül, a kiírás alá tedd ezt a sort:

document.querySelector('.message').textContent = "Helyes szám!";

Az üzenet így a kattintáskor változik meg. Ez még csak a kapcsolat kipróbálása. A teszt után töröld vagy kommentezd ki ezt a sort, mert a tényleges találatot a következő leckében vizsgáljuk.

A tipp eltárolása és számmá alakítása

Cseréld le az első eseménykezelőt erre. A value szöveget ad vissza. A Number() azért kell, hogy később a tippet a titkos számmal összehasonlíthassuk. Az üres bemenetet is itt kezeljük.

document.querySelector('.check').addEventListener('click', function () {
  const guess = Number(document.querySelector('.guess').value);
  console.log(guess, typeof guess);

  if (!guess) {
    document.querySelector('.message').textContent = "⛔ Nem adtál meg számot!";
  }
});

Üres mezőnél a value értéke "". A Number("") eredménye 0, amely falsy. A ! ezt igazzá fordítja, így az üzenet megjelenik. A 0 beírása is ezt az ágat választja. A játékban a keresett szám 1 és 20 közé esik. Ez az első ellenőrzés még nem vizsgál minden hibás bemenetet vagy tartományon kívüli tippet.

A következő leckében létrehozzuk a titkos számot, és a helyes, túl alacsony, valamint túl magas tippeket is kezeljük.

Önálló próba

Üres mezővel kattints, majd írj be 5-öt, és kattints újra. Figyeld meg a konzolban a 0 number és az 5 number kiírást. A második kattintás egyelőre nem állít be új üzenetet, ezért a korábbi hibaüzenet a felületen marad. Magyarázd el, miért a függvénytesten belül olvassuk ki a mezőt.
