11. évfolyam HTML és CSS 3. óra

VS Code beállítása HTML- és CSS-fejlesztéshez

Hasznos bővítmények telepítése, automatikus tagek használata és a Live Server beállítása.

Az óra célja

  • VS Code bővítményeket telepíteni és használni;
  • képelőnézetet használni HTML-kódban az Image Preview bővítménnyel;
  • színkiemelést használni CSS-ben a Color Highlight bővítménnyel;
  • automatikusan átnevezni a HTML-tageket az Auto Rename Tag bővítménnyel;
  • használni a VS Code HTML: Auto Closing Tags beállítását;
  • Live Server segítségével futtatni a weboldalt;
  • megérteni a localhost és a port fogalmának alapját.

1. Miért használunk bővítményeket?

A VS Code önmagában is alkalmas HTML és CSS írására, de néhány bővítménnyel gyorsabbá és kényelmesebbé tehetjük a munkát.

Fontos: a bővítmények nem helyettesítik a HTML- és CSS-ismereteket. A már megtanult munkát gyorsítják.

2. A bővítmények panel

A VS Code bal oldali oldalsávjában nyisd meg az Extensions panelt. Itt kereshetjük meg, telepíthetjük és engedélyezhetjük a szükséges bővítményeket.

Telepítendő bővítmények

  • Image Preview – képelőnézet HTML-ben.
  • Color Highlight – CSS-színek vizuális kiemelése.
  • Auto Rename Tag – a nyitó és záró tag együtt nevezhető át.
  • Live Server – helyi webszerver és automatikus böngészőfrissítés.

3. Image Preview – képelőnézet

Az Image Preview bővítmény megmutatja a HTML-ben hivatkozott képek kis előnézetét közvetlenül a szerkesztőben. 

<img
  src="img/post-img.jpg"
  alt="HTML-kód egy képernyőn"
/>

Ez különösen akkor hasznos, ha a projektben sok képfájl található.

4. Color Highlight – színkiemelés

A Color Highlight bővítmény CSS-ben vizuálisan is megmutatja a megadott színeket. 

color: #0d6efd;
background-color: #f8f9fa;

A CSS tanulásakor ez különösen hasznos lesz.

5. Auto Rename Tag – automatikus tag-átnevezés

Az Auto Rename Tag bővítmény használatakor, ha megváltoztatjuk egy HTML-elem nyitó tagjét, a hozzá tartozó záró taget is automatikusan átnevezi. 

<p>Szöveg</p>

Például:

<div>Szöveg</div>

6. HTML: Auto Closing Tags – automatikus záró tagek

A VS Code beépített HTML: Auto Closing Tags beállítása képes automatikusan létrehozni a HTML-elemek záró tagjét. 

<p></p>

Mivel már ismerjük a nyitó és záró tagek működését, ezt a segítséget mostantól nyugodtan használhatjuk.

7. Live Server

A Live Server egy helyi webszerveren futtatja a projektet, és mentéskor automatikusan frissítheti a böngészőben megnyitott oldalt.

  1. Telepítsd a Live Server bővítményt.
  2. Nyisd meg a projekt HTML-fájlját.
  3. Kattints az alsó állapotsor Go Live gombjára.
  4. A böngészőben megnyílik a weboldal.
Megjegyzés: a portszám eltérhet. Gyakori példa az 5500, de nem minden gépen szükségszerűen ugyanaz.

8. Automatikus frissítés kipróbálása

Módosítsd ideiglenesen a magazin főcímét:

<h1>📘 Saját Kód Magazin</h1>

Mentsd el a fájlt. Live Server használatakor a böngésző automatikusan frissülhet. Ezután állítsd vissza az eredeti címet.

9. Localhost és port

A Live Server a saját számítógépünkön futó helyi webszervert használ. Ezt a környezetet gyakran localhost néven említjük. 

http://127.0.0.1:5500/

A portszám segít megkülönböztetni a számítógépen futó különböző hálózati szolgáltatásokat. Kezdőként ennek részletes működését még nem kell ismerni.

10. Live Server leállítása

Ha befejeztük a fejlesztést, az állapotsorban a futó Live Server jelzésére kattintva leállíthatjuk.

Ha a Live Server nem működik, továbbra is megnyithatod közvetlenül az index.html fájlt a böngészőben, majd kézzel frissítheted.

11. Közös órai feladat

  1. Nyisd meg a Kód Magazin projektet VS Code-ban.
  2. Nyisd meg az Extensions panelt.
  3. Telepítsd vagy ellenőrizd az Image Preview bővítményt.
  4. Telepítsd vagy ellenőrizd a Color Highlight bővítményt.
  5. Telepítsd vagy ellenőrizd az Auto Rename Tag bővítményt.
  6. Kapcsold be a HTML: Auto Closing Tags beállítást.
  7. Telepítsd és indítsd el a Live Server bővítményt.
  8. Módosítsd ideiglenesen a főcímet, majd mentsd el a fájlt.
  9. Ellenőrizd az automatikus frissítést.
  10. Állítsd vissza az eredeti kódot.

12. Ellenőrző kérdések

  1. Mire használható a képelőnézet?
  2. Mikor lesz hasznos a színkiemelés?
  3. Mit csinál az automatikus tag-átnevezés?
  4. Mire való az automatikus záró tag?
  5. Mire használjuk a Live Servert?
  6. Mi történhet mentés után Live Server használatakor?
  7. Mit jelent a localhost?
  8. Mi a portszám?
  9. Mit tehetsz, ha a Live Server nem működik?

Összefoglalás

  • Image Preview: segít felismerni a képfájlokat.
  • Color Highlight: segít a CSS-színek használatakor.
  • Auto Rename Tag: együtt módosítja a nyitó és záró taget.
  • HTML: Auto Closing Tags: automatikusan létrehozza a záró taget.
  • Live Server: helyi szerveren futtatja és mentéskor frissíti az oldalt.
